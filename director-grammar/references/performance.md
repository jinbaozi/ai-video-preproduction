# 可见表演与镜头内动作

## 把情绪变成可拍行为

以“触发 → 微反应 → 行动 → 对手/环境反馈 → 停止状态”写表演。
例如：听见金属声 → 指尖先停、目光下移、眉间略收 → 肘部带手拉回信封 → 对方手不接信 → 手停、视线回到对方面部。
这是一条动作因果链；不要同时要求惊讶、悲伤、愤怒、冷笑都清楚出现在几秒钟内。

按镜头选细节：

| 条件 | 可用载体 | 避免 |
|---|---|---|
| 近景且面部清楚 | 视线目标与转移、眉/眼睑/嘴角的小变化、吞咽、呼吸 | 堆砌解剖肌肉名而无可见结果 |
| 中景保留手 | 手指接触、动作停顿、腕肘肩协同、躯干轻移 | 推进后手离画仍要求看清接触 |
| 全景/远景 | 姿态、距离、步序、重心、进入/离开画面 | 宣称观众能读出细微眼肌变化 |
| 背面或遮挡 | 肩背、头部偏转、手和呼吸节奏 | 要求看到不可见的眼神和嘴角 |

眼睛先看什么，头随后转多少，躯干怎样跟随，脚怎样调整，要各自清楚。
无需无依据地填每个关节角度；数字应服务动作或预演，并标为拍摄设计。

## 接触与重心

手部动作至少写对象、哪只手、接触部位、移动方向、受力/承载关系与终态。
“自然转身”不足以解释固定双脚的人怎样改变朝向；写支撑腿、脚掌旋转/跨步和肩髋先后。
舞蹈或教学优先脚底、全身、节拍；相机不得围绕主体遮住关键支撑转换。

## 对白与声音

可复制正文写 `说话人：“台词内容”`。旁白与画外音也登记稳定说话人。
语气、音量、语速、重音、停顿和表演写在引号外；保留用户台词，不为填模板新增对白。
先确认说话者、听者与画面人物关系，再定口型和反应。对话时不要让每位角色同步动嘴。
`start_frame/end_frame` 是设计时间窗；实录/生成音频应实测时长，检查可懂度、口型和剪辑锚点。

静默也有功能：完全无声、保留环境声和无对白是三种不同要求。
首版无原生音频后端会把 sound/dialogue 留给后期并写入损失表，不伪造已生成配音。

## 修订表演

只改变失败载体：视线没转就明确观察对象与时点；手指穿模就减少同时接触点；脸漂移先查首帧身份绑定。
不要因手部失败改写故事、人物身份或全部灯光。保留旧 Take 和失败时间码用于比较。
