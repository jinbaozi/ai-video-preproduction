# 构图、三维空间与相对位置

## 两套坐标，不能混写

世界为右手坐标：X向场景右、Y向纵深、Z向上，单位米。原点由场景选择并写明；跨场景坐标不直接比较。
画面为归一化坐标：左上(0,0)、右下(1,1)，box=[左,上,宽,高]。
人物左/右手采用人物解剖方向；画面左/右由摄影机朝向决定。侧身或反打时不能沿用未转换的画面位置。

机位 `start_m/end_m`、观察点 `look_at_m`、roll、光学焦距、主体朝向和视线是不同量。
首版只编码一个观察点；复杂焦点/视点变化在 path/focus 中写明并用关键帧验证，不能宣称为精确三维轨迹求解器。
变焦改变视角范围；推轨改变机位与透视。广角观感通常还取决于距离，不能只填焦距。

## 构图的工作顺序

1. 定义必须看见的叙事/演示证据，例如“纸始终贴桌”和“脚掌接触地面”。
2. 选景别和视角，让证据有足够面积、清晰度、停留时间。面部与手须同时读懂时，先解决同框。
3. 安排注意力顺序，利用大小、亮度、清晰度、方向和运动引导；背景细节不能夺走关键动作。
4. 选择对称、三分、对角、中心、框中框或不平衡布局，解释它如何表达关系。它们是工具，不是评分规则。
5. 明确头部空间、视线空间、运动空间、负空间与字幕安全区。竖屏尤其要检查双人站位和手脚。
6. 写起始与结束画幅。主导运镜不能在中途裁掉证据。AI输出的中间帧也要审，不能只检查首尾。

`composition.subjects` 是计划可见框，非实测检测框；安全区也是设计意图。
首版静态校验只检查数值范围、可见部位、部分左右顺序与机位后方矛盾。
它不能证明透视、头顶裁切、肢体遮挡、碰撞或焦平面实际成立；用平面草图、关键帧/预演与真实视频补验。

## 空间与身体

每个实体记录初终位置、姿态、支撑、接触和视线目标。人、物、摄影机分别描述路线。
动作按“准备 → 发力/支撑转换 → 移动 → 接触/反馈 → 停稳”检查。
拿起道具需要原支撑释放和新接触建立；递交需要交接时刻与归属变化；坐姿转身允许脚/骨盆自然调整。
不得为锁脸要求身体完全不动而同时大幅转头；不得让固定脚底与整体平移同时发生，除非动作确为可解释滑步。

前中后景要有尺度、遮挡与视差逻辑。玻璃、镜面、门框必须属于已登记场景；不要为“电影感”添加无来源家具。
镜中视线与相机不能凭主观左右推定。使用反射时明确真实主体、镜面位置、反射主体与不可见区域。

## 连续性

轴线是场景地平面的有向两点。`positive/negative/on_axis` 根据叉积定义，并非全局“北/南”。
跨轴可以是有意设计，但需连续越轴、轴上桥接或重新建立空间；提供可见过渡理由。
对话反打要保留人物屏幕方向、眼线高度、观察目标、光源世界方向；世界-X侧光在反打中不一定仍位于画面左。

连续动作使用 `from_shot + match_entities` 检查明确前驱的终态；插入镜头后可以引用最近一次包含同一动作的镜头。
时间省略/新场景需要理由，不能拿来掩盖未计划的道具瞬移。远近镜头更换也要复核手型、物体方向和动作阶段。
