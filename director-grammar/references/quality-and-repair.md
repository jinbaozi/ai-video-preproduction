# 质检与局部修复

| 门禁 | 当前工具可检查 | 仍需人或实际执行 |
|---|---|---|
| G0 输入 | ID/来源关联、附件存在、文件名/哈希、声明状态 | 文件内容、来源真实性、用户授权含义 |
| G1 导演 | 阶段帧数、引用、初终态、轴线侧、部分左右投影、可见部位声明 | 动作物理可行性、遮挡、表演负荷、意义与空间读懂程度 |
| G2 编译 | 目标时长/词法/长度、附件路径、请求形状、损失与来源映射 | 入口仍可用、账号和预算、语义是否完整兑现 |
| G3 实际素材 | 记录/哈希新鲜度、媒体可probe解码 | 身份、接触、手指、步序、表情、视线、运镜、光影、声音/口型 |
| G4 最终成片 | 证据关联与实际帧数/尺寸/FPS | 接点、节奏、信息次序、字幕、安全区、听懂/看懂、播放质量 |

QA命令需要ffprobe。缺工具、文本伪装视频、默认“尚未执行”的PASS或版本变化均阻塞。
即便probe正确，仍不能代替真实观看；`ACCEPTED_RECORDED` 只说明完整的通过记录已被核对。

## 实片观察方法

先完整播放一次判断观众目标，再按镜头起、中、末取帧；接触、换手、越轴和转身段提高抽帧频率或逐帧看。
记录素材路径、sha256、Take/Shot、帧号或时间码、观察与原因。不要对没看过的媒体签PASS。
看表情时检查触发前后区别；看动作时检查支撑、受力、接触和停止；看构图时检查关键证据在全过程可见。
声音需要听：源文件是否带音轨不能证明说话归属、口型、台词完整或触发同步。

G4按真实成片检查：总帧数、画幅、声音、字幕、黑帧/闪帧、拼接连续性、信息顺序。
判断观众是否理解时，让审片者说明看到了什么与何时知道，不仅问“有没有电影感”。

## 最小修复路径

| 失败 | 优先改变 | 保持 |
|---|---|---|
| 人脸/衣装漂移 | 身份首帧冲突、参考维度、当前镜头幅度 | 故事、未受影响角色 |
| 手与道具穿模 | 接触动作分段、接触点数量、关键帧 | 台词和场景事实 |
| 关键证据被裁切 | 机位/景别/终点框、主体路线 | 证据出现时序 |
| 左右关系跳变 | 机位坐标、轴线过渡、反打参照 | 已确认空间与角色归属 |
| 反应早于触发 | 动作/声音锚点、剪辑入点 | 既定信息差 |
| 口型不同步 | 当前台词、声轨或口型任务 | 无关B-roll、背景图 |
| 字幕外观不合适 | 字幕与最终渲染 | 已通过角色视频 |

每次记录假设、变更字段、所用Take、观察结果与剩余尝试数。达到合同上限后停止该依赖任务。
不得在失败后同时改风格、身份、镜头和故事再声称已定位原因。

## 评测边界

代码回归覆盖非法输入与编译行为。真实质量评测需同批场景、素材、预算，多次生成并记录失败候选。
分别报告叙事理解、身份/空间连续、动作终态、可用秒数成本和重试数；没有媒体与账单不能填成功率。
