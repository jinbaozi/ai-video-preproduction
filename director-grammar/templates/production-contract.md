# 制作合同填写模板

用于沟通，不直接提交工具。将尖括号内容替换为项目事实；可编译版参照 examples 中完整 JSON。

- 合同与版本：<合同ID / revision>
- 任务与观众目标：<要让观众知道、感受或看清什么>
- 上层事实源：<Canon URI、版本或哈希>
- 交付：<前期提示词包 / 实际素材 / 成片及规格>
- 执行范围：<已授权动作与授权记录，未授权动作不推断>
- 预算与重试：<币种、金额、适用范围、每任务上限、停止条件>

|要求ID|来源及定位|硬/软|字段/镜头范围|允许的实现渠道与执行路径|验收ID与判据|
|---|---|---|---|---|---|
|<ID>|<文件/消息/时间码>|<hard/soft>|<JSON Pointer>|<参数/文本/附件/后期>|<可观察条件>|

|镜头|信息变化|初态→动作→终态|构图与可见证据|世界位置/轴线|相机/表演|不可改变项|
|---|---|---|---|---|---|---|
|<Shot>|<观众/人物所知>|<触发与反馈>|<面部/手/脚/道具>|<机位、朝向、接触>|<有动机的表达>|<身份等>|

|验收ID|G0–G4|方法|证据文件/哈希/时间码|审片者|状态及观察|
|---|---|---|---|---|---|
|<ID>|<gate>|<静态/帧审/播放/probe/理解>|<实际文件>|<执行者>|<NOT_RUN/PASS/FAIL>|

变更规则：硬要求修订需新版本与决定来源；旧回执保留，依赖内容重新检查。
签收条件：全部阻塞项通过，实际证据与当前版本一致；前期包不得签收为生成媒体。
