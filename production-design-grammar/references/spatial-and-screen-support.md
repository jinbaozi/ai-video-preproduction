# 构图、三维空间、表情与镜头的美术支持

本文件决定镜头前的布景条件，不重新做导演分镜。以下判断是设计与人工审核方法，不是几何求解保证。

## 两套空间

与 director-grammar 对齐：右手系 X向场景右、Y向纵深、Z向上，米；原点必须写清。
`set.layout.position_m` 是资产的底面中心锚点，`size_m` 是未旋转长宽高，yaw为绕Z轴的设计值。
首版检查锚点边界、尺寸正值和结构件计数，不做旋转包围盒、碰撞、透视或完整可达性求解。

导演的归一化画面框左上(0,0)、右下(1,1)仍由导演持有。世界X大不等于永远在画面右；
相机反向、侧视或roll变化后要重新检查。人物左右手始终为人物自身左右。

三层空间分别写：建筑和固定陈设；可移动道具及支撑面；导演角色与摄影机轨迹。
记录门窗开合空间、通道宽度、桌下空间、坐面高度、取物可达区和不可侵入区。
功能区域是设计体积与人工检查目标，不因为JSON合法就声明角色走得过去。

## 画面构图支持

1. 从导演 must_show、composition和camera读出要看清的脸/手/脚/物及视点变化。
2. 在既定前中后景配置结构、陈设、色块和纹理频率，避免柱子从头顶长出、强反光压过眼睛。
3. 用明度、色相、边缘、材质与负空间区分主体。不要只靠浅景深掩盖不成立的布景。
4. 为视线/运动/字幕保留低信息区域；背景简化不可擅自删除剧情道具和固定建筑。
5. 运动镜头检查起点、中间、终点的遮挡和视差；只在起点好看不算成立。
6. 世界总柱数与镜头可见柱数分别审；局部特写不能要求所有结构件挤入画面。

`relative_relations` 描述美术所支持的支撑、容纳、接近与世界左右条件。
人物站位和道具运动轨迹读取导演，不在ArtIR新增角色路线。每条关系给可观察判据，不能只写“自然”。

## 人物表情支持

| 导演条件 | 美术应处理 | 交回导演的情况 |
|---|---|---|
| 面部近景、眉眼必须可见 | 帽沿/刘海边界、妆面反射、面后低频背景；保留身份锚点 | 既有朝向或遮挡使眼睛不可见 |
| 中景看手与脸 | 袖口不吞手指、道具握持尺寸适当、衣领不挡下颌 | 画幅裁手或焦点无法兼顾 |
| 远景或背面 | 用轮廓与衣装明度支持导演既定身体行为 | 要求读取不可见微表情 |
| 表情前后连续 | 保持年龄、面部结构、妆面、发际、既有痣/疤和服化状态 | 想以改脸、换人、增笑容来“优化美感” |

美术不指定“第2秒挑眉、随后冷笑”；该内容属于performance。美术写“眉尾不被刘海遮挡，
面后去掉未经锁定的高频条纹，保留既有发型轮廓”，并附实际近景验收条件。

## 镜头表达协作

低机位表达庄严时，美术保证门洞、梁架、上部材质和人体尺度参照可信；不重新选广角焦距。
推镜显露信息时，美术保证移动中逐步出现的线索真实存在；不能提前把它放在初始视点可见处。
反打保持窗/炉火的世界方位；玻璃与镜面提供表面位置和反射审核项，不能凭画面左右推算反射。

若需要精确六柱、接触位置或复杂镜面，先做布局图/三维预演/必要参考图，再审真实帧。
未生成预演时写待办，不声称已用坐标控制生成模型。
