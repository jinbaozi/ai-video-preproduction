# 风格路由

12张原创语法卡在 `registries/styles.json`。研究人物只是检索入口，不是编译参数。

生活年代：`period_lived_in / urban_memory / contemporary_observation`；神话媒介：`ritual_myth / ink_material`；
未来世界：`alien_monument / industrial_layers / culture_future`；风格化：`handmade_fable / gothic_environment / graphic_blocks`；
产品：`brand_product`。

先按 world_mode、medium、禁用项硬筛选，再按叙事任务标签匹配。分数为 `3×匹配标签数−风险先验`，
仅为可解释启发式，不是审美最优模型。没有匹配就报错，不随机套风格。显式locked_style仍须通过硬筛选。

输入标签从世界、环境叙事和制作需求提取；不要为了高分堆全部标签。风格已批准则固定ID跨镜继承。
每张卡包含形态、色彩、材料、图形四维及验收要点；具体世界事实始终高于卡片默认建议。
辅助语法只选一个维度并写理由；同一场景不能逐镜重选主语法。

例如架空酒馆选择年代生活语法，原因是器物使用史和可通行尺度服务交接动作；
不把“唐代意象”自动称为考古复原。产品演示以材料与功能识别为先，不套入悬疑、仪式或人物戏剧。

风格来源冲突时保留用户锁定项，修订未锁定设计；无法一致则标记冲突并提出具体可选改法。
路由器无法从自由语言证明文化准确性，也无法识别所有软性冲突；冻结前仍需美术复核。
