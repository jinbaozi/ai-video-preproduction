# V5.2 运动、动态空间与无损交接合同

本文件由 video-prompt-compiler/scripts/shared_v52 单一源码构建，六个包各自携带运行资源；运行不导入相邻技能目录。V5.1 细节、声音与动作合同继续适用。新完整制作使用 DirectorIR / StoryboardIR / AVIR 1.2，ArtIR 保持 1.0；旧 1.0、1.1 走明确兼容分支。读取旧原件、旧构建重放、达到新细节标准须分别报告。

## 职责和使用尺度

导演持有意图及锁定项；美术持有空间、材质、服化道、光源；分镜细化未锁的时序、姿态与构图；图片优化器只改图片指令表达；编译器冻结后不增加制作语义；总工作流登记来源、资产、版本与实际依赖。每项技能可独立完成职责内的必要设计，区分来源事实、实际观察与设计补充。不强制轻量任务建项目、填坐标或填写 JSON。

轻量例：“保留右手拿杯、转腕和递交这三个动作，逐项写清接触、支撑和收束。人物整体向门口移动时，身体方向、回头、视线和对白分别定时。摄影机横移同时摇摄，最后转焦；缺少距离和角度依据时使用明确相对描述。”

## 1.2 数据权威

`timeline.spatial_nodes` 登记实体整体、部位、摄影机、场景元素、群体或范围节点，包含稳定 ID、实体、父节点、部位、坐标依据、来源。节点标签用读者可理解的名称；自身右手不等于画面右侧。只拆本任务需要控制的部位，不要求骨架动画。

`motion_tracks` 每条只占用一个节点的一种动态属性：position、orientation、gaze、rotation、zoom、focus、deformation、extent、group_motion、light、color、material、atmosphere。身体、头部、视线分别用节点/属性，门转动、布料形变、烟雾扩散不强制刚体轨迹。记录对象、动作/摄影机引用、时间、路径、速度、起止及中间关键值、来源。已拆动作不能重新合为一句；父级表示目的，轨道依附动作，不另执行一遍。

同一对象同一动态属性不得有重叠权威；旧状态/起止视图用于一致性检查。多条并行轨不靠数组顺序覆盖。镜头位移、朝向、变焦、焦点分开；truck+pan 可以并行，相同属性冲突会报错。明确的 pan 与 tilt 可沿独立轴并行；复杂旋转需 Agent 核对合成顺序，脚本不模拟摄影机。

## 坐标、时间与求值

世界坐标为右、上、深；画面坐标为右、下、深；局部和人体自身坐标声明锚点。数值不是必填，`mode=relative` 保留完整相对描述和目标，不能填伪数值。数值位置是三维向量；数值方向为单位向量；数值旋转需角度标量、明确单位旋转轴。世界轴对齐 bounds 是偏移范围，不冒充旋转后的包围体。

局部转世界仅在同刻有明确世界锚点、相符原点及正交归一坐标基时计算。没有投影/范围依据，画面位置、世界位置和遮挡不互相推算。缺证据的数值变换阻塞该转换；有效相对表达仍可使用。

区间统一左闭右开，镜尾和瞬时关系使用 point。来源时间、项目时间、生成片段局部时间及真实媒体时间各自保存，分数帧率沿用有理数边界转换；音频不强制量化到帧。

关键值默认 `transition=none`，节点间未知。输入明确 hold 才保持，明确 numeric linear 才计算位置/标量中间计划值，输出 DERIVED_*。不插值身体姿态、关节、接触或物理可行性。关键姿态缺失返回 NEEDS_KEY_POSE，不用整镜初态填补。

## 动态关系与构图

`spatial_relations` 记录关系双方、坐标、点/区间、判定依据及来源。支持上下、远近、世界/画面左右、前后、朝向、接触、支撑、包含、遮挡、附着。附着另存连接部位、明确相对偏移及解除时刻；接触、支撑与控制权互不替代。

`composition_tracks` 记录每段构图、主体画面区域、可读尺度、可见部位、前中后景、注意顺序、留白、安全区、遮挡和入出画。区域允许部分或全部在画外。表演可见性按实际发生区间及声明的可读尺度检查；起初背对不否定之后正面微笑。数值区域与可见性矛盾报告，文字 occlusion 仍须语义复核。

画格只取指定时刻的完整关键姿态及相关轨道、构图、朝向、视觉、接触。已知数值求值不等于完整姿态插值。不同画格依赖实际消费的时刻状态；更改其他时间节点不自动使该画格失效。

## 交接与正文

1.2 有独立转换分支，空间关系不经过旧版枚举。完整 timeline、来源与合同保留；StoryboardIR 的新空间坐标与 AVIR 都采用同一声明，所以逐字段直接映射。旧静态字段按既有显式规则转换，合同 Pointer 随字段映射更新。导演/美术文件及适用完整依赖保留，不用摘要代替。

交付完整制作说明、可复制模型正文、覆盖报告与附件表。正文使用片段局部时间，按当前空间/构图、逐动作及附属运动、分时摄影机、声音、终态与保持项组织。逐项写对象、部位、方向依据、路径阶段、速度、朝向、接触与收束，名字代替内部 ID。对白原文及说话人、起止时间、归属、口型和渠道保持；静默心理不变发声，后期声音不冒充原生音频。

覆盖记录使用 source_path、来源指纹、对象 ID、正文块及文本指纹、转换规则，区分 direct_output、equivalent_conversion、not_applicable，以及诊断中的待语义判断/无法表达。来源和结构元数据留在制作包，不混入模型正文；坐标变换的 origin 是执行数据，不能误当来源元数据。正文被删改或缺少覆盖条目可确定性发现；含义是否等价仍需当前 Agent 审阅全文并绑定内容指纹，不能靠词命中或字段映射判通过。必须执行的硬要求只有 sidecar 不算完成。

超限完整稿保留，拆段保持动作相位、轨迹/朝向/附着、构图、焦点、声音及参考。跨边界动作或运动轨需明确切片，未知边界阻塞。拆段正文不重复生成后期对白，不把计划标成无缝媒体。

## 检查、修订、迁移和证据

geometry-checks 只对有依据的同一坐标关系计算。PASS 检查点不证明整条曲线或物理接触；UNDETERMINED 不等于失败，也不等于已验证。缺乏相机投影、实际范围或观察证据时明确未判定。真实视频需核源哈希和已看范围，新观察只记实际查看；图片审核、静态检查、语义复核、视频执行分别记账。

工作流 `revise --node-id ID` / `--track-id ID` 使用已有范围检查；节点变化含父子/锚点依赖，单条轨变化不因同场景扩散到角色设计。动作依赖、同步声音、关系、画格和片段分别传播。已有项目按原 modules.lock 运行，新版安装不改旧锁。

原生包可用 `python scripts/upgrade_spatial.py INPUT --out NEW_DIR` 从 1.1 生成 1.2 草案、原件副本和缺项报告。1.0 先显式升级到 1.1。旧件不改写，升级状态 NEEDS_REVIEW，不补造不存在的轨迹、朝向或动态构图。旧相对引用转为明确路径，不替用户批准。

发行版本：工作流 0.5.2，专业技能 1.3.0，转换器 1.2.0；项目存储协议仍 5.0。共享源一致性、隔离安装、重复构建和包哈希检查通过，仍不能证明模型更可控或实际视频质量。
