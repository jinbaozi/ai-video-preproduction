# 世界与资产设计

先写一句美术命题：环境应让观众读出何种身份、关系或变化。产品和教学任务以功能可读性为目的，
不自动添加冲突、反转和故事。研究事实、创作推演和已批准事实分别登记来源。

## 十二个设计域

| 设计域 | 最小可执行设计 | 验收线索 |
|---|---|---|
| 世界与文化 | 年代/地域/气候/资源/制度；史实与架空边界 | 关键形制有来源或明确推演标记 |
| 环境叙事 | 物品归属、使用史、阶层、空间权限 | 观众能从具体物件读出设定，不靠旁白补救 |
| 形态与尺度 | 母题、人体参照、承重关系 | 巨物有比较物；门/椅/台面可实际使用 |
| 场景与陈设 | 门窗/立柱/通道/家具与世界坐标 | 全景与反打仍是同一布局 |
| 色彩叙事 | 主/辅/角色/强调色及阶段原因 | 关键资产从背景分离；情绪变化不等于全片滤镜 |
| 材料与旧化 | 基材→工艺→表面→使用史→局部损伤 | 接触与水热位置解释磨损，不平均铺脏 |
| 道具 | 功能、尺寸、持握点、归属与允许变化 | 接触、支撑、转交可见；缺口和结构连续 |
| 服化协同 | 身份锚点、剪裁、纹样、妆发、湿/损状态 | 人物本人穿指定服装；年龄、脸和既有皮肤特征保持 |
| 画内图形 | 精确文字、徽记、地图、屏幕的可编辑资产 | 字符逐字正确；未生成的字体纹理不能算完成 |
| 光源与气氛 | 窗、火、灯的世界位置；烟雾影响区域 | 反打保留物理光源；烟雾不吞关键证据 |
| 媒介与特效 | 实体/水墨/能量/合成层及遮挡关系 | 接触与阴影明确；笔触层不造成实体漂移 |
| 资产与连续性 | 版本、不可改项、状态事件、依赖 | 可回查来源及受影响镜头；旧证据不签新版本 |

## 资产卡

按用途制作必要视图：身份正面/侧面、全身衣装、场景俯视布局/关键反打、道具接触面和缺口细节。
不要强制每件资产四视图；应由后续镜头的可见面和操作需要决定。参考图计划是文字，不能当已生成图。

资产明确 `identity_locks` 与 `initial_state/state_rules`：锁定补片所在肩、碗的形制与缺口；允许湿度、
开闭或持有人依据剧情变化。把磨损规则与具体损伤锚点分开，避免每帧随机重新旧化。

多角色/换装：人物ID与服装ID分开管理。提示词写“指定角色穿着指定服装”，不能只写服装环境。
从身份图仅继承脸/发/体态时，明确排除背景、饮料、背包和原衣装等非目标元素。

## 状态演算

按 `shots` 的故事顺序，再按镜内 `events.order` 递推。剪辑倒叙场景应拆包或由宿主提供独立状态切片，
本版不将剪辑顺序误当复杂时间线求解。事件写来源、触发、before/after及导演phase指针。

碗 table → host → guest 是有效状态链；代码仅验证链条。接稳后再松手仍要审导演动作与真实媒体。
单张关键帧只写当前初态；禁止同图同时端碗、递碗、接碗和空手。跨场景坐标不可直接比较。
