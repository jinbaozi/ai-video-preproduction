# V5.1 细节、时序与交付合同

本文件是同源构建资源，维护源位于 video-prompt-compiler/scripts/shared_v51；各 Skill 自带副本，无相邻目录运行依赖。版本 1.1.0。

## 独立与合作

导演管理意图和锁定项；美术管理空间、服化道、道具、材质与光线；分镜细化未锁定动作及画格；视频编译器冻结后只转换；图片优化器只优化当前时刻；总入口管理事实、版本、依赖、资产和交付。没有上游时在用户授权内设计并标明来源，不为补上游启动整个工作流。

轻量任务也逐项写清细节，但无需 JSON。完整制作由 Agent 整理原生协议，脚本验证和导出。DirectorIR 1.1、StoryboardIR 1.1、AVIR 1.1 保留各自静态结构，新增 timeline 时间轨。旧 temporal 数组必须留空以避免双重权威。旧版 1.0 的命令及语义保持原分支。

## 动作与动态状态

场景、节拍、镜头显式关联，动作组表达目的和保持条件，不额外重复执行。动作有稳定 ID、跨镜 semantic_id、parent_id、类型化依赖和独立时间范围。独立动作变化（主体、部位、目标、接触、持物、关键节奏）要分项；同一连续轨迹的速度节点不机械拆为新行为。

叶动作分别保留触发、执行部位、路径、速度、接触、承重支撑、控制权、反馈、收束和确定状态变化。右手不能仅写“手”；否定语义不能丢失。表情、视线、手部、身体、呼吸、发声表现独立关联动作。未知、不适用、不可见分别记录；未知必需执行细节阻塞最终交付。可以补齐既定动作所需合理细节并标 design，不增加剧情或情绪转折。

state_samples 是已明确设计或已观察关键状态，不是物理插值。changes 的 before/after 应与样本一致。接触、支撑、控制分开，允许共同接触和承重交接。并行动作可以改变不同字段，同一字段冲突必须修正，不能靠数组先后掩盖。

时间轨坐标统一明确为 x-right,y-up,z-depth；导演旧静态坐标 X-right,Y-depth,Z-up 仅世界位置按 [x,z,y] 转换。屏幕左右、人物自身左右、朝向和焦点不得套用同一位置变换。旧静态状态只作兼容边界视图，必须与新版关键状态逐项复核。

visibility 按实际表演区间说明可见部位和可读性，支持遮挡、入出画、转身和移动构图。先背对后转身微笑，只要求微笑发生时表情可读；不因镜头初态背对强制切镜。

## 摄影机

每一分时操作独立列出类型、起止机位与构图、路径、速度变化、观察目标、焦点、轴线策略及同步动作。固定、推拉位移、横移、摇摄、变焦、转焦分开。可并行的平移和摇摄保留两轨，互斥操作不能同时成立。未知距离或焦距不伪造数值，可用明确相对描述。数值都是制作意图，除有已核验的执行证据外，不声称模型具有精准运动控制。

## 声音与时间

对白、音效、环境声、音乐、有叙事意义的静默均有起止时间，不量化音频到视频帧。对白原文只登记一次，保留说话人、画内/画外/旁白、口型要求、native/post 渠道。一句跨正反打用一个声音事件覆盖多镜，不在每镜重新生成一句。后期画内对白确需口型时单独提供视觉口型指令；画外和旁白不要求嘴部可见。静默心理不变成发声。

接触声等以指定动作开始、结束或具名 marker 加 offset 同步；不能一律绑定动作结束。重叠发声须有依据。拆分短语后必须原样拼回原文。

来源时轴、项目计划时轴、片段局部时轴、实际媒体时轴分别登记。帧率可为 30000/1001，边界按分数直接换算毫秒并四舍五入；同一边界共享结果，不累计逐镜舍入。source_time_maps 留下剪裁、变速或设计依据。计划中的精准时间不冒充真实媒体测量结果。

## 无损交接与复核

原件按不可变版本保存。任务读取相关完整依赖，镜头外未来剧情及证据不灌入模型正文。覆盖记录包含版本、来源字段指纹、对象 ID、目标字段/正文条目/执行渠道、规则、检查状态。直接保留、等价转换、不适用、待判断、无法表达分别记录。

detail-coverage 的 emitted 只证明确定性字段投影及正文指纹，不能证明语义等价或模型已执行；retained 仅表示留在制作包，不代表已满足正文硬要求。当前 Agent 对照原件与实际正文复核手别、否定、阶段、依赖、声音归属。semantic_review 的 PASS 绑定完整内容指纹，不以关键词命中替代。字段值改变则复核失效；已绑定文件哈希的纯路径迁移不改变语义。合同 Pointer 要随字段迁移更新。

## 真实参考视频与画格

有参考视频时先 probe、登记哈希及观察范围，调用本 Skill 自带的 observe_video.py（总工作流使用锁定导演或分镜模块）。默认 0.5 秒浏览，关键区间 0.1 秒加密；需要定位变化首帧时继续查看相邻原始帧。提取使用实际帧索引/PTS，固定采样不等于完整观察。每条观察关联已查看帧 ID、源哈希和不确定项。声音另行听审，截图不能证明说话人。

```sh
python scripts/observe_video.py extract INPUT.mp4 --out observation-v001 --start 0 --end 3 --step 0.5
python scripts/observe_video.py extract INPUT.mp4 --out key-range-v001 --start 2 --end 2.5 --step 0.1
python scripts/observe_video.py review observation-v001 --record reviewed.json
```

reviewed.json 包含 reviewer、source_sha256、viewed_frame_ids、findings（frame_ids/observation）及 audio_review（status/method）；只能记录真正查看/听审的结果。抽帧成功是 EXTRACTED，实际查看后是 SAMPLED_FRAMES_REVIEWED，仍非完整运动验收。未经观察的范围保持未验证。

画格提示词只描述画格时刻的状态、表情、视线、接触、机位与构图。不存在明确 key pose 时返回 NEEDS_KEY_POSE，由 Agent 补设计并标来源。图片优化器不可用整镜初态代替中间时刻，不把动作全过程塞入静态图。

## 正文格式与交付

交付完整制作说明（含原生结构和来源）、可复制模型正文、覆盖报告与附件表。正文必选：片段/镜头局部时间、主体、场景光线、初态、构图、逐动作、逐摄影机操作、声音安排、终态、保持项。存在参考、对白、接触、运镜时相应字段条件必选。可选项只在适用时出现。扩展声明版本和执行渠道，未知执行语义阻塞相关交付。

动作各占条目，不合并已拆开的动作；摄影机各阶段独立写出。附件用真实文件名并限定身份/服装/构图/运镜用途。正文不包含内部哈希或验证术语。后期声音进入 post-production 独立执行说明，正文说明声音安排，不把其存在误报为原生音频已生成。

超限保留完整正文和损失报告，生成拆段提案；生成片段不等于叙事切镜。提案说明动作相位、持物、相机/焦点、声音延续、参考帧、必要重叠和费用影响。跨边界动作需要明确切片/关键姿态；对白需要短语边界或单独后期全轨；不能自动重说或重做动作。尚未完成适配的方案不得标为可执行或无缝成片。

## 兼容与检查边界

旧包原件不改写。upgrade_detail.py 产生独立草案和报告，缺少的新细节保持 unknown/PENDING；非固定旧运镜不猜类型。读取兼容、旧构建重放、新标准验收分别报告。

修订沿实际动作依赖、声音同步、画格时刻和附件传播；更换模型只重编译适配，不重生无关角色图。旧项目使用原模块锁；新版不默默换锁。用户批准绑定具体图片版本和用途；结构复核不是用户批准。

静态检查、实际图片审核、参考视频观察、实际视频执行四项分别记录。任何测试或正文长度都不证明生成画面更可控。
