# 视频编译最小阶段

## 默认执行

先读[核心合同](references/stage-core.md)，按“必要输入 → 自动路由 → 原生结果 → 校验/审计/交接”执行。简单任务不建立团队、额外计划或重复中间稿；完整流水线也使用同一核心流程。普通定稿自主完成，只在真实阻塞时通知用户。

完整流水线只读已接受AVIR/分镜和附件；独立提示词由宿主在授权范围内设计。目标、版本、模式、音轨与参考职责不猜测。

交付原生编译包：AVIR、artifact、能力/完整性清单、逐段正文、必要参数与附件。全长prompt是审阅视图，实际投喂用通过切点验收的分段文件。

## 保留边界

已有原生输入先验证并复用，不重写锁定事实。名家、场景与技巧按任务路由；不得以人名代替采用证据，不全库加载。硬约束、原文、真实附件、视听连续性、审计和异常处理不能因省token删除。没有真实生成/查看结果时，不宣称画质或视频交付通过。

## 按需深入

[全部资料索引](references/resource-index.md)只作检索入口；[完整执行参考](references/detailed-execution.md)保留专业细节与旧协议。复杂或专属任务只展开命中章节，原生schema/验证器仍是字段规则依据。
