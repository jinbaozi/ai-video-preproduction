# 自然面容视频行为回归

以下是待执行请求与验收标准，不代表已生成视频。程序验证来源、路由、冻结内容和回放；实际外观与时序由宿主看片，不能用关键词检索代替。

| ID | 请求/情形 | 验收 |
| --- | --- | --- |
| NV01 | 写实近景人物转头后回应朋友。 | 固定面容与皮肤区域随脸运动；表情/透视变化不新增永久不对称；不为自然感加对白 |
| NV02 | 胡茬人物由近景切中景再回近景。 | 同一胡须型、密度区与发际；中景不要求可数毛孔，回近景不重置布局 |
| NV03 | 已冻结 AVIR 只有“自然肤质”，选自然面容模板编译。 | 正文保持原生字段投影，模板不擅加分区、标记或动作；不足返回有范围的修订建议 |
| NV04 | 已锁夜景硬光与彩色灯，脸部转动。 | 保留灯光；高光/阴影变化不能错误固定成痣或色斑；不可辨区域 N/A |
| NV05 | 风格化动漫人物或远景背面人物。 | 具体范围不适用，不以方法卡覆盖风格或虚构隐藏细节 |
| NV06 | 原人物没有胡茬，想自然皮肤。 | 不增加胡茬、痘印、年龄或健康状态；商业修饰可保留 |
| NV07 | 长发随既定头部动作运动。 | 按已授权动作连续跟随与回落，不随机抽动、逐帧变发际；不要求运动帧发丝同锐 |
| NV08 | 两段独立生成拼接同一角色。 | 必要身份/毛发锚点与真实附件映射复述，末态承接初态；检查切点和尺度，不重置人物 |
| NV09 | 只拿一张关键帧声称毛孔全程不闪烁。 | 单帧不能证明时序稳定；需实际镜头及时间定位，未看片保留 NOT_RUN |
| NV10 | 给“不要真人感”的否定标签。 | 不以子串命中自然面容；既有来源绑定的语义分析决定适用性 |

看片先看完整镜头，再查转头、表情峰值、遮挡与切点的原始分辨率帧；每项附可见证据和时间码。文本检查、编译检查和真实媒体状态分别记录。
