# 自然面容的视频继承与时序检查

## 来源与适用范围

依据用户于 2026-10-12 提供的约 86 秒视频分析文字归纳；未获得或独立检查原视频、逐帧图及完整转写。用户转述的原片方法是五官只重点强化一两个特征、轻微不对称、皮肤区域差异、胡茬分区/边缘/方向、先柔光检查再风格化。用户材料止于胡茬方向；眉毛、头发和下述时序方法均为本项目延伸。未确认的“画面观察”不升级为事实；不声明模型增益已实测。

仅用于写实人物/真人照片感，不替换已锁定风格、人物身份、年龄、妆面或毛发。五官主识别点数量不限制身份锚点数量；已有参考多个突出特征照常保留。胡茬、痘印、泛红、稳定不对称均为有来源的条件项，不自动添加。背面、远景、遮挡和失焦不展开不可见微纹理。

## 前端创作方法

1. 继承身份与参考职责，再把五官主识别点和稳定形态写入现有 `entities[].appearance/locks`。新设计避免同时极端强化高鼻梁、深眼窝、高颧骨、锋利下颌；微小不对称需要已有依据，不用随机畸变制造辨识度。
2. 特写按细节类型、区域、强度和过渡描述皮肤。鼻翼/内侧脸颊毛孔与较平顺区域有差异；眼下轻微阴影和下巴局部泛红只在适用时保留。毛孔、短毛、痣和痘印形态不同，不统一为黑点，不以强锐化制造纹理。
3. 已有胡茬按实际胡须型描述密度与方向；上唇/下巴较密、脸颊较稀只是可用示例。边缘自然过渡，方向顺面部曲面。延伸：眉毛分区方向与头发发根/分缝/发束连续，整洁修剪按既定造型保留。
4. 新设计先以有方向的柔光检查脸部体积与区域过渡，再按已授权导演意图风格化；这是检查次序，不要求额外生成。已锁硬光、彩光或夜景不改灯光，不可辨细节记 N/A。

## 时序与连续性：延伸方法

稳定面容和皮肤标记绑定人物及面部区域；视角、遮挡、景深和光照可改变其可见程度。转头不能使毛孔或痣在脸上滑动/新增/消失，胡茬密度与发际不能逐帧重置；变化的明暗、高光不等于固定色斑。表情造成眼睑、嘴角和面颊张力变化，不改变稳定骨相；不要求脸部纹理像屏幕贴图一样固定不动。

发束运动绑定头部转动、风或身体动作，有连贯跟随与回落，不随机抽动或逐帧重画轮廓。眼神、眨眼、呼吸等只在已有动作/表演范围内细化，不为“更自然”新增动作、改对白或改变时长。运动模糊与清晰区服从镜头，不强制所有时刻毛孔同锐。

近景切到中远景后只继承可读身份与毛发轮廓；再次回近景应回到同一人物的区域布局。独立生成段复述必要身份/毛发锚点及真实参考映射，前段末态承接后段初态。景别变化不重置年龄、胡须型或永久不对称。

## 原生字段与冻结边界

| 内容 | 现有原生承载 | 复核 |
| --- | --- | --- |
| 稳定面容、皮肤/毛发布局 | `entities[].appearance/locks` | 只用已有或授权设计的稳定特征 |
| 光线与可见区域 | `scenes[].lighting`、镜头 camera/style | 不改冻结灯光；按景别和焦区检查 |
| 表情、转头、发束运动 | `shots[].performance`、原生 timeline/motion 字段 | 可见动机与时长一致，不新增剧情 |
| 参考与跨镜交接 | `assets/bindings`、`shots[].start_state/end_state` | 身份职责与禁止继承项一致 |
| 验收 | `contract[].acceptance` 与既有审片记录 | 逐镜/逐帧证据，无法辨认记 N/A |

字段结构服从实际 AVIR 版本 schema；表中是承载入口，不是新的 API 参数。冻结 AVIR 缺少必要外观信息时，给有范围的损失/返修建议，由原责任阶段修订；编译器不直接注入方法正文或重写锁。模型专属引用、负面框、上传槽位和参数仍由精确能力入口决定；文本不保证精确纹理绑定。

可用既有模板机制：

```sh
python scripts/vpc.py techniques plan --target agnes-video-2.5 --template natural-face-realism
python scripts/vpc.py compile examples/teahouse.avir.json --target agnes-video-2.5 \

```

第一条展示方法卡；第二条只投影示例原有字段，不使示例自动获得新面部细节。模板按来源绑定的语义标签路由，不能从“不要真人感”等否定词子串命中。`natural-face-realism` 是外观细节方法，不是新的主风格，可与已批准的手持/商业光线共用；风格化任务须有范围地不适用，不能覆盖原风格。

## 提示词片段与验收

以下仅为独立创作或冻结前授权设计示例，不粘贴到已冻结 AVIR：

> 人物继承批准的面容与发际，近景中鼻翼和内侧脸颊的原有细微纹理向外侧较平顺区域过渡；转头时皮肤区域随面部曲面变化，光照改变高光而不新增皮肤标记。既定发束随头部动作连贯跟随并回落，表情张力变化保持同一人物骨相，既定光位与对白不变。

实际审片先看完整镜头，再定位转头、表情峰值、运动遮挡、切镜与分段边界。检查身份、区域滑动/闪烁、毛发密度/方向/发际、视角和光照的合理解释；不凭单帧断言时间稳定。只修失败区域或责任字段，保留成功动作、台词和灯光。没有真实生成与看片时，`submitted=false`、`media_quality=NOT_RUN`；静态校验不升级为视觉通过。行为回归见[自然面容视频用例](../tests/natural-face-cases.md)。
