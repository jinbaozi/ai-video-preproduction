# 执行路径与验收

本包有真实本地编译器，没有生成传输、排队服务、付费调用或真实VBench结果。
制作合同给宿主执行，`submitted=false/runnable=false/media_qa=NOT_RUN`不因静态测试改变。

## 四层验收

| 层 | 检查 | 通过的含义 |
|---|---|---|
| G0来源/意图 | 来源、真实文件名、版本、身份/台词/参考职责、补充的出处 | 需求可追踪；需要Agent语义审查 |
| G1静态编译 | schema、ID/引用、时轴、起止空间、可见性、字段断言、模式/时长/数量、预算、重放 | 软件转换与声明规则有效 |
| G2提交前入口 | 当前模型/账户/地区/模式、附件槽位、媒体尺寸/时长/格式、URL可用性、额度及既有授权 | 宿主可执行；API草案自身不是此证据 |
| G3媒体/成片 | 身份、构图、空间、表演、接触、连续性、语音/口型、音乐、最终时长像素 | 基于实际素材的验收，不能由G1代替 |

每条合同记录PASS/FAIL/NOT_RUN、证据URI、哈希、时间码、检查者/工具和修订号。
仅有字段断言时`static_assertions=PASS`，其`realization`仍为NOT_RUN。

## 宿主执行合同

1. 使用AVIR与compile-manifest固定一次执行输入；发现BLOCKED只继续独立工作，修复依赖项再提交。
2. 按mode上传真实已审素材，核对文件名/哈希/数组次序/槽位；不把本地路径当公共URL。
3. 在既有用户授权内提交；新费用、权限或重大创作变更才补决定。幂等键建议用project/revision/target/shot/build_id。
4. 保存供应商真实request/job/video ID，轮询至终态；遵循渠道退避与有界重试，未知结果不能重复付费提交。
5. 回收媒体URI/哈希、生成参数、实际费用与时延；按post清单配音/音效/音乐/字幕/剪辑。
6. 实际观看关键帧与完整视频，听取音轨，按合同检查；失败只修订引发问题的字段并建立新revision。

Agnes国际站文档使用返回的video_id及model_name查询；不同代理可能不同，不混用ID或轮询路由。
本Skill的batch是本地NDJSON批量编译，逐项成功/失败独立返回，不是异步生成队列。

## 媒体检查方法

构图/空间：关键主体、手脚/道具可见，画面左右与世界关系一致，无遮挡穿模；相机移动符合意图。
表演：触发顺序、微表情可读且不过量、重心/支撑合理、人物/物件路径与落定连贯。
声音：ASR核对原文与说话人，听取停顿与语气，口型/接触音对应时点，旁白不侵占画内口型，音乐不盖对白。
实际时长与分辨率用媒体元数据核实；原生输出和后期导出分别记录。

## 真实A/B与质量优化

同一输入、参考、模型版本、入口、时长/比例/分辨率、多个seed比较基线和候选；盲评保存偏好与失败原因。
可接VBench主体一致性/运动平滑/空间关系及其他物理、常识指标；指标按任务选择，不能一条CLIP阈值代替全部验收。
报告中的55%胜率、成本/合格片和时延指标是建议目标，未测不得写达成；小样本不做普遍结论。
记录编译时延、排队、生成、实际成本、合格数量；合格为0时成本/合格片应为空或无穷，不能写0。
没有媒体时保留候选规则，不能宣称prompt优化提升质量。
