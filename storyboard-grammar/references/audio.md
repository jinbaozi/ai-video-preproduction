# 台词、心理、旁白与音乐

## 声音归属

| 条目 | Schema | 口型与执行 |
|---|---|---|
| 画内对白 | dialogue + on_screen | lip_sync按目标需求；需mouth可见 |
| 画外对白 | dialogue + off_screen | 仍归真实说话人物，当前画面不要求口型 |
| 旁白 | narration + voice_over | 独立旁白voice实体，不强塞给画内角色 |
| 内心独白 | internal_voice + voice_over | 原文发声依据；绑定对应表演心理条目 |
| 静默心理 | performance.psychology.silent | 不创建utterance，不可被编译成VO |
| 音乐、环境声、动作声、静默 | cues.kind | 独立时段、混音与同步标记 |

原文台词在source.excerpt中的字符区间逐字登记，utterance同时绑定source_id/source_utterance_id。
保留原语言、标点与人物归属；输出正文用`说话人：“台词内容”`。引号是正文排版，不改变text值。
范围内每句恰好一次；删句必须在scope.excluded_utterance_ids写原因和来源。禁止把人物心理擅自转成可听台词。

## 时间与节奏

整数帧使用全片时轴[start,end)，不要把镜内秒数与全片秒数混用。
先按语句自然节奏朗读，再放置动作与停顿。CLI的每秒7字符提示仅为粗排期警告，不能当语言学上限或音频验收。
重叠对白写overlap_reason；同一声音句子跨镜时，当前Schema要求宿主显式映射及来源跨度记录，不能复制整句到两个镜头。
J/L-cut或音乐跨镜用cue.shot_ids覆盖真实时段；动作音sync_event绑定事件完成帧。
声音原生或后期渠道不改变台词归属。需要画内口型时，即使后期配音也要保留画面动作时点。

## 音乐与环境

音乐描述作用、进入/退出位置、密度、音色、节奏与是否随剧情转折，避免写成无作用的“史诗配乐”。
混音明确对白时让位、环境空间感、动作声清晰度及静默含义。不要默认所有分镜有BGM或旁白。
音乐不是动作音：放下道具的瞬间应由具体接触事件同步，不能用节拍近似代替。
已有音轨记录文件及用途；版权或许可由资产/宿主记录，不在本分镜文件编造“可商用”。

文本验收、说话者音色、口型、实测时长与混音可懂度是不同验收项。没有音频时全部声音媒体项为NOT_RUN。
