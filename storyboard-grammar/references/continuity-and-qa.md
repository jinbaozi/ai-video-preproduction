# 连续性与验收

## 自动检查范围

来源摘录/文件哈希、台词字符区间、实体与场景引用、指定镜头范围、节拍覆盖及前置关系；
连续帧时轴、画格与动作时间、状态类型、事件before/after回放、持物接触/松手/拿取、相邻镜头逐字段继承；
固定行动轴及机位起终侧、世界相对坐标、声明画框顺序、表演所需部位、近景微表情；
发声类型、原台词和speaker、声音重叠/同步、资产文件/版本/用途冲突、上游声明锁及制作合同断言。

这些检查使用输入声明，不自动理解原文语义、推断全三维人体或识别图片内容。无来源的新增剧情即使结构通过仍应被Agent审阅拒绝。

## 连贯性分层

| 层 | 审阅重点 |
|---|---|
| 剧情 | 行动起因、角色已知/观众已知、揭示次序、反应对象、台词覆盖 |
| 人物 | 身份、年龄、发型、妆容、衣饰、身体比例、惯用手、声音归属 |
| 场景 | 门窗与出口、桌椅拓扑、世界光源、天气与时间、行进路线 |
| 动作 | 姿态/重心、接触与支撑、握持侧、力的方向、前后动作相位 |
| 镜头 | 视线、轴线、屏幕方向、景别可读性、焦点、镜内/镜外移动 |
| 声音 | 原词、声源、画内/画外、心理/旁白、动作音、声桥和混音 |

先看一镜起中末，再看相邻镜头交界，最后整段播放。动作连续性不只比较两张静帧。
静音看画面确认叙事可读性；只听声音核对说话者和信息；声画一起检查口型与同步。

## 结果状态

- INVALID：结构或硬断言失败；compile只写qa.report.json，退出码2，不发交接文件。
- BLOCKED：结构可审阅但硬参考/硬几何执行条件缺失；完整计划可交接审阅，execution_ready始终false，退出码2。
- VALID / PLANNED：结构检查完成；媒体、视觉与人工验收NOT_RUN，执行与提交均false。
- 真正的媒体PASS由宿主另存证据记录，不修改静态回执来伪装生成结果。

## 修复与验收条件

每个问题提供code、JSON Pointer、失败原因。修复导致失效的最小上游字段，再复查受影响镜头、合同和相邻状态。
软要求失败可保留W_CONTRACT及偏差；硬要求不能通过改成warn、删条款、删原句或省略坏帧来过检。
编译后运行verify检查产物完整性与Schema；它不是对当前外部依赖或语义的重新认证。源文件变化后运行inspect/重编译。

## 人工失败案例

远景写“瞳孔轻颤”承载秘密揭示：改用可读姿态或申请近景。
人物A画外后道具突然在B左手：保留画外A世界状态，补右手/左手交接事件或修正终态。
将“他心想不可信”读成旁白：按原文是否发声重新归属，未经允许保持silent。
反打画面仍写“窗光永远从屏幕左边”：先定位世界光源，再重算画面投影。
坐标和轴侧都对但人物穿过桌子：机器检查不足，交受控预演或人工路线审查，不报告几何通过。
