# 镜头与画格语言

## 七种对象

| 对象 | 职责 |
|---|---|
| Scene | 时间、空间、光源、实体环境 |
| Beat | 行动、反应或信息变化 |
| Shot | 连续摄影表达单元 |
| Panel | 镜内一个可审阅时点；多画格不必切镜 |
| GenerationJob | 一次模型执行，可容纳多个镜头 |
| Take | 实际素材候选，带真实文件与生成回执 |
| EditSegment | 选中take的时间区间及剪接关系 |

分镜层只计划前四项；animatic.plan中的takes与edit_segments在离线输出时为空。
九宫格只是审阅排版，不表示九个生成任务或九镜头。画格使用全片帧，落在所属镜头的[start,end)内。

## 景别按信息选择

大全景/远景承担地理、距离、路线；全景承担全身姿态和支撑；中景承担人物关系与手部；近景承载可读表情；细部插入承载特定动作或线索。
不能把眉眼微动写进远景当作关键信息。插入镜头前后明确所属人物、道具和空间，避免没有归属的手。
机位高度、俯仰、roll、主体朝向、头部方向、视线分别描述；“低机位”不自动等于人物低头俯视镜头。

## 运动和切镜

固定机位用于让行为变化可读；推近应有信息或关系收紧的动机；横移/跟拍交代路线；摇镜表达视线或发现；环绕会改变遮挡与轴侧，要承担连续性成本。
焦点转移与相机位移不同。推近和变焦会产生不同空间观感，不能用同一描述替换。
写移动的起止、经过区域、速度变化和结束状态，不能只堆“推拉摇移跟”。
每次切镜说明新增信息、反应或节奏原因，以及匹配动作相位、视线、屏幕方向或声音的方式。
接动作需看前镜尾若干帧和后镜头若干帧，不只比静态终态。跳时、换场、主观联想要明确入口和现实回归状态。

## 画格制作要求

画格选择建立空间、动作关键接触、信息揭示、反应或结束状态等实际节点，不按固定数量凑格。
每格有镜头ID、时点、场景/人物引用、要看见的事件、主体与must_show；继承所属镜头机位、构图和参考用途。
运动很复杂或构图中途变化时，Agent补更细镜内节点或拆镜；本版机位只存起终点与文字路径，画格尚无独立投影引擎。
需要动态独立机位、动态构图或动态轴精算时，保留制作说明并交预演；不要往当前Schema塞不存在的字段。
