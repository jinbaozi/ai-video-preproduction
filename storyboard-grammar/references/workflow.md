# 分镜工作流

## 输入与范围

优先读指定原文；摘要仅用作导航，不能替代台词、事件或人物状态依据。已有分镜先确认镜头ID与排序，禁止把“前五镜”理解为“前五集”。
读取参考图后才记录观察事实；没有实际文件时保留metadata_only，不编造长相、服装或文件名。
来源最少包括类型、URI、版本、定位、摘录和摘录哈希。文件来源另存原文件字节SHA-256。
既有项目用宿主Canon；独立创作可用当前用户需求作事实源，必要调度标为design，不伪装原文。

## 制作顺序与门禁

| 阶段 | 做什么 | 进入下一阶段的条件 |
|---|---|---|
| 来源 | 定位原文、上游锁定字段、参考用途与指定范围 | 台词归属、人物、场景、事件无关键歧义 |
| 节拍 | 列行动、反应、观众信息变化与因果依赖 | 每个必需节拍有镜头覆盖，删减有来源 |
| 语法 | 确定媒介、主语法、局部修饰与禁止项 | 不与硬要求、已锁风格或媒介可读性冲突 |
| 空间 | 原点、尺度、人物/道具布局、支撑、轴线 | 每个对象有位置与关系，行动路径可解释 |
| 镜头 | 视点、景别、构图、机位、焦点、剪点 | 每镜有新增信息或表演价值，必要细节可见 |
| 动作与声音 | 事件状态、表演链、原台词与声音时序 | 接触在拿取前、角色反应有触发、台词留足时长 |
| 合同与编译 | 硬/软条款、渠道、验收、降级、来源映射 | inspect无结构错误；依赖缺失明确BLOCKED |
| 交接 | 宿主映射AVIR、选择具体入口、回收素材 | 已有授权有效，硬要求有实际渠道，媒体QA另做 |

不要将每个阶段都变成向用户确认。可逆设计在范围内继续；仅剧情改写、硬要求冲突或缺失信息会影响正确性时询问，暂停依赖部分即可。

## 风格路由

`route`读取标签而非预测成功率，输出匹配词和分数供Agent选取。明确主语法，避免“唯美、电影感、复杂运镜”叠加。
透明叙事、悬疑、动作、喜剧、观察、动画、武侠、产品、竖屏、主观蒙太奇各自有执行规则和验收条件。
动作清晰/观察连续与主观蒙太奇作为全局规则冲突时，拆成有边界的段落，而不是删除连续性门禁。
媒介与画幅不强制绑定语法：水墨可拍克制对话，9:16可用双人和纵深构图。

## 修订

先定位失败属于原文、导演决定、美术资产、空间、表演、声音、后端或真实素材哪一层。
记录原版本/哈希、字段、冲突证据、建议值、影响镜头、验收条件。由拥有该事实的一方更新。
增加revision，新建输出目录；下游所有依赖旧哈希的镜头、合同与素材选择都需重查。
不把已编译输出反向覆盖源IR，不在失败重试时悄悄放宽硬要求。
