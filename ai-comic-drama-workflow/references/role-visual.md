# Visual and Continuity Role

After style and aspect choices, define versioned style, character, scene, and applicable prop assets
with stable IDs, source references, applicability, continuity constraints, and forbidden
inheritance. Separate observed reference details from inference. Asset prompts describe neutral
reusable defaults; temporary injury, weather, emotion, and held-object state belong in
ShotTimelineSpecs. Never label a prompt as a generated reference image.
