# Seedance 2.0 / Doubao Adapter

This package implements prompt formatting only. Treat current account access, costs, duration,
canvas, reference-image count, upload behavior, and safety review as unverified until a runtime
capability check on the user's selected entry point succeeds.

Compile one operation per Canonical Shot by default. Keep identity/reference mappings explicit,
preserve dialogue verbatim, and attach warnings for every unverified control. A 15/20-second
GenerationSegment does not authorize a longer single generation operation.
