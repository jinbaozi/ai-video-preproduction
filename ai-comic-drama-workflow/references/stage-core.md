# 最小创意到视频流水线：核心合同

## 输入与责任

输入是创意、原始资料、真实参考和目标入口。Canon只记录事实、身份、锁定及来源；不得把补充设计伪装成原文。

资料/Canon → ScriptIR → DirectorIR → 按场景ArtIR → 必需图像 → StoryboardIR/必需控制 → 分镜图 → AVIR/目标编译包 → 最终审计。生产入口存在时继续真实回收与剪映；DELIVERED不等于VIDEO_DELIVERED。

## 四步闭环

1. 验证来源、范围、原生输入和锁定项；缺真实媒体/权限/能力时保留阻塞，不伪造记录。
2. 新studio默认不要求方法研究和采用材料。显式开启craft-routing auto时执行自动方法路由。完整任务使用已经嵌入的task.craft；独立创作按当前目标选择登记方法。当前场/镜细化，主语法保持稳定，不覆盖用户要求。
3. 在授权范围创作或复用一个权威原生结果。只补影响叙事、可见画面、模型输入或验收的字段；确定性校验由脚本承担，语义与视觉检查由宿主承担。
4. 检查硬约束、采用证据和交接。失败返回原责任字段/阶段；普通选择由宿主定稿。通过后提交现有结果与审计，不另写重复的计划/上下文/方法清单。

## 原生交付与命令

每阶段保持一个权威原生产物和原任务/结果收据；00-progress.md是进度入口，09-delivery/index.md是交付入口。新studio默认最小上下文、按需方法与内置FFmpeg；--profile lean保留旧默认；--context-profile audit保留完整宿主阅读要求，--profile audited使用既有独立审阅。旧项目不迁移。

```sh
python -m pip install -e .
ai-comic-drama start "成年旅人雨夜拾起信封，焦点从信封移向表情。" --project ./film --target agnes-video-2.5
ai-comic-drama step ./film --result -
```

命令在当前技能目录执行，示例不代表已执行。仅在相应原生结果需要时调用验证器，不让用户填写项目协议。已有上游时继承其来源与版本；独立结果不是自动获得完整流水线验收。

## 自动路由与审计

studio不要求craft_context/craft_review。需要方法路由时显式开启auto，沿用以下证据规则。完整任务先读取最小任务视图，不重复打开其审计信封、整库注册表或来源目录。名家是项目归纳的方法参考，不是原话或质量保证；指明采用方法对应的实际内容和可观察结果。没有指定名家也保持自动路由。

采用证据相同时可分组列rule_ids，逐项覆盖规则不减少；不同场景/字段/结论不得为了省字合并。程序生成指纹与读取/校验回执，宿主不手填哈希、不自动宣称应用成功。未知、冲突和不适用必须有范围与理由。

最小审计保留输入/输出指纹、所选方法、采用位置、硬约束检查、结论与阻塞；真实生成与画质状态单列。问题只修受影响的字段和下游，不重写上游已接受内容。相同成功结果幂等；外部状态UNKNOWN先回收，禁止盲目重试。
