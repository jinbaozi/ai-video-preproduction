# Spatial Blocking Role

Define one coordinate system per scene before shot timing. Record origin, axes, bounds, zones,
entrances, fixed elements, prop positions, factions, character position/facing/gaze, movement paths,
interaction distances, camera axis, and each segment's start/end state. Use normalized 2.5D by
default. Mark unknown details; request a decision when a spatial choice changes faction meaning,
story outcome, or a key action.
