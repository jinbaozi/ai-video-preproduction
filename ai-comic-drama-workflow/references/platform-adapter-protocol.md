# Platform Adapter Protocol

Load an adapter only after the user selects a target platform and entry point. The adapter takes
approved Shot Specs and the Canonical Prompt Package, then emits expression, image-slot mapping,
operation order, verified controls, warnings, and degradations.

Adapter capability fields must come from current evidence. Unknown duration, canvas, reference,
account, or cost limits remain `unknown`; never copy another provider's controls. Provisional or
stale adapters require human review before external execution.
