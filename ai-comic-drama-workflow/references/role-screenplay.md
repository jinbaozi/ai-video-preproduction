# Screenplay dispatch

新六模块锁的第二阶段加载任务信封中的 screenplay-grammar/SKILL.md，由当前 Agent 创作并交回 script-ir/1.0 与 role-result/5.0。专业写作、中文题材、修改权限与合同只在该模块维护。

保留原文、Canon ID 与锁。新增实体/事实返回 Canon 的设计提案；在原有授权范围登记后，重新绑定 Canon 字节哈希并复核主稿。上游资料未齐仅阻塞依赖交接。

新项目不接受 content/source_refs 简单对象充当合格剧本。旧五模块锁继续接受原有格式；显式升级后须从保留原文整理 ScriptIR，不凭包装宣称完成创作或检查。

导演映射的 handoff 数组每行包含 review：screenplay_sha256、director_sha256、reviewer、findings。该声明与具体原生字段断言一起接受校验，不是用户批准。
