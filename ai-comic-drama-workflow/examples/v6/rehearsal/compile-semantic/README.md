# Compile 语义审阅演练

[`batch-1/`](batch-1/) 保存真实智能体对旧静态 CompilePackage 的独立语义检查、原始派发回执、结构化 RESULT、失败候选、内核事件和哈希。该批因 AVIR 终态可见性冲突正式失败；其失败证据转入后续 Control/Compile 责任重建，旧批次不作为当前已审结结果。

[`host-fingerprint-closure/`](host-fingerprint-closure/) 保存新构建的真实 `compile_review` 派发、候选和内核接受事件。17 条硬要求获静态复核，旧信件终态可见性冲突在当前 AVIR、时间线和正文中闭合；内核于修订 707 `ACCEPTED`。媒体 QA 仍为 `NOT_RUN`，后期义务仍为 `PLANNED`。
