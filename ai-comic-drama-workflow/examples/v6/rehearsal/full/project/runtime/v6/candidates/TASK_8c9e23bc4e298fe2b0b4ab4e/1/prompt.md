# PROP_LETTER 静态视觉提示词

## 来源与默认假设

- ArtIR 锁定同一封未拆信、完整封口、纸材与三镜连续；雨夜是源事实，中性偏暖纸色是美术提案。
- PLAN_PROP_LETTER 仅为文字参考计划；没有真实参考文件、附件槽位或实际图像。
- 中性承托面、略俯视的静态道具图是本次表达选择，不是剧情新增事件；画幅 4:3 为可调整建议。

## 主提示词

为道具资产 PROP_LETTER 制作一张单一静态的信封外观锚图，供 S_HANDOFF、S_SEAL、S_STOW 沿用同一封信的纸色、轮廓、纸纹与封口形制。本张是入包前的道具展示：只见一封普通纸质信封平稳置于无标识的中性承托面，从单一略俯视视点拍摄，使整张信封和朝上的闭合折叠封口完整入画；不表现交接、验封或入包的先后动作。信封采用中性偏暖的哑面纸色与细微纸纹；封舌沿折线平贴，边缘连续，封口从头至尾完整且未拆，无掀起、破口或内页外露。信体上没有可读文字、邮戳、签名、贴纸或图案，也不加入未给出的信件内容或来历。背景以低饱和蓝灰和低频雨夜气氛退后，不出现可辨地点、建筑、年代或室内外线索；柔和画外环境光让封口与纸纹可辨，纸色与背景分离，承托接触自然，不以反光或遮挡吞没封口。画面只呈现这一封，不添加第二封信、背包、人物或其他道具；此图只锁定入包前外观，后续沿用同一实体，8500毫秒后完全在背包内，9000毫秒终帧不再外露。
