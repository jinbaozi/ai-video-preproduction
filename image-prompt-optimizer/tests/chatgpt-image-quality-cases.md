# ChatGPT 非 API 图片质量回归

把真实请求与技能交给独立执行者；不要附本表预期，不执行生图或外部后处理。审查输出的约束、路由和边界，不以固定措辞匹配代替行为判断。文本通过不代表图片或降噪效果通过。

| ID | 请求 | 必须观察到 | 禁止行为 |
| --- | --- | --- | --- |
| CQ01 | ChatGPT 窗光半身人像提示词，要干净、低噪。 | 清洁目标与皮肤／衣物保护并存，短提示 | API 设置、满脸可数毛孔 |
| CQ02 | 雨夜直闪照片，暗部干净，保留背景灯轨。 | 减少彩斑且锁夜景曝光与灯轨 | 提亮全部夜景、移除指定模糊 |
| CQ03 | 保留胶片颗粒但不要噪点。 | 区分指定颗粒与异常杂纹，说明理解 | 全部磨平、把可兼容目标阻断 |
| CQ04 | 同一区域零颗粒，同时必须明显粗颗粒，两项都不妥协。 | 澄清互斥要求 | 静默选择、折中成细颗粒 |
| CQ05 | 全身穿搭照片，提高真实清晰度。 | 重点姿态、衣物轮廓、接触 | 无限皮肤纹理、所有区域同锐 |
| CQ06 | 半写实仙侠插画，减少碎纹但保留笔触和辉光。 | 保留绘画媒介与指定风格 | 真人毛孔、实拍化、删除辉光 |
| CQ07 | 只降低背景杂点，人物其他都不变；暂时没有上传图。 | 候选局部合同，缺证据不诊断 | 假装看图、重画人脸 |
| CQ08 | 只清理天空条带，并减少同一处彩斑。 | 两个兼容改动一起保留，锁其余内容 | 强制两轮或删一项 |
| CQ09 | ChatGPT 要9:16、2160×3840，保留全身。 | 目标／实际待核验分开，给可用构图提示 | API 字段、尺寸校验脚本、原生保证 |
| CQ10 | 仅有缩略图，说皮肤噪点是否消失并报像素。 | 证据不足，不评分或虚构像素 | 缩略图代替原文件验收 |
| CQ11 | 手指数量错误，只加高清能修好吗？ | 区分结构修订与清晰化，不作效果保证 | 将结构错误当随机噪点 |
| CQ12 | 只返回一条清洁数字绘画提示词。 | 一条提示词，无内部档案与解释 | 评分表、API／外部软件建议 |
| CQ13 | 胶片人像编辑词：减少暗部红绿色斑点，原有明显颗粒、肤质和夜景亮度保留。 | 去异常色噪与保留颗粒、纹理、曝光同时成立 | 将高 ISO 或胶片视为所有噪点的确定来源；加粗颗粒 |
| CQ14 | 新建现代护肤商业半身照提示词，干净低噪、柔光、自然皮肤，没有胶片效果。 | 保留商业修饰与柔光，按景别描述肤色／纹理 | 自动换硬光、直闪；添加雀斑、颗粒或漏光 |
| CQ15 | 为已有肖像写编辑词：只减轻皮肤磨皮感和发丝锐化白边，身份、年龄、妆面、光位都不变。 | 同时处理两项允许改动，锁定身份与原光位 | 增加年龄痕迹、全局锐化、强制拆轮 |
| CQ16 | 同一广告提示词要脸和标签清楚；另外请在画面外围金属栏杆高反差边缘加一点色差。 | 限定色差对象、低强度与范围，保护脸和标签 | 全图红蓝描边；为此模糊脸或文字；承诺必然更真实 |
