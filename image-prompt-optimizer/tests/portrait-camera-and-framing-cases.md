# 人像机位与取景行为用例

以下为待执行的行为回归请求与验收标准，不是通过记录；静态链接检查或脚本测试不能替代实际输出审查，更不能证明生成图像改善。执行时记录原请求、实际输出、判定及限制。

| ID | 请求 | 验收重点 |
| --- | --- | --- |
| PC01 | 三句话，贴地拍鞋，相对鞋部平视，镜头水平。 | 保留低绝对位置与平视关系，不改为仰拍，不填完整七字段 |
| PC02 | 成年女性身体朝右、头转向镜头、看镜头。 | 不强制正面身体；区分躯干、头和视线 |
| PC03 | 严格左侧脸，仅一只眼可见；其余不变。 | 明确人物自身侧别与画面鼻尖方向相容，不改为两眼可见 |
| PC04 | 全画幅85mm约三米，站立成年人竖版全身；优先保证完整造型，距离可调整。 | 识别覆盖不足、调整距离，数值只作意图，不声称精确模型控制 |
| PC05 | 一张全身远景，毛孔唇纹都必须像局部特写一样清楚，二者都不能退让。 | 说明景别竞争并询问取舍，不静默添面板或交多图 |
| PC06 | 全身穿搭为主，浅笑可辨即可。 | 全身边界与轮廓优先，不强制泪珠毛孔 |
| PC07 | 竖版趴卧全身，一条小腿翘起，身体允许沿对角线展开。 | 头脚、膝部与抬脚边界成立，接触支撑明确，不拉长肢体 |
| PC08 | 男友抓拍，只出现成年女友，她听到招呼刚转头。 | 单一互动瞬间，拍摄者在镜头后，不额外生成男性或虚构固定眼位 |
| PC09 | 空旷站台上的孤独人像，人物很小。 | 用尺度、留白、姿态表达，不要求微表情承担全部情绪 |
| PC10 | 写实成年模特坐姿，冷白皮、九头身，肤色自然。 | 协调比例并服从缩短，保留局部血色，不缩头拉腿或全身纯白 |
| PC11 | 时装插画，要夸张九头身；只优化配色。 | 保留风格化比例，不加载摄影几何纠正造型 |
| PC12 | 只修改已有图的高机位，改为胸部同高、镜头水平，其余不变；未附图。 | 明示基于文字的修订；锁身份、服装、动作，仅联动必要取景，不声称看过图 |
| PC13 | 只加f/4、ISO800就能保证真人感吗？ | 区分画面要求、摄影意图、工具设置，不保证参数收益或默认加噪点 |
| PC14 | 两次图的姿势和取景也变了，可以证明85mm更自然吗？ | 不归因于焦距单变量，说明随机与共同变量；不宣称已做生图实验 |
