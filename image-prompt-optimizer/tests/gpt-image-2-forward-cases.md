# GPT-Image-2 前向用例

发布 GPT-Image-2 适配前，由未参与编写的独立执行者直接调用本技能完成下列请求。执行者只能看到用户请求和技能，不提供预期答案；审查者再按“必须观察到／禁止出现”判定。无需实际生成图片。

## 执行规则

1. 每个用例从新上下文开始，不沿用前一例的提示词或参数。
2. 只评价技能产出的提示词、参数、追问和质量检查；不把模型出图随机性算作技能错误。
3. 任一阻断项失败，先修订技能，再用原始输入重跑。
4. API 能力以运行当日官方指南与参考为准；若无法核验，必须回退纯自然语言并标注参数待确认。

## 通过门槛

- 二十四个用例均无模型语法、任务路由、自然观看概念、结构化版式或局部编辑合同阻断项。
- G2-01、G2-04、G2-05 的人物身份、造型、表情与遮挡关系一致。
- G2-02、G2-03、G2-09、G2-10 的界面和参数边界均有当前官方依据。
- G2-04、G2-06 发生失败时，修订指令只改变一个变量并重述关键不变量。
- G2-11 的屏幕、视线、手部、景深与混合光属于同一摄影因果，且提示仍保持简洁。
- G2-12 只改变清晰度分布，并重述身份、几何、光线与内容不变量。
- G2-13 在同一局部编辑合同中保留两个兼容改动，不因单变量偏好删减用户意图。
- G2-14 把逐眼注视几何作为证据核验项，但只有排除正常偏侧目标与头部透视解释后才给确定性修订。
- G2-15—G2-18 完整区分尺寸合法性、实验性、Image API 与 ChatGPT 控制边界及实际像素核验；保留用户指定模型，generations／edits 均按各自当前请求参数给值。
- G2-19—G2-24 正确区分参考图新生成、遮罩编辑、结构化视觉和多图合成，并把数量、文字、顺序与编辑局部性设为硬门。
- 输出不依赖社区魔法词、固定长负面词表或无法验证的成功率承诺。
