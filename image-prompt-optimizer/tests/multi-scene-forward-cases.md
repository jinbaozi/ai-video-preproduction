# 多场景行为用例

检查任务路由和提示词内容，不匹配固定措辞；未生成图片时不宣称视觉质量通过。

| 请求 | 行为验收 |
| --- | --- |
| 三名朋友雨夜街头同框，一人递伞 | 图片数与人数分开，身份和动作归属明确，雨后不自动全身湿透 |
| 三位成人分别用参考脸 COS，穿角色灵感度假服 | 身份与角色来源分离，不把所有人同脸或同款换色 |
| 古风角色横向四视图 | 四格数量和朝向明确，不触发单幅抓拍禁令 |
| 儿童学生证件照 | 保持年龄身份与端正姿态，不套成人预设 |
| 团队统一制服，横排全看镜头 | 保留统一服装和正式构图 |
| 白底新品广告，不要颗粒 | 保持产品结构和洁净背景，不增加生活痕迹 |
| 三维人物和二维水墨特效 | 指定分层、遮挡、边缘和光照，不强改真人 |
| 身份不变但换成另一人的脸 | 询问明确冲突，不输出假定已解决的成稿 |
| 对称抓拍，慢快门直闪 | 不把对称或慢快门直接判失败，交代曝光和动作关系 |
| 大窗旁的人物脸上有太阳硬影 | 允许窗中直射太阳，不强改全柔光 |
| 集市多个人物各做不同事情 | 用主次和空间组织，不强制只许一个事件 |
| 只修衣服颜色，其余保持 | 最小修订，不重做脸、姿势或场景 |

案例应覆盖自然语言完整输出及不适用模块未被加载；实际生图评估须另行取得图像证据，不以规则静态检查替代。
