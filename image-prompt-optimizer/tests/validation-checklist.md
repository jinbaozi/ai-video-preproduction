# 验证清单

复杂交付、提示词审查或发布技能新版本时逐项执行。任一“阻断项”失败都要修正后再输出。

## 制作合同扩展检查（1.2.0）

复杂包先运行 `python3 scripts/validate_production_contract.py <合同>`，修订使用 `--baseline <原合同>`；此结果仅为结构与追踪检查。人工核对每条硬项在正文中等义出现、文字通道与说话人正确、空间与动作同帧一致、尺寸/去噪/逆光不越过模型界面能力。附加行为回归见 [合同与叙事用例](production-contract-forward-cases.md)。下列既有领域检查按当前任务选择。

## 1. 必检项

| 检查 | 通过标准 | 级别 |
| --- | --- | --- |
| 视觉意图 | 能用一句话说清主体、事件／状态、氛围和用途 | 阻断 |
| 操作模式 | 已区分文生图、参考图引导的新图、整体编辑、遮罩编辑、多图合成和连续修订；上传图片未被自动等同于编辑 | 阻断 |
| 交付物类型 | 已识别照片／人物、产品／电商、插画、海报／社媒、信息图、UI／网页模型或多面板；没有把人像检查表强套到其他资产 | 阻断 |
| 通用简报 | 用途、主体／核心信息、场景、媒介、构图／版式、光色材质、精确文字、约束、参考图角色和目标模型按需齐备；未机械补全无关字段 | 阻断 |
| 失败图证据 | 用户提供失败图时，已先以整图检查视点、比例、动作与光线；只有分辨率足够时才检查微小局部，并区分确定／疑似／可合理解释／分辨率不足；图片不可访问或成因不唯一时未伪装成已确认，而是请求原图或明示单一保守假设 | 条件阻断 |
| 词语有效性 | 每个关键形容词都能映射到主体、动作、光线、色彩、材质、空间或用途 | 阻断 |
| 人物要素覆盖 | 仅人物任务：已检查发型、发饰、发色、脸型、肤色、眼睛、眉毛、面容、服饰、配饰和表情；只输出可见且有用的项 | 条件阻断 |
| 属性来源 | 用户明确、参考图、品牌固定与创作默认可区分；未从外貌推断敏感身份 | 阻断 |
| 同级冲突 | 同一优先级的身份、造型、视线或表情互斥时停止成稿，合并为最多 1—3 个选择问题 | 阻断 |
| 身份与造型 | 仅人物／角色任务：身份锚点、造型变量和瞬时状态分开；系列图未无意改变脸型、眼色、基础眉形或发色 | 条件阻断 |
| 遮挡与佩戴 | 仅相关人物任务：发型、发饰、帽子、眼镜、耳饰和衣领的遮挡、固定与佩戴关系可成立 | 条件阻断 |
| 景别细节 | 仅人物摄影：面部微观细节与拍摄距离相符；远景未要求虹膜、单根眉毛或毛孔清晰 | 条件阻断 |
| 表情自然度 | 仅人物／角色任务：视线只有一个落点；眼周、口部、肩颈和动作属于同一时刻 | 条件阻断 |
| 姿态与手部 | 仅画面出现身体／手时：手势有支撑和受力；裁切、道具、关节与动作关系可解释 | 条件阻断 |
| 人眼概念边界 | 仅当用户提出“人眼成像／肉眼观感”时，已改写为视觉线索自洽的静态摄影；未虚构固定人眼焦距、光圈、景深、200° 鱼眼或无限 HDR | 条件阻断 |
| 观看模式 | 仅在人眼／主观视角任务中选择自然摄影、用户明确要求的主观化注视效果或双目／立体／VR；普通单幅图和仅说“像肉眼看到”时未混入双视点、重影或固定外围滤镜 | 条件阻断 |
| 视点与尺度 | 仅写实、3D 或有明确空间投影的画面：共享一个可信投影／观察逻辑；位置与可见尺度关系成立，拼贴、多视点或特殊投影例外已标注 | 条件阻断 |
| 人像机位与取景 | 仅相关人像：高度有参照，俯仰与高度分开；相机、躯干、头部和视线未混同；裁切边界、人物占比、姿态与画幅相容，情绪载体在当前景别可读 | 条件阻断 |
| 焦段与透视 | 仅摄影任务：焦段、拍摄距离、景别和主体比例互相支持；未混合长焦脸、超广角近手或另一消失点背景 | 条件阻断 |
| 景深与对焦 | 仅摄影／写实渲染任务：一个主要焦平面或可解释的清晰区明确；同深度静止物体清晰度相近，离焦随相对焦平面连续变化，运动、倾斜焦平面或合成例外已明示 | 条件阻断 |
| 曝光参数 | 快门／ISO 只在动作、拖影、低光、颗粒或同步有意义时出现 | 警告 |
| 光线因果 | 仅画面使用真实／模拟照明时：主光明确；当前距离、朝向和遮挡下的投影与材质响应可由光源解释，未强行为每个灯具添加效果 | 条件阻断 |
| 影调与适应 | 仅写实／摄影任务：曝光锚、高光、黑位和选择性暗部细节成立；无“人眼 HDR”、全局提灰、极端局部微对比或边缘光晕 | 条件阻断 |
| 色彩与后期 | 主白平衡／主色、局部混合光、颗粒、锐度和对比不矛盾；有人物时肤色优先级明确，未把所有不同光源强制中和 | 阻断 |
| 注视与眼神光 | 仅当双眼可见且人物正在注视具体目标时，已先定位物理目标，再逐眼检查虹膜相对眼角／眼睑的位置与头部姿态；两条视轴能在同一目标相交，会聚量与距离相称且不夸张；三分之二侧脸保留自然差异；眼神光只用于核对光源，不被误当作注视方向，无眼神光也可成立 | 条件阻断 |
| 接触与落地 | 仅检查当前景别可见且叙事相关的功能面、手—道具、身体—座椅、脚—地面或衣物—身体关系；遮挡、支撑、形变、阴影和互反射按可见性择要成立 | 条件阻断 |
| 屏幕／反射材质 | 相关材质出现时，屏幕、玻璃、镜面或液体的使用朝向、平面透视、内容、亮度、与材质／涂层相称的反射／扩散／折射、遮挡和焦点属于同一照片；人物注视点、屏幕法线与相机位置几何成立，相机可见性未破坏人物实际观看，无贴图感 | 条件阻断 |
| 材质密度 | 仅写实／材质敏感任务：同一观看尺度下各表面的细节密度相称；无一处无因超锐或相邻材质塑料化 | 条件阻断 |
| 去噪与成像痕迹 | 减少异常彩斑与保留指定颗粒、肤质相容；未默认添加色差／漏光；指定效果的位置、成因、强度和保护范围明确，未把直闪／硬光当通用真人感保证 | 条件阻断 |
| 生活方式自然度 | 仅在自然生活方式／纪实任务中，道具服务人物活动，并按叙事需要保留克制使用痕迹或不完全对称；整洁广告图未被强行做旧 | 条件阻断 |
| 真实感 | 仅在写实任务中，当前可见的皮肤、五官、视线、手指、服装、接触、反射或材质要求可以同时成立 | 条件阻断 |
| 模型语法 | 只使用当前官方文档确认的目标模型、版本、字段和值 | 阻断 |
| 模型名称保持 | 保留用户指定的精确模型／别名；只有用户明确要求固定版本并接受取舍时才改用已核验快照 | 阻断 |
| 字段隔离 | 主提示词、负面约束和生成参数分开；无跨模型参数污染 | 阻断 |
| GPT-Image-2 界面路由 | 已区分 ChatGPT Images、Image API 与 Responses API；未把某一界面的字段假定为另一界面可控 | 阻断 |
| GPT-Image-2 提示密度 | 简单任务保持 1—3 个清晰句子；复杂任务才分段，未把检查表原样堆入提示词 | 阻断 |
| GPT-Image-2 编辑合同 | 局部编辑已列出全部允许改动项、参考图角色、不变量与融合要求；单问题采用单变量修订，用户明确要求的多个兼容改动未被静默删除，必要的分轮建议已说明理由 | 阻断 |
| GPT-Image-2 参考图模式 | 已区分“输入图指导全新画面”与“以图 1 为基图编辑”；多图均有索引、元素来源和目标位置 | 阻断 |
| GPT-Image-2 遮罩 | 遮罩任务写明唯一改动、遮罩外不变量和边界融合；未承诺像素级硬边界，多图时知道遮罩作用于第一张输入图 | 条件阻断 |
| GPT-Image-2 禁止项 | 未输出 `input_fidelity`、独立 `negative_prompt`、`style`、seed、CFG、steps、采样器、`--ar`、`--no` 或透明背景 | 阻断 |
| GPT-Image-2 尺寸 | 自定义尺寸两边均为 16 的倍数且符合比例、总像素和最长边限制；实验性大尺寸已提示 | 阻断 |
| GPT-Image-2 4K 路由 | 已分别确认尺寸合法性、实验性、当前界面／端点能力和下载后实际像素；Image API generations／edits 使用各自当前请求参数，未把 API 控制假定为 ChatGPT 界面能力，也未把后期放大称为模型直接输出的 4K | 条件阻断 |
| GPT-Image-2 性能措辞 | 仅把 `quality: low` 作为低延迟草稿依据；未在无官方证据时宣称某画幅、尺寸或格式必然更快 | 阻断 |
| 精确文字验收 | 文案逐字引用、只出现一次且有位置／层级；未承诺一次生成无误；质量检查同时明确“先用 OCR 提取”与“再人工逐字核对”，只写泛称检查不通过 | 阻断 |
| 结构化视觉硬门 | 信息图、UI、海报和多面板的交付类型、必需组件、数量、精确文字、阅读顺序与关系先按通过／失败检查；审美分不能覆盖硬门失败 | 条件阻断 |
| 产品结构 | 产品任务锁定轮廓、部件、朝向、标签、固有色和材质；氛围、人物或场景未造成结构漂移或额外产品 | 条件阻断 |
| 语言洁净度 | 中文主提示词不夹杂零散英文；模型名、API 字段和标准参数除外 | 阻断 |
| 输出克制 | 未要求比较时只有一条主提示词；没有空泛品质词和重复同义词堆叠 | 阻断 |
| 权利边界 | 真实人物、品牌、参考图用途已确认或提醒；未直接模仿在世摄影师 | 阻断 |
| 物理承诺 | 未承诺模型一定复现真实相机、镜头或曝光效果 | 阻断 |

## 2. 快速冲突扫描

出现以下组合时必须解释或修正：

- 极近距离广角人脸 + 自然无透视夸张；
- 极浅景深 + 双眼耳朵和背景全部锐利；
- 人物、手机和前景道具全部锐利 + 与其同深度的沙发或桌面突然虚化；
- “肉眼视角” + 200° 鱼眼、固定径向周边模糊、50mm 等于人眼或全画面同锐；
- “人眼 HDR” + 窗外、肤色、室内暗部全部同亮、黑位提灰或边缘光晕；
- 多人错位 + 大光圈 + 所有人全锐；
- 低速快门 + 快速动作完全冻结；
- 单灯 + 独立主辅轮廓三灯；
- 柔光 + 同一光源造成极硬阴影；
- 无阴影平光 + 强烈明暗对比；
- 纯剪影 + 面部均匀可见；
- 同一区域明确零颗粒 + 必须明显颗粒且无优先级；去异常彩斑与保留指定颗粒可兼容；
- 胶片柔和高光 + 极端 HDR、零颗粒和超锐；
- 直视镜头 + 同时凝望画外；
- 双眼看近处手机／书本 + 视轴发散、各看不同位置，或头颈与眼睑方向相反；
- 齐刘海完整遮眉 + 眉毛全貌清晰；
- 深色墨镜遮眼 + 虹膜纹理和眼神光清晰；
- 紧贴头皮盘发 + 长发披肩飞扬；
- 同一人物基础发色、眼色或脸型在系列相邻图片中无原因改变；
- 全身远景 + 清晰毛孔、虹膜纹理和单根眉毛；
- 发饰、帽子或配饰占用同一空间，或穿透头发、皮肤和服装；
- 手持屏幕／玻璃 + 无透视、表面响应与材质／涂层或环境光不符、从边到边等亮，或显示内容像独立贴图；
- 人物从明显侧面注视屏幕 + 屏幕却完整正对相机，且没有可解释的镜面、转角或近视线轴机位；
- 同一照片 + 长焦比例的脸、超广角夸张的近手和另一消失点的房间；
- 明窗主光 + 暖灯点缀 + 所有区域被强制同一白平衡；
- 人坐沙发／脚踩地面／手握道具 + 无压陷、遮挡或附着接触阴影；
- 自然抓拍 + 所有道具完整朝向镜头、等间距摆放、色彩完美呼应；
- 塑料般绝对光滑皮肤 + 清晰自然毛孔；
- 通用／OpenAI／Gemini 提示词 + 未经核验的 `--ar`、`--no`、CFG、采样器或权重；
- Stability API + 自动套用 A1111／ComfyUI 语法。
- GPT-Image-2 + `input_fidelity="high"`、`background="transparent"`、`style="natural"`、独立负面提示或 URL 响应格式；
- GPT-Image-2 自定义尺寸 + 任一边不是 16 的倍数、边比超过 3:1、最长边超过 3840 或总像素超限；
- GPT-Image-2 4K + 把像素写成“8K／超清／杰作”等主提示词魔法词，或没有标记大于 3,686,400 像素的实验性；
- GPT-Image-2 图生图 4K + 未按当前 edits 请求参数核验尺寸、把 Image API 能力冒充 ChatGPT 界面能力，或把后期放大冒充模型直接输出的 4K；
- GPT-Image-2 局部编辑 + 重新改写全部主体、背景和构图；
- 三张参考图 + 未标明每张图的单一主角色和元素来源。
- 参考图引导的新图 + 错写成“只改图 1”，或基图编辑 + 错写成全新构图；
- 信息图／UI／海报／多面板 + 未指定组件／面板数量、精确文字或阅读顺序；
- 产品图 + 氛围描述改变产品几何、部件、标签或固有色；

## 3. 模型语法证据

输出任何模型专属字段前，记录：精确模型和版本、界面／API、字段名、允许值、官方直接链接、核验日期。缺一项则删除该字段并回退通用自然语言。官方没有独立负面字段时，不创建“负面提示词”区块。

## 4. 过度堆词测试

逐句问：“删除这组词，画面是否失去可见信息？”若答案是否定，删除。尤其审查“高级感、电影感、杂志感、奢华、8K、HDR、杰作、最佳质量、超细节”。若确实需要，把它们改写为构图密度、光比、色彩、材质、清晰范围、颗粒和用途。

## 5. 最小验收用例

| 用例 | 必须观察到 | 禁止出现 |
| --- | --- | --- |
| “30 岁女性在咖啡馆自然地笑，不像摆拍” | 动作触发的微表情、可读环境、合理焦段、单一自然主光 | 无模型时出现专属参数；“完美微笑”空词 |
| “完整设定一位虚构人物并连续生成三张照片” | 十一类人物规格、来源与固定／可变关系；相邻图片只改变 1—2 个轴 | 隐性推断族裔；脸型、眼色、眉形或基础发色漂移 |
| “三岁男孩坐在爬爬垫上吃玉米” | 年龄相符的发型、服饰、配饰与自然表情；视线、手部和食物接触成立 | 成人化妆造；不必要的永久外貌虚构；手指或食物悬空 |
| “户外友善成年人，淡紫短波波头、绿眼睛、白衬衫、轻微微笑” | 保留全部已知要素；只补摄影选择并标为默认；表情与唯一视线可观察 | 擅自补性别、族裔、肤色、脸型、眉形、发饰、配饰、职业或背景故事 |
| “同一人物同时黑色短波波头和铜色及腰卷发、戴发带又无发饰、直视又向下看” | 识别身份、造型与表情阻断冲突；合并成最多 1—3 个问题后等待选择 | 静默平均互斥属性；在冲突未解决前声称提示词可直接使用 |
| “极简护肤品牌全身广告，竖版留文案空间” | 版式留白、全身比例、受控棚灯、肤色与产品色优先级 | 近距离 24mm 无畸变；品牌授权被忽略 |
| “老木匠傍晚停下工作望向窗外” | 人物与工具受力、环境可读、混合光有动机、唯一视线 | 极浅景深抹掉环境；工具悬空；直视镜头 |
