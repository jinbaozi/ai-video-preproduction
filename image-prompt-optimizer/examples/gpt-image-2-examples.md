## 1. ChatGPT 中生成雨后街道自然人像

### 输入

> 一位年轻成年女性在雨后街道回头微笑，真实自然，环境人像，目标 GPT-Image-2。

### 输出

#### 需求理解与默认假设

- 核心是走动中听见呼唤后刚回头的自然瞬间，而非停下摆拍。
- 默认虚构成年人物、傍晚城市支路、竖向三分之二身；未指定永久外貌，不擅自补族裔、肤色、脸型或眼色。

#### 主提示词（可直接复制）

生成一张写实环境人像照片：雨停后的傍晚城市支路，一位虚构的年轻成年女性撑着收拢的伞向前走，听见画外呼唤后刚从肩侧回头，视线落向镜头，眼周放松、嘴角出现不完全对称的轻微笑意，肩颈仍保持行走中的自然转动。竖向三分之二身、眼平机位，人物位于右侧三分之一，湿润路面和商店灯光形成可读但克制的背景；左前方阴天柔光照亮面部，路面反光仅作环境层次，保留真实皮肤纹理、潮湿碎发、外套褶皱和握伞受力，不做塑料磨皮，不添加无关文字、标志或额外人物。

#### 质量检查

提示保持 2 句；视线、动作与微笑属于同一瞬间，主光与湿路反光有因果，未混入 API 或其他模型参数。

## 2. Image API 商业肖像与精确中文文案

### 输入

> 为原创香氛品牌做竖版人物海报，成年女性手持磨砂玻璃香水瓶，文案“雨后新生”，GPT-Image-2 Image API，最终成品。

### 输出

#### 需求理解与默认假设

- 第一视觉为人物与香水瓶，中文文案是硬性验收项。
- 默认品牌为虚构且无现成标志；采用常用竖版尺寸，最终发布前需人工核字和产品结构复核。

#### 主提示词（可直接复制）

任务与用途：创建原创香氛品牌的竖版人物广告海报，第一视觉是人物手中的磨砂玻璃香水瓶。
场景与背景：雨后温室入口，背景为低对比的深绿叶片和湿润玻璃，左上方保留干净文案区。
主体与动作：一位虚构成年女性三分之二侧身站立，单手从瓶底和侧面稳定托住香水瓶，另一手自然放松；她直视镜头，眼睑稳定、嘴角中性，下颌放松，气质清醒而克制。
人物与造型：湿润感低髻、少量自然碎发，简洁米白风衣和小型银色耳饰；不过度补充不可见永久外貌。
构图与空间：竖向半身，人物位于右侧，产品标签朝向镜头且不被手指遮挡，背景柔化但仍能辨认温室环境。
光线、色彩与材质：左前方大面积阴天柔光塑造自然肤色和磨砂玻璃，右侧轻微负补光保持轮廓；深绿、米白、雾灰和少量银色，保留皮肤纹理、玻璃雾面、风衣纤维、水珠和自然接触阴影。
精确文字：只出现“雨后新生”一次，现代中文无衬线粗体，米白色，左上方左对齐，与人物和产品不重叠；除此外不出现其他文字、标志或水印。
约束与不变量：人物手指与瓶体接触自然，瓶身结构连续，文案逐字一致且不裁切；无额外产品、植物穿透、塑料磨皮或无关品牌元素。

#### 生成参数

| 项目 | 建议值 | 说明 |
| --- | --- | --- |
| model | `gpt-image-2` | Image API |
| size | `1024x1536` | 合法常用竖版尺寸 |
| quality | `high` | 最终海报且包含关键中文文字 |
| output_format | `png` | 便于后续人工排版与核字 |
| background | `opaque` | 当前模型不支持透明背景 |

#### 质量检查

主提示词与 API 字段分离；没有独立负面提示或 `input_fidelity`；文案需检查逐字一致、只出现一次、无裁切和额外文字。

## 3. 多参考图身份保持式服装编辑

### 输入

> 图 1 是已授权人物照片，图 2 是羊绒大衣产品图。只给图 1 的人物换上图 2 的大衣，其他都别动；后续若衣领不对还要继续改。GPT-Image-2 Image API。

### 输出

#### 需求理解与默认假设

- 图 1 负责人物身份、身体、姿态、构图、背景和光线；图 2 只负责大衣的剪裁、颜色与材质。
- 本轮只更换外套。用户只声明图 1 人物已授权；图 2 产品图的使用权未说明，以下按内部概念稿拟写，公开或商业使用前需人工确认产品图权利。

#### 主提示词（首次编辑，可直接复制）

编辑图 1。图 1 是人物身份与待编辑基图；图 2 是羊绒大衣产品参考。本轮只把图 1 人物现有外套替换为图 2 的羊绒大衣，准确保留图 2 的颜色、长度、翻领、门襟、口袋、缝线和羊绒质感，并让衣物自然贴合图 1 的身体和姿态，形成合理褶皱、遮挡、接触阴影与环境色温。必须保持图 1 人物的脸型、五官比例、肤色、眼睛、眉毛、发际、发色、年龄、发型、表情、身体比例、姿态、手势、画面裁切、机位、背景和光线不变；不添加其他服装、配饰、文字、标志或人物。

#### 单变量修订指令（仅当衣领不符时）

继续编辑当前图像。本轮只把大衣衣领恢复为图 2 所示的翻领宽度、开口角度和缝线位置。保持人物身份、脸型与五官、肤色、发型、表情、身体比例、姿态、手势、其余大衣结构与颜色、构图、机位、背景、主光方向和综合色调不变；不要重画面容，不要新增或删除其他元素。

#### 生成参数

| 项目 | 建议值 | 说明 |
| --- | --- | --- |
| model | `gpt-image-2` | Image API edits |
| quality | `high` | 身份与产品结构均敏感 |
| size | 与图 1 构图相符的合法 `WIDTHxHEIGHT` 或 `auto` | Image API edits 当前支持灵活尺寸；像素不写入主提示词 |
| background | `opaque`／`auto` | 保持原背景 |

#### 质量检查

两张图角色单一且明确；首次编辑区分唯一改动与不变量，后续只修衣领；没有 `input_fidelity`、独立负面字段或“融合所有参考图”的含糊指令。

## 4. 自然观看现实感的居家游戏人像

### 输入

> GPT-Image-2：帅气年轻男性坐在明亮客厅沙发上横握手机玩手游，真实自然，像肉眼看到，不要手机屏幕贴图感和广告图库感。

### 输出

#### 需求理解与默认假设

- “像肉眼看到”按视觉线索自洽的真实生活照片处理，不使用固定人眼焦距、鱼眼、径向周边模糊或无限 HDR。
- 未指定调用界面，本例只输出自然语言主提示词；默认虚构成年人物和通用横屏手游界面。若必须精确复现某款游戏 UI，应另附可用截图并把它定义为屏幕内容参考。

#### 主提示词（可直接复制）

生成一张未经重度修饰的居家抓拍照片：明亮客厅里，一位虚构的年轻成年男性坐在布艺沙发前沿，身体自然前倾，双手横握手机并用拇指操作；他低头看向屏幕中心同一个物理点，双眼只有符合近距观看的轻微会聚，握持处有自然遮挡和指腹压力。相机位于人物肩外侧、接近坐姿眼高，屏幕主要朝向人物，相机只看到带真实透视缩短的斜向屏幕；左侧窗光为主光，玻璃保留随倾角变化的克制窗形反射，屏幕亮度服从白天环境。保留沙发压痕、自然衣褶和少量不完全对称，背景按偏离焦平面的程度自然变软，不做无菌广告布景。

#### 单变量修订指令（仅当显示内容未贴合屏幕透视时）

继续编辑当前图像。本轮只修复手机显示内容与现有屏幕平面的透视贴合：保留当前游戏内容不变，依据手机原有四角、边框、倾角和透视缩短，将显示内容准确限制在屏幕范围内，并让内容边缘受到现有边框与手指的正确遮挡。保持人物身份与注视、双手握姿、手机位置、朝向和机身、屏幕亮度、既有玻璃反射与使用痕迹、构图、焦平面、环境光及其他所有区域不变；本轮不修改反射、高光、指纹、游戏内容设计或整体清晰度。

#### 最小因果组修订指令（仅当双眼未落在同一屏幕点时）

继续编辑当前图像。本轮只修正近距注视几何：以屏幕中心现有位置为唯一物理目标，分别调整两眼虹膜在各自眼裂中的方向，使两条视轴以与观看距离相称的轻微会聚落在该点；同步调整必要的轻微眼睑和头位，只有屏幕朝向确实阻断观看时才联动最小倾角。保持人物身份、虹膜颜色、表情强度、面部比例、发型、身体姿态、手势、手机位置与尺寸、机位、构图、焦平面、客厅、光线和色彩不变；不要重画整张脸，不添加强眼神光，也不要夸张成斗鸡眼。

#### 质量检查

提示没有虚构固定“人眼参数”，只保留注视与握持、可信机位、屏幕玻璃和克制生活感四组高风险因果；显示内容错误用单变量修订，双眼分离则用最小注视因果组修订，不重画无关区域。

## 5. Image API 的 4K 产品文生图

### 输入

> 为虚构咖啡机做 3840×2160 横版电商头图，极简厨房晨光，目标 GPT-Image-2 Image API。

### 输出

#### 需求理解与默认假设

- 这是从零生成的产品资产；第一视觉是咖啡机，背景只承担使用场景。
- `3840x2160` 通过尺寸约束但总像素达到上限，属于实验性；“4K”进入参数和验收，不作为提示词品质词。

#### 主提示词（可直接复制）

为桌面端电商头图生成一张写实产品照片：一台无标志的虚构紧凑型咖啡机位于极简浅橡木厨房台面中央偏右，哑光暖灰机身、单一出液口、清晰水箱边界和金属接水盘结构完整，咖啡杯稳定置于出液口正下方，左侧保留干净文案安全区。清晨窗光从左前方形成柔和明暗过渡，保留金属、哑光塑料、陶瓷和木材各自的表面响应；产品轮廓、部件数量、颜色和标签区不漂移，不出现额外机器、人物、文字、标志或水印。

#### 生成参数

| 项目 | 建议值 | 说明 |
| --- | --- | --- |
| model | `gpt-image-2` | Image API generations |
| size | `3840x2160` | 合法 4K UHD 横图；实验性 |
| quality | `medium`／`high` 对照 | 以产品结构、边缘和材质硬门选择，不保证 high 必胜 |
| output_format | `jpeg`／`png` | 按后续制作需要选择；无透明背景 |
| background | `opaque` | 当前不支持透明背景 |

#### 质量检查

尺寸已通过 16 倍数、边长、比例和总像素校验；提示词未堆“8K／杰作”，下载后仍需确认实际像素、产品结构和文案安全区。
