# 独立与协作均可使用的图片提示词示例

输入：两名成年虚构角色在同一咖啡馆交换蓝色信封。先制作供身份、服装、场景和道具核对的参考图，画面时刻为A尚未把信封放下。这里输出提示词，不声称已生图。

提示词：写实自然光咖啡馆画面，两名成年虚构人物面对面坐在同一张木桌两侧。左侧A是短黑发成年男子，穿深蓝外套；右侧B是齐肩深色头发成年女子，穿米色衬衣。两人的脸、发型和服装都清晰可辨。A右手拿着一个蓝色信封，手和信封悬在桌面上方；B的手留在自己这一侧，视线落在信封上，还没有伸手接取。左侧窗户提供柔和日光，桌面纹理、衣服褶皱和手部接触可信，空间保持简单、没有第三个人。横向构图，摄像机在桌子同一侧拍到两人的侧前方和完整交接空间。保持人物分别位于画面左、右，不镜像反转；只有一个蓝色信封，不在信封或画面上生成文字、字幕、标志或水印。

约束检查：身份和衣服互不串换；右手属于A；B尚未接触信封；蓝色信封只有一个；机位能同时显示两人和关键手部；这张图仅作为该瞬间参考，不能替代完整交接动作。尺寸与图像模型参数由实际宿主能力决定。

协作时读取任务信封和ArtIR/画格切片，把允许改变与必须保持的内容写入prompt与checks。原文没有的新情节不作为提示词“优化”增加。
