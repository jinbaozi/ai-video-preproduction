# 真人、国漫、仙侠与混合媒介示例

以下均为原创提示词设计示例，未进行生图对照实验。用于 ChatGPT 非 API Image-2，不附 API 参数。默认单张，无文字；画幅可按用户用途调整。

## 真人感：竹窗人像

生成一张竖版写实半身照片。一名成年女性站在竹窗旁，柔和椭圆脸，深棕杏仁眼，黑栗色长发在后脑低束，人物左耳佩戴一枚不规则银耳坠。她穿灰青色亚麻交领上衣，指尖扶住窗框，视线落在窗外。相机与眼睛同高，人物位于画面右侧，左侧保留窗框和竹影；焦点落在靠近相机的眼睛。窗外柔光从画面左前方照入，鼻侧保留阴影；鼻翼有细小毛孔，嘴唇保留唇纹，面颊纹理柔和，额侧有两三根散发。黑栗发色只在受光边缘显出暖棕，衣袖褶皱由肘部弯曲形成。背景保持纵深，不添加磨皮光泽、颗粒滤镜或文字。

## 二维国漫：雨中执伞

生成一张竖版二维国漫插画，采用有轻重变化的墨线、简化色面和两级明暗，远景带水墨湿边。一名成年女剑客立在石桥上，长脸、平直眉、墨黑高马尾，暗朱红短披肩是主色锚点，腰间悬挂一枚缺角白玉环。她握着油纸伞，身体朝桥尽头，脸转向画面左侧的来人方向。伞缘构成上方弧线，桥栏引向远处城门；脸与持伞手保持可读。阴天冷灰环境中，披肩红色形成视觉中心；发丝用成组线条表现，皮肤保持绘画色面。湿痕仅在肩部与衣摆，桥面水迹反映人物色块，不添加摄影毛孔或三维塑料高光。

## 三维仙侠＋二维水墨特效

生成一张横版仙侠动画概念画面。主体是一名成年三维国漫女修，纤长成年比例、黑色高束发髻，银色半月发冠和靛青外袍构成身份锚点，内层为暖白丝衣。她站在残桥中央，右手持剑向下，左掌朝向画面左上方；略低机位的中远景呈现身体、剑与桥面。角色保持三维体积、织物厚度和接触阴影。左掌外侧形成一条二维手绘墨焰弧，根部浓墨、外缘水墨扩散，飞白位于笔触内部；一段从身后绕过，前景部分从袖口外侧掠过，不遮脸。墨焰只有朱红内缘发光，在指尖和白袖留下局部暖色反射。天空冷色柔光是主光，远处山门被分层薄雾隔开，桥石与门洞提供尺度。保留眼睛、手势与半月发冠的辨识度，不叠加胶片或VHS滤镜。

## 实拍底图＋CG角色（需要上传竹林照片）

以图1竹林照片为背景基图，在画面右侧空地加入一名成年三维国漫古风角色，保持背景相机视点和竹林结构。角色穿象牙白内衫、苔绿色外袍，黑发低束，人物右腰挂一只铜铃，左手扶住腰带。按图1可见太阳方向匹配人物亮面与投影；阴影软硬、肤色曝光、地面反射色和景深与基图一致，脚底接地，前景竹叶按原有深度遮挡人物边缘。只在基图已有逆光条件下延续叶隙光晕，不凭空增加第二个太阳。保留三维动画脸型和材质，不转成真人脸。仅修改放置角色所需的区域、接触影和必要遮挡。

若未上传图1，改成“生成摄影质感竹林背景”，删除实拍底图与保持原图的声明。

## 数字赛博＋模拟成像瑕疵

生成一张横版赛博复古叙事静帧，主体和街道采用数字三维渲染。一名成年信使站在雨棚下，黑色短发中有一束青蓝挑染，深灰机能夹克左胸有一枚橙色圆形扣件；她回头看向街道转角，半透明终端夹在右臂下。相机在胸口高度，以中景保留人物与街道纵深。冷青环境光配合转角霓虹的橙色侧光，雨棚下脸部曝光可读。成像层仅在暗部加入细密16mm风格颗粒，左下边缘保留一小片暖色漏光；VHS风格色度拖尾限于远处霓虹，底边有一条低强度水平跟踪干扰。高光溢出仅发生在霓虹灯芯，不覆盖眼睛、青蓝发束和橙色扣件。整体轮廓保持清晰，不全屏扫描线，不添加文字。

## 模块化骨架

任务／画幅：单张静态画面与用途。
主体层：一种主要媒介、角色、动作、识别锚点。
环境层：生成环境或指定实拍基图、空间深度、尺度与接触。
特效层（可选）：媒介、位置、形状、遮挡、是否发光及环境响应。
构图与光色：机位、景别、视觉中心、主光与必要辅光。
成像层（可选）：瑕疵类别、位置、强度、受保护细节。
约束：最相关的不变量与排除项。

不要将所有可选层自动填满；最高质量是界面能力范围内的目标，实际像素以原图为准。
