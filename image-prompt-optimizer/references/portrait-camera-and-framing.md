# 人像机位与视觉目标

用于人像机位、景别、取景和注意力控制；只补本次缺失或冲突的变量。来源及原文／延伸边界见 [来源记录](sources.md)。这些规则服务普通摄影意图，保留用户明确的风格化比例、特殊透视及多面板要求。

## 1. 先选视觉目标

| 第一观看目标 | 优先控制 | 降低权重 |
| --- | --- | --- |
| 身份与五官 | 面部占比、脸部朝向、遮挡、光照 | 环境复杂度 |
| 完整穿搭 | 头脚边界、衣服轮廓、肢体分离 | 毛孔、微表情 |
| 亲近感 | 目光、互动触发、观看位置 | 无关环境 |
| 动作 | 动作阶段、支撑点、手脚可见性 | 饰品细节 |
| 孤独或渺小 | 人物尺度、空间、留白 | 面部表情可读性 |
| 皮肤与妆容 | 面部近摄、光源面积、纹理尺度 | 全身与环境 |

全身中可辨浅笑，不等于看清泪珠或唇纹。若全身与局部放大同时被要求，按既定优先级让细节服从景别；用户允许多图时才拆成全身与独立特写。若两项都是不可让步的单幅要求，说明冲突并询问取舍，不擅自加局部面板或多交图片。

## 2. 七个空间变量分别排歧

| 变量 | 可执行表达 |
| --- | --- |
| 相机方位 | 相机位于人物自身左前方 |
| 相机高度 | 相机与坐姿人物胸部同高 |
| 镜头俯仰 | 镜头向下取景，纳入双脚 |
| 相机横滚 | 画面水平、门框竖直，或指定倾斜 |
| 躯干朝向 | 躯干朝画面右侧转约30° |
| 头部朝向 | 头部转回镜头方向 |
| 视线落点 | 双眼注视镜头 |

看镜头不等于正面脸，正面脸不等于正面身体，低机位不等于仰拍。高度优先用目标部位作参照，再按需要补离地数值；贴地机位与相对鞋部平视可以同时成立。高于面部且镜头水平与高于面部向下拍是两种条件。

“侧面”须区分人物自身侧别、画面方向和相机位置。严格侧脸可写可见身体一侧、鼻尖朝画面哪侧及仅一只眼可见；三分之四脸可写两眼可见、远侧面颊较窄。检查这些描述是否相容，不能为补字段随意指定左右。

## 3. 取景边界 → 人物占比 → 透视 → 焦段意图 → 必要距离

景别名称不对应跨体系统一的裁切线。用头顶至鞋底并留边、头顶至腰部且双手入镜、头顶至锁骨、眉毛至鼻梁上部等边界定义本次取景。人物占比同样是构图意图，须在成图后核验。

相机位置与物体空间关系决定透视；焦距与画幅决定视场。保持人物大小而换焦距，通常须移动相机，透视随之变化；镜头光学畸变另行区分。不要把85mm视为自然脸保证，也不要把同距离等同于同景别。

只有数值确实影响判断时才作粗估：理想直线投影、全画幅竖拍且传感器长边36mm垂直、目标平面垂直光轴时，垂直范围约为距离×36／焦距（统一焦距和传感器单位）。85mm、3m约覆盖1.27m，通常不足以容纳站立成人全身与留白。该估算不模拟模型，也不直接适用于倾斜、卧姿或不同画幅；距离未被用户锁定时让它服从完整取景，明确参数冲突时按已有优先级处理。

卧姿须明确身体展开方向、头脚位置、关节屈曲和抬脚边界。身体完整不代表站姿式竖向排列；狭长画幅与横向伸展竞争时可在允许范围内沿对角线安排，不以拉长肢体解决裁切。

## 4. 情绪必须有可见载体

- 面部：眉眼、嘴角、下颌；只描述景别可读的变化。
- 身体：肩背、手势与重心，例如手停在门把上。
- 空间：人物位于空旷站台一端，以尺度、距离和留白表达孤独。
- 互动：听见镜头后方的人叫她，手仍停在袖口，转头看镜头、嘴角出现笑意。写成一个瞬间，不串成多帧动作。

“男友视角”不确定高度、距离或透视，也不要求拍摄者身体入镜；单人合同可明确拍摄者在镜头后方。限制抢眼颜色、贴头灯具、高亮杂物等具体竞争元素，环境叙事所需内容仍保留。

## 5. 真实感与适用边界

先检查结构、接触承重、光向和材质，再补当前景别的纹理。趴卧可用胸腹、骨盆与大腿接触床垫、双肘支撑上身、一条小腿由膝部抬起且膝仍贴床；压陷、衣料压褶和阴影须对应实际接触，不给每处机械加痕迹。细则复用 [结构现实感](structural-realism.md) 与 [人像照片感](portrait-photo-realism.md)。

- 冷白皮可表达为中性偏冷的浅象牙肤色，局部保留血色与受光变化；不得覆盖已锁定肤色。
- 写实“九头身”可转为修长且头躯协调的比例意图，坐卧服从透视缩短；用户明确的风格化比例不擅改。
- 全身真实肤质不要求肉眼可见毛孔；不以噪点或新增皮肤标记代替真实感。
- 棉布哑光、丝缎沿褶面有亮带、头发方向性反光、皮肤区域差异，避免所有材质统一发亮。
- 成年人物的抽象气质用服饰、肩颈线条、目光和表情落地，不擅改年龄或造型。

画面要求（人数、裁切、动作、位置）、摄影意图（等效焦段、景深、快门效果）、工具设置（实际尺寸、质量、参考图）分层。相机数值不能证明真实采用了该设置；冻结动作写清楚部位，拖影指定运动对象，景深写焦点及前后清晰范围，肤色用光源与目标表达，不把色温当保证。

## 6. 按问题来源最小修订

| 可见问题 | 优先核对与改动 |
| --- | --- |
| 脸变形、腿夸张 | 距离、俯仰、脸部朝向 |
| 手脚过大 | 是否伸向镜头及前后距离 |
| 完整却缺少交流 | 脸部占比、视线、互动触发与背景竞争 |
| 裁脚或小腿 | 边界、留白、画幅、身体展开方向 |
| 趴卧悬浮 | 支撑点、接触面与反馈 |
| 背景像抠图 | 空间层次与景深连续性 |
| 皮肤蜡感 | 光线、局部色差、反光及过度修饰 |
| 改机位后身份漂移 | 锁身份、服装、动作，仅改机位及必需取景关系 |

这些是诊断候选，不是无图结论。单问题每轮只改一个主失败所需的最小因果组，保留已通过条件；多个获授权兼容修改仍完整处理。仅当入口已确认支持时保持参考图、随机种子等条件；随机差异仍可能存在，单次结果不能证明因果。
