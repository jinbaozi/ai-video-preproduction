# 构图与场景

在复杂空间、群像、构图选择或场景改编时读取。以下是设计启发式，不是审美定律。

先回答画面第一眼看什么、随后看什么、哪些区域应安静。用面积、明度差、色彩、边缘、清晰度和视线共同建立重点，不让每个主体都最高对比。暗色主体可依靠亮背景、轮廓或位置成为重点，不必总把主体照得最亮。

| 目的 | 可选构图 | 需要检查 |
| --- | --- | --- |
| 庄重、秩序、展示 | 中心、对称、正交、横排 | 轮廓可读、间距、裁切 |
| 动作与关系 | 对角线、三角群组、错位深度 | 动作空间、视线、接触归属 |
| 环境与尺度 | 小主体、大环境、前中后景、框景 | 尺度参照、主体仍可识别 |
| 文案或头像 | 负空间、集中主体、安全边距 | 实际裁切形状、文字背景复杂度 |
| 四视图或漫画 | 明确面板、阅读顺序、独立边界 | 数量、视角、跨格连续性 |

这些选择可交叉使用；中心构图不等于呆板，倾斜不等于动态，浅景深不等于高级。视线空间、头顶留白、关节裁切是可调整惯例，有意压迫、截断或失衡应保留。

场景只补会影响结果的条件：时间与天气、地形尺度、光源、风向、表面干湿、可用支撑。因果链采用事件→状态→可见证据：刚出水→发束聚拢和局部滴水；雨停后→地面反光但衣物未必湿透；寒冷室内不必有室外呼气白雾。不要给所有场景添加全部环境痕迹。

建筑检查重复结构、开口、地面支撑与尺度；自然景观检查前后层次及空气透视；微距按小尺度安排焦点；奇幻可指定局部物理例外，其余关系保持自洽。平面装饰、正交图和多视点绘画不套用单一摄影投影要求。

风格组合先选媒介，再选题材与视觉处理。水彩、厚涂、版画、线描、三维动画、摄影各自明确边缘、体积和纹理处理；不逐项堆词。混搭细则沿用 visual-anchor-styles.md，避免复制一套平行规则。
