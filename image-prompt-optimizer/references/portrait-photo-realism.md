# 真实人像照片感：参数与可见效果

仅在用户要求人像照片感、相机参数、皮肤真实性或摄影感修复时读取。沿用 photography-language.md 的机位、景深与曝光原则，不对其他媒介强加摄影纹理。

## 1. 先确定照片类型

区分生活抓拍、清晰穿搭、商业棚拍与复古成像。商业修饰、正式姿态和无颗粒均可真实；抓拍不是唯一标准。先写动作、光线、空间及材质证据，再按需要附参数。摄影常识支持这些视觉关系，不证明任何提示词对当前模型有固定增益。

## 2. 参数—可见效果映射

焦段以全画幅等效视角表述；光圈为景深意图示例，不声明等效曝光或通用配方。数值只在有助于表达或用户要求时添加。默认可为 0 项，通常保留 0—3 项数值线索；这是压缩策略，不是模型上限，不删除用户明确的参数。每项绑定取景、清晰区、运动或低光取舍中的一个可见目的。

| 信息 | 可见效果写法 | 限制 |
| --- | --- | --- |
| 焦段与距离 | 85mm 等效视角，保持拍摄距离，头肩构图，近侧五官不过度放大 | 先定距离与构图；不能仅凭焦段保证脸型 |
| 光圈与焦区 | 约 f/4 的景深观感，双眼及主要五官清楚，耳后和背景随深度变软 | 景深还取决于距离、放大率及观看条件 |
| 快门与运动 | 约 1/500 秒的动作冻结观感，面部清楚，发束保留动作形态 | 不保证所有速度的动作均冻结；静态任务可省略 |
| ISO 与低光 | 暗部允许细小亮度噪声，面部保留层次 | ISO 不是通用颗粒强度；噪声还受曝光、设备和处理影响 |
| 白平衡 | 以脸部肤色为基准，背景保留暖灯色和局部环境染色 | 不用固定 K 值承诺所有混合光都中性 |
| 对焦 | 焦点落在近侧眼睛，非重点发丝按深度变软 | 手部或产品为重点时改变焦点，不强制全锐 |
| 闪光 | 近轴直闪主导人物曝光，环境曝光保留背景灯轨 | 慢快门允许环境重影，保护五官而非承诺零重影 |
| 机位与景别 | 眼平半身，朋友交谈距离，背景仍可辨识 | 不把 50mm 等同固定人眼视角 |

示例参数不是生成接口字段，不输出虚构 camera、aperture 或 ISO API 参数。用户明确的相机数值不得为省字静默删除；互斥时按主技能澄清。相机型号可保留作语义线索，但不代替可见描述。

## 3. 景别与真实细节预算

| 景别 | 优先证据 | 不应机械添加 |
| --- | --- | --- |
| 面部特写 | 鼻翼与唇部纹理、局部色差、符合光源的高光 | 全脸同强度毛孔、满脸油亮、额外雀斑痘印 |
| 半身 | 五官总体、肤色层次、可见手部接触、衣物褶皱 | 不可见的汗毛与虹膜微结构 |
| 全身 | 头身关系、支撑腿、落脚、衣物重量和轮廓 | 可数毛孔、用拉长肢体制造修长 |
| 环境人像 | 人物与环境尺度、遮挡、接触、清晰度主次 | 每个区域同锐、过量面部微纹理 |

纹理还取决于输出观看尺寸、光线和修饰程度。真实不要求瑕疵；已有身份不擅加痣、皱纹、晒伤或年龄特征。高光应有位置、面积与光源依据，肤色应有层次，不以美白或全脸油膜替代。锐化不制造轮廓白边，虚化不按人物轮廓剪纸式切割。

动作写动机与受力：回应朋友转头、接杯、整理袖口；检查支撑脚、坐面接触、握持和布料受力。九头身与纪实比例存在风格张力而非必然冲突：保留用户时装意图，禁止结构错误；有明确互斥要求再澄清。

## 4. 证据不足的捷径

RAW、unedited 或“原图模式”可改写为“低修饰、保留原有肤色层次与局部纹理”的可见目标，不代表启用了模式或输出 RAW 文件；IMG_1234.JPG、DSC_0001 等文件名不作为已验证增益。8K、16K、masterpiece 不保证像素或结构。颗粒、漏光、失焦用于有意风格，不能修复错手、身份漂移或错误透视。无痕修饰与局部皮肤纹理可共存。负面约束只覆盖当前风险，不输出整页通用缺陷词。

遇到“破坏性词／烂镜头能去 AI 感”的建议，先恢复动作、光影体积、材质和局部纹理，再按用户选择考虑成像痕迹。已有身份不得为此擅加雀斑、痣、皱纹或脏污；现代商业人像也可保持干净清晰。只说“破坏性词／去 AI 味”不等于选择胶片或故障风格，默认不添加颗粒、色差、噪声或不均匀锐度；用户选定具体成像效果后才启用，位置与强度复用 [受控瑕疵](visual-anchor-styles.md#受控瑕疵)。

不要把“按原图模式”当执行指令，也不要把“去 AI 味”展开成整串未确认缺陷。未见原图且用户未指定具体问题时，按主技能明示一个保守假设，例如仅调整过度平滑的肤质；只围绕该假设与必要不变量写修订，不顺带纠正对称、视线或背景。

例如，未见原图且要求保持年龄、皮肤标记与妆面时，先说明“以下暂按肤质过度平滑处理，未确认原图存在此问题”，再给局部指令：“仅减轻皮肤过度平滑的观感，保留原有肤色层次和与景别相称的局部纹理。保持身份、年龄、全部皮肤标记、妆面、光线和构图不变，不添加颗粒或镜头特效。”不要在其后再补一组“轻微成像不完美”。

## 5. 增强档案与选择顺序

简单任务只保留相关字段；下列为内部编排记录，不是接口参数，也不要求逐字段展示。

| 字段 | 内容 |
| --- | --- |
| 操作与媒介 | 新生成／参考图引导／编辑；摄影类型；奇幻题材另行指定媒介 |
| 三项目标 | 成像可信、人物状态、场景与行为成立；记录当前重点，不要求三者等权 |
| 固定项与来源 | 身份、年龄、数量、造型、画幅、参考图职责及优先级 |
| 事件与人物 | 一个动作触发及可见瞬间、视线落点、入镜支撑和接触 |
| 成像 | 景别、机位、距离意图、清晰区、主光、曝光锚、必要环境光 |
| 材质与修饰 | 当前观看尺度可辨的肤质、头发、衣物、道具响应及修饰程度 |
| 重点与数值 | 最高风险的 2—4 组约束；可选数值及可见效果 |
| 证据状态 | 仅检查提示词／已检查结果图／已开展对照；记录判断限制 |

按用户合同（身份、数量、编辑范围等）→ 空间与身体结构 → 视线与接触 → 光照与景深 → 材质 → 调色与颗粒选择约束。此为诊断优先级，不强迫每张图经历完整清单；用户明确兼容改动仍全部保留。

- 人物行为用“触发 → 此刻动作 → 可见反应”设计，最终只表现一个时刻。眼神依赖落点、眼睑与头位；不靠增加虹膜锐度表达精神。闭眼、背面和墨镜用可见头颈、肩线与手势表达。
- 皮肤按区域、尺度、光线描述。妆面可遮盖部分色差，修饰可减弱瑕疵；身份不通过换脸型、增加年龄痕迹或改变肤色底调来增强。
- 布料、发束和身体连接：只描述当前动作产生的牵拉、堆褶、下垂与遮挡。硬椅不强加软垫压陷，不要求被遮住的支撑证据可见。
- 共享机位、光色和清晰度关系；具体因果复用 [自然观看现实感](natural-viewing-realism.md)，不另建重复规则。
- 生活痕迹要能解释活动；证件、广告与整洁棚拍不强制脏污、噪声或抓拍。手机照片不等于低画质。
- “真实人像摄影”足以表达中文媒介意图。photorealistic 是语义线索，不是确定性模式开关，不要求中英重复。

需要场景写法时读取 [场景预设](../presets/portrait-realism-profiles.md)。预设只补未指定项；对称抓拍、直视镜头、商业修饰与无颗粒不自动构成冲突。

## 6. 修订与验证入口

修订记录包含可见问题、置信度、允许改变、必须保持和验收证据。一处失败可联动最小因果组，例如视线、必要头位与屏幕倾角；皮肤油亮不应连带换脸、换妆、换光位或重构背景。用户要求多个兼容改动时全部列入合同；分轮仅为控制漂移或处理因果依赖，不作为强制限制。

只有要求评价或实验才读取 [真实感评价与实验](realism-evaluation.md)，该文件维护 A/B/C、评分和证据记录。技能只输出实验提示与评价标准，生成由获授权的生图流程完成。没有图片只检查文本约束，不声称视觉通过或参数增益已验证。
