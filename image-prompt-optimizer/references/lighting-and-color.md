# 布光与色彩

在棚拍、多灯、混合色温、电影调色或胶片质感任务中完整读取本文件。

## 1. 先建立光线因果

按以下顺序设计：环境光基底 → 主光方向与软硬 → 阴影深度 → 是否需要辅光或负补光 → 是否需要轮廓分离 → 眼神光与背景亮度。

- **主光**：定义脸部形状、明暗方向和基调。先写它，再写其他光。
- **辅光**：弱于主光，只抬起阴影；不要抹掉主光塑形。
- **负补光**：用黑旗或暗面吸光，加深背光侧，提升轮廓和对比。
- **轮廓光**：从后侧勾勒头发、肩线或材质；只在主体与背景需要分离时加入，避免无缘由整圈发光。
- **柔硬度**：大且靠近的光源过渡更柔；小或远的光源阴影边缘更硬。

将光源方向、相对尺寸／阴影软硬、覆盖范围／明暗关系分开描述。侧光可以很柔，柔光也可以有明显明暗体积；硬光会强调皮肤起伏，但不必然更真实。不因“降低 AI 感”自动替换用户指定的柔光或均匀商业布光。

眼神光的位置、数量和形状必须能由实际光源解释。单一窗光不要生成多个方向无关的环形眼神光。

反射也要回溯到具体光源与表面朝向：窗形高光随玻璃／屏幕倾角发生透视变化，金属高光随曲率移动，接触阴影贴附在实际受力位置。白天明亮环境中的手机屏幕通常不应成为照亮整张脸的强霓虹主光；只有低光且屏幕足够明亮时，才在手指、下颌或眼中保留克制色光。

## 2. 可执行布光方案

### 自然窗光

人物左前方的大窗作柔和主光，右侧白墙或反光板轻微回填，保留鼻侧与颧骨层次；背景比人物略暗，无独立轮廓光。适合生活方式、自然表情和编辑肖像。

### 干净商业棚拍

相机左前方大型八角柔光箱作主光；相机右侧低强度柔光回填；背景独立均匀照明；仅在深色服装与背景接近时，从右后方用窄条柔光形成受控肩发轮廓。适合护肤、美妆和服装广告。

### 戏剧性侧光

高位侧前方硬质主光形成清晰阴影；背光侧使用负补光增强明暗；背景保持简洁，仅在轮廓丢失时加窄后侧光。适合有力量的编辑或叙事人像。

### 直闪快照

仅在用户选择直闪或相应快照风格时采用。近轴机顶直闪可以造成正面较平的面部明暗、局部反光和背景硬阴影，不承诺更立体或更真实。若需要侧向塑形，明确离机闪光的位置；不把同一盏灯同时写成近轴正面与强侧向主光。慢快门与闪光组合时分别描述闪光主导的人物曝光和环境光形成的拖影，不保证零重影。

直闪与硬侧光都应检查曝光锚、鼻影／背景投影、眼神光和肤色高光是否相容。用户要求辨认五官、肤色或衣料时保护对应细节；有意高光溢出或深阴影仍按原风格保留，不把整幅图改成均匀硬光。

### 环境混合光

窗外冷日光作为空间环境色或人物主光，室内暖色实用灯作为可见点缀。自然可用光模式下，人物的回填必须来自可解释的白墙、地面或明确反光板，并弱于主光；不得为维持肤色凭空加入无来源的正面柔光。明确哪种光支配人物、哪种光只负责环境。

## 3. 色温与综合色调

先确认光源与白平衡，再做风格化调色：

1. 确定日光、钨丝灯、闪光或有意混合光。
2. 决定人物肤色是中性准确、略暖还是刻意偏色。
3. 分别描述阴影、中间调和高光。
4. 最后添加曲线、颗粒、晕影、辉光或柔化。

不要把“高色温”简单等同于暖画面；白平衡会改变最终色偏。混合色温必须说明动机和优先级。

## 4. 配色与调色表达

- **自然纪实**：中性肤色、克制饱和度、柔和反差、保留环境光色；不加重度色偏。
- **高端商业**：限制为 2—3 个主色角色，肤色准确，背景和服装形成明确明度分层，高光干净不过曝。
- **青暖分离**：阴影轻微偏青、高光略暖、肤色保持自然；不要把皮肤强推成橙色。
- **柔和胶片质感**：柔和高光滚降、略抬黑位、适度降低数码锐利感、细腻均匀颗粒。
- **硬朗编辑感**：更明确的局部对比与结构光，但保留肤色层次和衣料纹理。

滤镜、胶片或后期风格只写可见结果。除非用户需要真实胶片流程，不要用胶片型号当作无法解释的“魔法词”。

## 5. 光色冲突表

| 冲突 | 修正 |
| --- | --- |
| 单灯布光，又列独立主、辅、轮廓三灯 | 改为单灯加反光板，或明确是三灯方案 |
| 已明确只有漫射窗光，却要求硬鼻影 | 澄清是否有直射太阳或其他硬光；大窗本身不排除硬影 |
| 无阴影平光，同时要求强烈明暗对比 | 选择干净平光或戏剧性侧光 |
| 纯剪影，同时要求面部肤色和五官均匀可见 | 改为背光肖像并增加前方补光 |
| 暖钨丝灯、中性肤色，但不说明白平衡或补光 | 指定以肤色为白平衡，或用中性主光照人物 |
| 干净画面，同时要求明显颗粒 | 保留指定颗粒并减少异常彩斑／块纹；仅在同一区域明确要求零颗粒且明显颗粒、又无优先级时澄清 |
| 柔和高光与 HDR、零颗粒并存 | 分别描述曲线和纹理；仅当同一区域要求互斥结果时澄清 |


## 6. 光线层级与材质响应

先定观者需要读到的体积与信息，再选择布光。低调不等于整图欠曝，高调不等于丢失所有高光；允许有意剪影、纯白背景或局部溢出，保护任务要求的身份、标签与材质细节。数字光比仅在用户要求可执行实拍方案时按测量定义说明，不编造模型控制值。

光源软硬由相对可见尺寸及传播条件共同决定，方向、强度和软硬是不同维度。大窗也可能同时透入直射太阳形成硬影，不能把“大窗”与“硬影”直接判为矛盾。光源可以在画外，不要求照片里出现灯具；自然可用光场景仍须有合理来源。

区分固有颜色、照明色偏和最终调色。保护肤色不等于抹除全部环境染色；品牌产品色应明确在哪种呈现条件下保持。轮廓分离也可用背景明暗、色彩与景深完成，不必增加轮廓灯。

材质写与光相关的证据：哑光织物呈宽缓明暗，丝缎随褶皱产生方向性高光，金属反射环境，玻璃同时有透射和反射。潮湿可改变粗糙度、反光和局部深浅，但不自动透明；复合表面允许哑光基底和局部镜面水珠共存。

柔和高光滚降、颗粒、抬黑、漏光是独立可选处理，非所有胶片共有特征。HDR 不必导致光晕或夸张色彩。不要将未采用颗粒或不同曲线直接判为媒介错误。

上述规则来自摄影因果推导，不是直闪或硬光对 image_gen 有固定增益的结论；依据见 [来源记录](sources.md#2026-09-12去噪真人感与受控成像)。
