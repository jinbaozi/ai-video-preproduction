# ChatGPT 清晰度与 Astra 编排

默认由 Astra 理解需求、整理视觉合同、输出中文提示词，供 ChatGPT Image-2 生成。本技能不执行生图。此分工是设计约定，不代表已证实的 Astra 专属增益。

## 非 API 清晰度

- 降噪、模糊、渲染质量或分辨率任务按需读取 [ChatGPT 图片质量](chatgpt-image-quality.md)。不把这里的 Image-2 工作流名称当成当前界面实际模型证明；用户未指定版本时称 ChatGPT Images，只有涉及具体版本能力时才核对当前官方说明。
- 不强制 4K、8K、固定像素或隐藏质量档位。输出画幅意图；仅当前界面明确暴露选项时才建议最高质量，不编造按钮。
- “最高可用清晰度”是用户目标，不能保证自然语言会改变服务端尺寸。不得在聊天提示词后附 size、quality=high、seed、CFG 等伪设置。
- 像素数量与有效细节分开：主体占比、焦点、纹理尺度、曝光和边缘有助于视觉清晰度；全画面锐化、颗粒和后期放大不等于原生细节。
- 只有取得原始文件并读取宽高，才报告实际像素。区分预览、下载原图、用户目标、后期放大；未取得文件不声称分辨率验收通过。
- 用户坚持精确像素但不用 API：保留期望并解释控制边界，不能用 API 尺寸合法性证明聊天端可达。API 任务才加载尺寸表、重新核验并运行相应脚本。

## 编排

先用一句话说明计划，然后执行：提取硬要求 → 选主体媒介与视觉中心 → 分配空间、材质和光照 → 消除冲突 → 输出自足提示词。无需展示内部思维链。

主体身份与数量、空间动作、媒介、视觉重点、装饰依次检查。明确的同级冲突需要澄清；普通缺口作可调整默认。简单任务输出短提示，复杂角色或混合媒介才分段。用户只要提示词时省略计划、解释和检查块。

编写提示词可检查合同一致性，未生成图片不能写“视觉验收通过”。已有结果优先修一个主要失败或相关因果组，锁定其余已通过内容。
