# ChatGPT 图片质量：非 API 分支

只优化 ChatGPT 界面的生成／修订提示词与检查方法，不执行生图、降噪、锐化、放大或下载操作。不要因清晰度诉求切换到 API、安装软件或外部后处理。具体按钮、模型版本和界面能力需核验当前官方说明；不固定界面背后的模型名。

## 1. 判断问题与证据

先确定媒介、操作模式、用户要改变和保留的内容。没有结果图只给预防性描述或修订候选，不认定缺陷原因；只有缩略图时不能判断像素级噪声。清晰原图也未必能证明缺陷来自压缩还是生成，应区分可见现象和原因假设。

| 现象 | 检查与处理方向 | 必须保护 |
| --- | --- | --- |
| 彩色斑点、暗部杂纹 | 减少异常彩斑和成团纹理，不把所有肤色变化当色噪 | 暗部层次、环境色与局部肤色差异 |
| 灰度颗粒、指定胶片颗粒 | 区分非意图的亮度噪声与指定颗粒；单凭外观不判定来源 | 指定颗粒的尺度和强度；未指定时不主动添加 |
| 纸纹、笔触、织纹 | 属于媒介／材质细节，不能统一当噪点删除 | 原媒介、纹理方向与观看尺度 |
| 方块、渐变断层 | 描述块纹减少、渐变连续；不凭外观断言文件压缩原因 | 正常色彩过渡和物体边界 |
| 边缘白线、黑线 | 区分锐化光晕与真实轮廓光／插画描边，只修异常边缘 | 正常轮廓、发束与指定描边 |
| 模糊、锯齿 | 区分预览缩放、失焦、运动、低像素和细节尺度；不默认全图锐化 | 原有焦区、景深和指定运动模糊 |
| 塑料皮肤、假毛孔 | 恢复局部色差、纹理与光照体积，不追加满脸微细节 | 身份、年龄、妆面和原有皮肤特征 |
| 手指、五官、物体或文字错误 | 结构／语义问题，沿用编辑合同修订，不能用降噪或清晰化代替 | 主体关系、构图与编辑范围 |

“不要噪点”默认减少非意图的颗粒和杂纹，保留自然材质。若同时指定胶片颗粒，则按“保留指定颗粒、去除异常彩斑／块纹”解释并简述；只有明确要求同一区域既零颗粒又明显颗粒，且没有优先级时才澄清。

数字亮度噪声、色度噪声、胶片颗粒与毛孔不是同一种细节。数字噪声受曝光、设备和处理影响，不能只凭 ISO 推导；不要以添加颗粒修复塑料肤质，也不要以整体磨皮消除彩斑。保留用户指定纹理不等于额外增强它。相关摄影依据与提示策略的证据边界见 [来源记录](sources.md#2026-09-12去噪真人感与受控成像)。

## 2. 编排与细节预算

按任务选择最高风险的 2—4 组约束，不把本表全量加入提示词。新生成用可见目标；已有图用变更—保留—融合合同。清洁描述不是已验证降噪开关。

- 降噪与纹理保护成对写：减少背景暗部彩色杂点，同时保留肤色层次、衣物织纹或指定笔触。
- 复用 [人像照片感](portrait-photo-realism.md) 的景别预算：特写保留可见唇纹／鼻翼，半身优先五官层次和服装，全身优先姿态、轮廓与接触；不要添加不可见的毛孔。
- 清晰区服从焦平面、运动与原始风格，不要求所有区域同锐；不改变原有背景虚化来满足“高清”。插画可采用自身的清晰度逻辑，不强加摄影景深。
- 低光任务保护黑位与阴影层次，不为了去噪提亮整个夜景；保留用户要求的环境色、灯轨和运动模糊。
- 不自动添加 ISO、镜头型号或“8K、极致锐利”作为增强。用户指定摄影数值沿用参数—可见效果映射，不静默删减。
- 只需场景例句时读取 [清洁渲染预设](../presets/clean-render-profiles.md)。保持原媒介、身份、数量、造型和构图。

## 3. 非 API 分辨率合同

仅在用户要求像素或交付规格时输出以下状态，不要求每条普通提示词附表：

| 字段 | 记录方式 |
| --- | --- |
| 目标画幅 | 用户要求的比例／方向，不作隐藏尺寸控制 |
| 交付用途 | 观看尺度、裁切安全区和必须可辨的结构 |
| 目标像素 | 原样保留用户请求，标明目标而非已实现 |
| 实际像素 | 只有取得原文件并读取宽高才填写；否则“待下载原文件核验” |

不给聊天提示词添加 size、quality、denoise、CFG、steps、seed 或采样器设置，不调用 API 尺寸校验推断聊天端能力。不把 RAW、PNG 或无损描述当作文件格式事实。目标像素不在聊天端暴露时仍给可用的画幅与构图提示词，不以此阻断全部成稿。

区分预览图、下载原文件和后期放大图。文件宽高达到目标只说明像素达标，不证明有效细节或原生生成过程；来源过程未知时不得称“原生 4K”。

## 4. 局部修订

单问题修一个主失败或其最小因果组；用户指定多个兼容改动时全部列入，不强制拆轮。保留身份、姿态、构图、光位、景深与用户指定纹理，逐任务选必要不变量，不保证选区外像素绝对不变。若修订后身份漂移，建议从原图重新提出限定范围的请求。

候选写法（有证据或用户明确指定对应缺陷时用）：

```text
只减少背景暗部的彩色斑点和块状杂纹，保留原有亮度、色彩过渡与虚化。保持人物身份、五官、皮肤纹理、发丝、姿态、服装、构图和光线不变，不增加全局锐化；修复边缘与人物轮廓、背景物体自然衔接。
```

## 5. 输出与核验

遵守主技能输出合同，普通请求只给短提示词和必要检查句；内部分类、档案字段不全量展示。仅诊断／方案请求增加问题分级与增强项，精确尺寸请求增加目标／实际状态。只返回提示词的请求不附解释，不在提示词中承诺生成结果。

无图只检查文本约束，有图才判断视觉缺陷，有原文件才核验像素。评价沿用 [真实感评价与实验](realism-evaluation.md) 的硬门、证据与 N/A 规则；非摄影作品不套摄影真实感评分。只给验收建议不等于已执行图像验收。

这些规则是面向提示词的工程建议，未完成本技能生图对照，不承诺固定增益。需查询界面现行能力时从 [ChatGPT 图像帮助](https://help.openai.com/en/articles/11084440-images-in-chatgpt) 核对；摄影表达方法参考 [OpenAI 图像提示指南](https://developers.openai.com/cookbook/examples/multimodal/image-gen-models-prompting-guide)，不得把其中接口示例复制成聊天设置。
