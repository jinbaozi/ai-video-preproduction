# 真实感评价与实验

仅在用户要求评分、比较或参数实验时加载。没有结果图只检查提示词约束；技能不执行生图，实验提示交给获授权的生成流程。不以主观评分鉴定照片来源或提供“真实概率”。

## 1. 硬门与观察尺度

先检查主体数量、用户要求的身份保持、关键服饰与道具、文字和编辑范围。失败不能被美观或总分抵消；身份只比较可见参考特征，不作生物识别认证。先看整图的比例、空间和光照，再在原始分辨率允许时看局部；插值放大不能创造证据。

## 2. 评分卡

各项 0—3 分：0 为明确失败，1 为问题可见，2 为满足当前用途，3 为证据完整且表现可信。无法判断记 N/A，注明遮挡、分辨率或缺少参考，不记为 0。每项附可见证据和置信度；仅比较同类用途，不跨证件、抓拍、插画计算统一排名。

| 维度 | 可见证据 |
| --- | --- |
| 人物状态 | 视线、表情、头颈、动作是否一致 |
| 身体与接触 | 重心、承重、手物归属、遮挡 |
| 空间与成像 | 比例、透视、清晰区、失焦与边缘；指定成像痕迹的位置、成因及对主体可读性的影响 |
| 光照与材质 | 主光、阴影、肤色、高光、布料、反射；纹理是否局部自然，是否出现过度磨皮或锐化 |
| 场景可信度 | 动作原因、道具用途、是否符合拍摄类型 |

分级诊断与局部修订复用 [自然观看现实感](natural-viewing-realism.md)。把确定问题、疑似问题、可合理解释和分辨率不足分开记录；低置信项不作为重画身份的理由。

## 3. 参数收益对照

仅用户要求实验或参数评估时编写：A 为主体、场景、动作；B 为 A 加可见摄影效果；C 为 B 加对应数值。A/B 观察摄影描述，B/C 观察数值附加价值。局部修正版单列 D，评价修复收益，不混入参数效果判断。

固定身份约束、构图、画幅、参考图、实际可控模型与设置；界面没有模型快照或 seed 时记未知，不编造。接口支持 seed 才使用；相同 seed 在不同文本下也不保证完全可比。不要为追求控制而改变用户指定产品或擅用外部收费服务。

各组样本数相同，随机顺序盲评全部样本，记录硬门通过数、评分分布、身份漂移及波动，不只展示最佳样本。每组 4 张可以是资源允许时的探索起点，不是统计保证。小样本只作探索结论，不从单模型单场景推导普遍增益。C 未稳定优于 B 时不把数值加入默认模板。

评估“皮肤、光线、镜头瑕疵”三类建议时，在 A/B 层单独做消融，不改写 C 的数值对照含义：每个候选均从同一 A 出发，只增加一类描述；需要时另列组合版。原有主体、事件和风格不变，清晰度约束也不随组变化。不把同时改变灯光、肤质和颗粒的组间差异归功于某一个词。

编写完整组间提示后做差异检查：公共基线不含“禁止眩光”这类与待测增量互斥的限制；眩光需要的强光源先作为各组共享场景条件，不只在瑕疵组新增光源。B 已写明取景距离、清晰区或运动效果时，C 只补对应数值，不同时新增“更远距离／背景更虚”等视觉要求。未提供固定身份参照时，不声称跨次新生成是同一人，身份保持记 N/A；仍可检查各图是否遵从已给人物约束。

可按下面的最小矩阵展开，不必列一整套曝光参数：

| 场景／组 | 编排 |
| --- | --- |
| 场景 P：干净商业人像 | 公共文本 A-P 锁成年虚构人物、姿态、半身构图、观看距离和大窗柔光，主要五官清楚，背景按深度渐软；不加镜头瑕疵组 |
| 场景 F：逆光生活人像 | 公共文本 A-F 锁人物、姿态、构图、距离与清晰区，固定右后方强光源和脸部可辨的回填；不写禁止眩光 |
| 两个场景各自的 B-皮肤／B-光线 | 分别从对应 A 出发，仅追加局部肤质或既定主光的明暗层次，不改变其他轴 |
| 场景 F 的 B-眩光 | 从 A-F 出发，仅追加强光源相关的局部低强度眩光及脸部保护，不新增光源 |
| 每个场景的 C | 逐字复用对应 B-皮肤，只追加“约 f/4 的景深观感”；其他焦点、距离和模糊要求已经在 B 内，不重复增改 |

该例共 9 组，若每组 4 张则共 36 张，可按预算调整等量样本数；场景分别评分。其他数值另开对照，并绑定 B 已有的可见效果，静态明亮场景不装饰性追加快门或 ISO。这是保持差异可解释的文本示例，不保证真实光圈模拟。

若改用基准图编辑，所有组包括无增强对照都从同一基图、同样编辑轮数开始，不能拿一张原始基图与多张编辑结果直接比较。记录为编辑收益实验，局部修订按 D 组单列，不把生成与编辑、单图与多样本混在同一参数收益结论中。

至少包含干净商业人像与符合瑕疵风格的场景，分别报告结果，不将粗糙纪实偏好当通用真人感。先报告硬门通过数，再给各维度分布／中位数及负面变化；评价低噪收益时复用第 5 节，不以更强颗粒换来的风格偏好抵消噪声增加。无固定快照或 seed 的生成标为探索性对照，不称严格同随机条件。

## 4. 证据记录

结构审查另按需记录：主体／区域、直接观察、约束关系、替代解释、证据是否与其他异常共因、允许修订范围。跨图任务注明参考图索引与可比视角／造型条件；文件来源缺失与细节不可辨均不计缺陷分。维度细则见 [结构与物理自洽](structural-realism.md)。

使用字段：任务编号、日期、原始要求、提示词版本、实际可见模型／界面信息、参考图职责、可控设置、图片编号、硬门结果、各项分数／N/A、可见证据、置信度、修改项、判断限制与结论。未知值写未知。

评价一条增强建议的依据时，另标明“官方明确示例／摄影因果推导／待生图实测”，并链接相应来源；官方示例不等于增益证明，摄影原理不等于生成参数。真人感评分衡量视觉可信度，不报告 AI 概率；人类判断和检测器均有局限，旧 GAN 的眼神光或纹理规律不直接外推当前 image_gen。相关研究见 [来源记录](sources.md#2026-09-12去噪真人感与受控成像)。

修订另记允许改变、必须保持、依赖项与下一轮验收证据。记录结构或文本检查通过，不代表图像效果通过；未开展实验不得声称增益已验证。

## 5. ChatGPT 非 API 清晰度评价

仅清晰度任务加下表；插画保留原媒介，不用摄影真实感统一排名。继续按 0—3／N/A 评分，缺原文件或观察分辨率不足记 N/A，不记失败。主体、结构、身份和编辑范围先作为硬门；文件宽高作为单独事实记录，不混入审美平均分。

| 检查项 | 验收证据 |
| --- | --- |
| 噪声与颗粒 | 异常彩斑、成团杂纹减少，指定颗粒仍保留 |
| 渐变与边缘 | 条带、块纹、锐化白边减少，正常描边与轮廓光未被删除 |
| 纹理 | 皮肤／织物未磨平，未新增假毛孔；插画笔触、纸纹保留 |
| 光色与焦区 | 夜景曝光、环境色、原有景深和指定运动模糊未漂移 |
| 文件事实 | 目标画幅／像素、实际宽高、格式及原图／预览／后期放大来源；未知写待核验 |

清晰度 A/B 仅改变候选清洁约束，保持主体、构图、媒介、参考图与实际可控界面选项相同；采用前述等量多样本和盲评方法。无 seed／固定快照时如实记录，不能声称严格受控。局部修订另评收益和漂移；未生成不宣称降噪增益，达到像素目标不等于有效细节或原生过程已证明。
