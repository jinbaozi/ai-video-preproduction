# 三维空间、表演与静态叙事

复杂互动、人物表情、动作、台词或连续画面任务读取。与 [构图与场景](composition-and-scene.md)、[机位](portrait-camera-and-framing.md) 共用规则；以下补充关系和表演，不要求所有任务填写全部细节。

## 空间与人物对应

先建立实体 ID：人物、道具、支撑物及需要参与关系的场景锚点。逐帧建立关系，不用“她在他旁边”承载多个可能归属。坐标默认以观察者画面为准：左/右是画面左右，近/远是到相机的相对深度；人物自身左手/右手另行说明。只有确实有测量或用户要求时才给米数或数值坐标。

一条空间关系至少包含：谁 → 与谁/什么 → 何种关系 → 哪一帧 → 哪个坐标系。区分 `left_of`、`in_front_of`、`occludes`、`looks_at`、`touches`、`supports`、`holds`。位置不等于朝向；头部朝向不等于目光；屏幕的可见面不等于人物注视面。前景主体不必遮挡后景；投影重叠才能出现遮挡。镜子中的映像应有独立 ID 并标记映像，不算新增真人。

空间自检：同一坐标系内 A 左于 B、B 左于 C、C 左于 A 是循环；同帧互相完全遮挡不成立。数值未知时只写定性层次，不从一张透视图反推出真实厘米数。奇幻、镜面、拼贴等例外需先标明，不能无条件套用普通空间规则。

人物自身坐标使用 `coordinate_owner` 指明以谁为基准。`occludes` 只表示局部遮挡，交错肢体可能相互遮挡；只有 `fully_occludes` 才参与完全遮挡循环检查，不能误报普通拥抱或交叉手臂。

每个人绑定身份/服装/道具/站位/深度/姿态/手部/视线。多人同色服装允许存在，但不得串脸、串衣、把 A 手中的物品交给 B。桌沿、椅子、地面、门框等作为空间锚点，使站位与场景对应。脚底/坐骨/扶手等支点承担重心；握持位置、物体重力方向、衣褶和接触阴影相互支持。

## 表情与微表情

按“刺激或语境 → 主情绪 → 次级张力 → 可见信号 → 动作时刻”组织。不是每幅都添加复杂心理。静态图只能呈现某个瞬间，不能宣称记录毫秒级微表情过程，不能仅凭表情判定真实心理。

| 景别 | 优先写入正文的表现 | 避免 |
| --- | --- | --- |
| 面部特写 | 视线落点、上/下眼睑张力、眉内侧、唇线、口角、下颌；选 2—4 个关联信号 | 同时大哭大笑、闭眼又瞳孔清晰、每块肌肉都活动 |
| 半身 | 可读眉眼/口角、肩颈、手势、躯干倾向及呼吸造成的姿态 | 全部细毛与虹膜纹理挤占动作描述 |
| 全身/远景 | 重心、头部方向、步态、手臂轮廓、人与环境距离 | 以肉眼不可见的眼角变化作为唯一情绪证据 |

“委屈但忍住”可转为：视线落在对方肩侧、眉内侧轻收、下唇轻压、下颌绷住，手仍稳握物件。此为可选表达，不能强加哭泣、眼泪、伤痕或新的事件。对照参考人物时保留年龄、皮肤标记、妆容和稳定面部结构；表情张力不能变成整容。

## 动作与连续性

单幅选一个动作阶段：准备、接触、发力、释放或余势。写清主动者、目标、作用方向、支撑/发力点、当前接触及结果状态。例如“正在接杯”应定义谁仍承重、谁已触碰杯柄；不能同帧既杯在桌上又已经喝完。

连作/漫画按帧记录 `before → moment → after` 作为上下文，真正画出的只有 `moment`。相邻帧检查前帧结束与后帧开始一致：人物进出位置、持物手、衣物状态、朝向、视线、道具损耗、光线时间和运动轴。跨轴或跳时可以是有意镜头表达，需显式标记转换，不能靠随机换边完成。

镜头表达先选叙事目的，再定景别、取景边界、相机距离/高度、俯仰/滚转、人物深度和清晰区。低机位不自动意味着仰拍，侧脸不代表身体也侧身。单张图的“推近/跟拍”应转为运动中的取景或模糊意图；不能承诺真实运镜或时间时长。

## 台词、心理活动、旁白

每段文字保留原文、来源、说话人/心理主体、帧 ID 与通道：

- `visible`：用户明确要求的对白气泡、内心框、旁白框或画内标牌。精确文本、布局区域、尾线指向和阅读顺序一起锁定。对白可复制记录采用 `说话人：“台词内容”`；渲染气泡内容是否带姓名由用户版式决定。
- `context_only`：仅指导表演和情境，不能变成字幕、标签或画面中文字。语气/语速/停顿属于叙事上下文，静态照片不输出音频。

心理活动转换为可见姿态和张力时，不新增未授权情节，也不要求“画出她在回忆什么”，除非用户明确要回忆画面/蒙太奇。旁白不是角色开口，内心独白不是普通对白；旁白允许无角色 speaker，其他角色话语需绑定实体。

示例：原文 A：“我没事。”，上下文是 A 隐忍。照片提示词表达 A 唇线刚闭合、视线避开 B、握杯仍稳定；不自动画上“我没事”。若用户要漫画气泡，则文字精确为“我没事。”，尾线指向 A，B 不抢台词。

需要完整成稿时读取 [叙事与后端示例](../examples/narrative-and-backends.md)，包含单幅心理转译、三格持杯连续动作与同意图跨模型编译。
