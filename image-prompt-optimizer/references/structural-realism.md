# 结构与物理自洽：真人感与现实感

用于写实生成提示词、已有图缺陷诊断和系列一致性检查，继续采用 ChatGPT 非 API 路径。只优化提示词与评价，不生成或修改图像，不扩展为 AI 来源鉴定、检测器规避或元数据伪装。结构异常支持“该处需检查”，不证明整图由 AI 生成；符合物理也不证明来源真实。

## 1. 分层处理

保留主技能的用户合同与媒介优先级。内部按“结构与归属 → 支撑与空间 → 光照与反射 → 材质与成像 → 风格”排查；只把最高风险的 2—4 组写入成稿。用户只要求局部降噪时不擅自重画人体，另指出范围外问题即可。非摄影、超现实、有意合成和特殊投影保留创作意图，不用自然摄影规则强制纠正。

新生成：从动作／空间推导风险并写目标状态，不假称已发现缺陷。已有图：先整图，后在原始像素允许时检查局部，记录观察与替代解释，再选择修订。系列：只比较同一身份在可比视角、光照、年龄和造型条件下的可见特征。

## 2. 检查维度与生成约束

| 维度 | 何时检查、如何转写 | 正常解释与保护边界 |
| --- | --- | --- |
| 解剖与肢体归属 | 肩肘腕、髋膝踝形成可追踪连接；多人注明手脚归属，手指围绕指定握点弯曲 | 遮挡、透视缩短、先天差异、截肢或辅助器具不是生成错误；不要求十指全部可见，不抹除参考身体特征 |
| 面部与眼睛 | 五官体积与头位一致；双眼有共同注视目标，近侧与远侧遵守透视；牙齿仅在可见时检查 | 自然不对称、美妆、牙齿差异可成立；对称或相似眼神光不单独构成异常，不为真实感改变脸型 |
| 皮肤 | 局部色差、明暗体积与景别相称的纹理，亮斑面积服从光源 | 妆面、商业修饰、年龄与低分辨率影响可见纹理；不强加痣、皱纹、瑕疵或美白 |
| 发丝与交界 | 发束从发际线延续，耳、衣领、配饰与头发前后遮挡可追踪 | 细发可因失焦、逆光或曝光消失；不强制每根发丝清楚，不抹除正常轮廓光 |
| 姿势与接触 | 明确支撑点、承重方向、接触范围，衣料与软面形变对应受力 | 硬椅无需凹陷；软床形变取决于软硬、受力与可见性；指腹压痕或接触阴影未必可辨；跳跃等瞬间可离地 |
| 场景几何 | 床沿、桌腿、门框等连接连续；同方向平行线在共同机位下形成相容投影 | 不同方向直线可有不同消失点，非所有线汇聚一点；曲面、镜头畸变、滚动快门与设计造型需考虑 |
| 光影 | 建立主光与必要环境光，每处阴影和高光能由光源、表面及遮挡解释 | 多光源可产生不同方向阴影；接触阴影不必处处黑边；不强迫所有受光面同亮 |
| 镜面、玻璃与液体 | 反射物与位置、遮挡和表面方向对应；杯壁厚度、液面、容器边界与折射可解释 | 镜像视域可包含画外物，相机未入镜不等于错误；弯曲镜面、水波、减反射、偏振与折射可改变内容 |
| 文字与符号 | 必需文案逐字锁定、数量和位置明确，精确文字沿用 OCR 后人工核对 | 失焦／小字不用于判错，装饰文字可能是创作；不添加虚构品牌、拍摄信息或真实性标签 |
| 材质与纹理 | 褶皱从受力点延展，木纹沿构件，叶片与枝梗连接；材质响应匹配光线 | 规则织纹、印花、木饰面和成排种植可重复；重复本身不是异常，不随机加脏污 |
| 相机与成像 | 清晰度随相对焦平面变化，运动模糊有方向依据，边缘与主体共享成像条件 | 不要求全图噪点均匀：曝光、亮度、局部处理和内容都会影响；手机景深处理、压缩、放大与锐化可解释异常 |
| 文件与来源 | 有原文件才报告格式／尺寸／元数据的实际观察；来源未知就写未知 | 无 EXIF、JPEG、水印、缩放或漂亮外貌均不能据此判 AI；不编造 EXIF、RAW、连拍或设备记录 |
| 跨图身份 | 逐主体绑定参考来源，比较可见脸型、耳轮、发际线、特征点与配饰归属 | 透视、表情、光照、造型与时间变化可成立；不要求各视图像素相同，不对遮住的痣或耳朵判漂移 |

注视、焦平面、光源和镜面的细则复用 [自然观看现实感](natural-viewing-realism.md)；纹理与噪声复用 [ChatGPT 图片质量](chatgpt-image-quality.md)，不重复加载无关模块。

## 3. 证据规则

- 分开记录“观察到了什么”“违反哪条关系”“还可能由什么解释”。高置信缺陷需要可定位的连接／遮挡／光影矛盾，并排除与当前场景相关的正常解释。高置信只指该缺陷，不指 AI 来源。
- 两个独立维度可加强修订依据，但不是来源分类阈值。同一抠图边缘同时出现白边、发丝断裂和虚化跳变可能共用根因，不能算三份独立证据。
- 不设置约 100 像素的统一阈值：按目标结构能否被分辨判断。失焦、遮挡、压缩、截图或插值放大造成信息不足时记 N/A／待核验；放大不生成取证依据。
- 面部对称、光滑皮肤、重复纹理和相近眼神光至多是观察点；不能为满足“真人感”而自动改成不对称或增加缺陷。
- 原文件与连续影像可提供交叉检查信息，但可能被编辑或生成；元数据、来源声明和检测器分数均不是单一真伪证明。不输出纯 AI／换脸／传统美颜的确定分类或“真实概率”。

## 4. 最小修订合同

记录：区域与主体 → 可见证据／置信度 → 允许改变 → 必须保持 → 接触或边缘融合 → 下一轮验收。先问是否已有足够证据；没有图而用户要提示词时，提供候选目标状态，不阻断整个任务。

| 失败组 | 可选修订内容 | 保持项 |
| --- | --- | --- |
| 趴卧姿势与床面不相容 | 调整可见支撑处的身体连接、床面形变和衣料受力，仅联动必要因果组 | 身份、成年状态、体型意图、构图与机位；不拉长肢体凑头身比 |
| 手与杯子连接异常 | 修对应手的握持、腕指连接及杯壁遮挡 | 手归属、杯子位置、人物与光照；若现有姿势根本无法成立，说明所需范围变更 |
| 家具边界中断 | 修对应构件连接与共同投影 | 人物、家具设计、机位和其他物体位置 |
| 镜像内容不对应 | 修能确认的镜像位置、朝向与遮挡 | 实体主体、镜面位置、构图与光色；不要求反射复制相机视图 |
| 发丝边缘融合 | 修局部发束、耳／领口遮挡与景深过渡 | 发型总体、身份、配饰、正常轮廓光 |
| 跨图身份漂移 | 用已绑定身份参考约束本张的可见特征 | 当前视角、指定表情、造型和场景；不把其他人的特征混入 |

一个缺陷可需多项因果联动；用户指定的多个兼容改动全部保留。修复范围会改变原有明确不变量时先解释冲突并澄清，不静默移动机位、换脸或改变动作。

## 5. 输出与验收

生成任务沿用短提示词合同，不附完整审计报告。只有用户要求诊断时给“可见问题／证据与替代解释／修订优先级／局部指令／待核验项”，结论用可见问题状态，不用来源分类。无问题可确认时允许结论为证据不足，不为了满足请求罗列缺陷。

结构与用户合同作为硬门；随后评价材质、风格和清晰度。修订后同时检查目标缺陷与身份、姿势、光照、布局的漂移。评价与对照实验沿用 [真实感评价与实验](realism-evaluation.md)，未生图只报告提示词约束检查。
