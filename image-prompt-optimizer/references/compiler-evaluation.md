# 编译质量与图像评价

先检验意图是否被正确编译，再评图。参考 [真实感评价](realism-evaluation.md)，避免重复建立相互冲突的分数体系。

## 两层证据

静态层：Schema、来源/字段绑定、硬锁不变、引用完整、按目标的正文覆盖、文字归属、空间关系和执行状态。自动校验通过后，由 Agent 审查正文语义；不得把正则或子串覆盖当作语义证明。

视觉层：取得真实结果后逐项检查身份/主体、数量、产品/服装属性、构图、空间/接触、表演时刻、光色、景深、材质/噪点、文字和文件尺寸。没有图像、无法读取原像素或缺少参考时，对应项 NOT_RUN/待核验。评分不能抵消硬门失败。

## 结果驱动修订

对每个问题记录结果文件及哈希、画面区域、可见证据、置信度、相关合同字段和最小修订。单个问题只改必要因果组；用户要求多个兼容改动时全部保留。修改软字段后重新编译所有受影响目标并以旧合同作 baseline 检查；用户改硬要求则创建有来源的新合同。

每轮应有具体假设，例如“脸被逆光压暗：保持太阳位置，只调整面部环境反射/补光”，不能只是“更真实”。由用户/宿主决定是否实际重生成。遵守用户给定预算与候选数；没有预算不自动推导为无限生成。达到合同、预算耗尽、工具阻断或没有新证据时停止相应实验。

## 比较实验（仅实际执行后报告）

固定同一 ICIR、精确模型、界面、参考集及其他可控参数，比较原始提示词与当前编译版本；一次只改一个优化模块。seed 仅在支持时固定，无法固定的随机性应记录，重复样本不得伪装独立。

优先报告硬约束通过率、成品接受率、人工成对偏好、关键伪影率；维度分开列出，不伪造统一 92.7 分。记录样本数、失败/排除样本、评审方式、延迟和实际成本；无费用数据写 unknown，不能写 0。预算允许时覆盖不同年龄、肤色、性别表达、光照与景别；不把年轻/白皙/无毛孔当成质量指标。

跨后端比较保留相同意图，比较约束遵循而非像素相同。CLIP/IQA 或身份相似度只能辅助；没有已校准的数据和实际运行记录时不报告指标或固定阈值。禁止变化区域应按对齐/遮罩检查，不能用整图相似度抵消局部身份漂移。基准论文是设计依据，不等于已部署其评测器。
