# 摄影语言

在需要选择焦段、景深、表情、姿态或真实感措辞时完整读取本文件。所有数值只表达拍摄意图，不代表生成模型会物理复现器材。

## 1. 主体与自然表情

把抽象情绪拆成可观察信号：

- **视线**：直视镜头、看向窗外、看向手中物体、与画外人物短暂交流；只保留一个可见的物理落点。近处目标让双眼以与距离相称的幅度自然会聚，头位与眼睑随之变化，不夸张成斗鸡眼。
- **眼眉**：眼周放松或轻微收紧、眉间张力、眨眼前后的瞬间；避免“警觉但完全松弛”。
- **口部**：呼气后的轻微笑意、嘴角不完全对称、下颌放松、嘴唇自然闭合或微启。
- **肩颈与手**：肩线放松、身体略偏离镜头、整理袖口、翻书、握杯或扶椅背；动作须有支撑与受力。
- **抓拍触发**：正式姿态结束后、回应画外对话后、转身或走动中短暂回望，比“自然摆拍”更可执行。

只设置一个主情绪和一个次级张力，例如“克制的喜悦中带一点疲惫”。不要堆叠互斥状态，也不要把“完美表情”当成质量控制。

## 2. 景别、机位与构图

- **头肩／特写**：强调眼神、皮肤与妆发；安排裁切，避免无意从关节处截断。
- **半身／三分之二身**：兼顾表情、服装和手势；让手有自然落点。
- **全身**：交代轮廓、姿态和服装比例；预留脚部与地面关系。
- **环境肖像**：让人物、工作区或道具形成前中后景，环境必须可读。
- **机位**：分别描述相机方位、相对高度、镜头俯仰和画面横滚；高低机位不自动决定情绪。眼平可帮助稳定面部比例，但不能消除过近拍摄的透视夸张。具体排歧与取景检查见 [人像机位与视觉目标](portrait-camera-and-framing.md)。
- **留白**：商业文案需要明确位于人物哪一侧，并保证该区域亮度、纹理和内容复杂度适合排字。

## 3. 焦段、距离与透视

使用全画幅等效焦段并同时说明目的：

- **35mm**：环境肖像、全身或强调空间；近距离拍脸会夸张近侧五官，除非这是刻意的动态透视。
- **50mm**：生活方式、三分之二身或自然空间感；能保留环境又不过度拉伸。
- **85—105mm**：头肩、半身、美容与商业肖像；配合较远拍摄距离获得自然五官和背景分离。

透视主要由相机与人物距离决定。不要把“长焦压缩”描述为镜头魔法；表达为“较远拍摄距离、窄视角，使背景在画面中显得更接近主体”。单张图只保留一个主要焦段。

整张图还须共享一个投影中心和一组镜头特性：脸、近手、道具、家具与背景的相对尺度、遮挡和消失关系应由同一机位解释。不得把自然比例的长焦脸、被超广角放大的手与另一透视方向的房间拼在一起。

## 4. 光圈、景深与对焦

- 极浅景深近摄可写约 `f/1.4—f/2`，焦点落在近侧眼睛，并允许远侧眼睛自然变软。
- 希望双眼和主要五官稳定清晰时，保守写约 `f/2.8—f/5.6`，并避免过近拍摄。
- 多人或前后错位时，让面孔靠近同一焦平面并缩小光圈；不得要求 `f/1.2` 下所有面孔全锐。
- 环境叙事应采用适中景深，不能一边要求背景完全虚化，一边要求工具、招牌和空间细节清楚可读。
- 默认对焦优先级：近侧眼睛 → 双眼区域 → 面部；不要让睫毛、饰品或皮肤纹理抢走眼神焦点。

## 5. 快门与 ISO

静态、受控肖像默认省略。仅在下列视觉结果确有意义时使用：

- 冻结走动、转身或甩发：表达“足以冻结人物动作”，必要时再给约 `1/250s` 或更快的语义参考。
- 保留拖影：明确主体哪部分清晰、哪部分出现运动模糊，并说明相机或环境是否静止。
- 低光纪实：按需要描述暗部噪声与细节取舍；不从 ISO 数值单独推断噪声强度。
- 长曝光或闪光同步：只在背景光轨、环境曝光或动作凝固是叙事要点时写。

避免“烛光、ISO 100、f/8、1/1000s、自然曝光”之类没有额外强光支持的伪精确组合。

## 6. 人像真实感

- 皮肤：按景别、年龄、光线与观看尺寸保留可辨纹理和肤色差异；不强制毛孔或细纹，不做塑料或蜡质磨皮。
- 眼睛：双眼落在同一物理目标；近距会聚量与目标距离相称，远距视轴更接近平行；瞳孔和虹膜自然，眼神光数量、方向与主光一致。
- 五官：比例自然，三分之二侧脸时允许远侧五官受透视和景深影响。
- 手部：若入镜，明确手腕连接、手指分离、握持受力和道具接触；若不是重点，让手自然垂放、支撑或合理裁出。
- 服装与材质：描述面料重量、褶皱、反光和贴合方式，避免同时要求哑光与镜面反射。

## 7. 快速冲突修正

| 冲突 | 修正 |
| --- | --- |
| 24mm 贴近拍大头照，同时要求五官无透视夸张 | 改用 85—105mm 并后退，或承认宽角夸张为意图 |
| 85mm、f/1.2 近摄，同时要求双眼、耳朵和头发全锐 | 改为 f/2.8—f/5.6，或仅让近侧眼睛锐利 |
| 走动人物、1/15s 手持，同时要求动作完全冻结 | 提高快门语义，或接受可见运动模糊 |
| 抓拍与对称、正式姿态并存 | 不直接判冲突；确认是偶然对称、被摄者回应镜头，还是用户要改变拍摄意图 |
| 绝对光滑瓷质皮肤，同时要求清晰毛孔细纹 | 改为适度修饰并保留自然纹理 |
| 手藏在身后，同时要求手部清晰可见 | 修改构图或手的位置 |
| 人物低头使用手机，但屏幕完整正对镜头且人物正脸也完整可见 | 先让屏幕朝向人物；若屏幕内容必须可读，改用肩侧／过肩三分之四机位并接受透视缩短 |


## 8. 条件判断与视觉目的

本文件中的焦段、光圈和快门只是语义示例，不构成清晰度保证或固定配方。景深同时受距离、放大率、焦段、光圈与观看条件影响；不要仅凭 f 数判断所有面孔一定模糊或清晰。主体焦点也可落在手、产品、轮廓或环境，眼睛优先仅适用于眼神为重点的人像。

高低机位的情绪取决于距离、姿态、环境与叙事，不自动等于强大或脆弱。单一摄影投影适用于普通照片，不约束正交图、拼贴或有意多视点绘画。

冲突表提供候选修正，不自动覆盖用户要求。对称与抓拍可共存；摆拍可表现自然状态。真正矛盾是同一可见区域同时被要求互斥状态。慢快门与动作清晰也可在闪光主导曝光时成立，需检查环境光重影；不要仅凭快门数值判定失败。
