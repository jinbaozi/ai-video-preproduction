# 角色转译

仅在角色灵感设计、COS 或跨媒介改编时读取。

拆分真人身份、角色辨识特征、服装改编、瞬时行为与背景世界。真人参考决定已声明的脸部特征；角色设定决定已声明的造型，不把角色脸覆盖真人脸。相反，用户要原作角色形象时，不默认加入真人扮演者。

角色名不足以确定作品版本、服装时期或标志道具。存在实质歧义时询问版本；不熟悉的事实按需核验来源，无法确认则标为创作选择，禁止编造设定。仅有角色名称不自动加载夏季预设。

改编强度按需求选择：灵感穿搭（色彩与少量形状语言）、可辨识改编（核心发型、轮廓与标志配件）、原作造型保持（服装结构与道具优先）。强度不是质量排名。改编为泳装、礼服、街装或铠甲必须有用户需求或已启用预设支持。

转译服装时保留有辨识度的轮廓、结构、图案与配饰关系，并考虑真实穿着的连接和受力；不能仅换色，也不能强制每个角色不同款。角色性格用当前事件中的可见行为表达，不凭外貌推断人格。

不自动更改年龄。成人主题预设仅用于明确成年人；无法适用时暂停该预设并澄清，不用年龄标签掩盖仍呈未成年特征的性化内容。普通儿童肖像保留其年龄与合适造型。
