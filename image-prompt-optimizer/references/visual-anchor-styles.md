# 视觉锚点与风格

本文件是摄影与绘画原理转译出的设计启发式，不是模型增益实验结论。按任务选用，不堆满词库。

## 层级与可见性

识别锚点回答“是谁”：轮廓、五官比例、固有发色、固定配饰。叙事锚点回答“发生什么”：手中物、注视点、衣物受力和环境响应。注意锚点回答“先看哪里”：明暗、色彩、面积和焦点。先选少量主锚点，再补支持细节；不规定每幅图必须出现相同数量。

每个锚点明确对象、位置、形状／颜色／材质。系列人物左右按人物自身定义，必要时补画面侧别；转身后不能照抄正面侧别。大远景不写面部毛孔，遮挡区域不要求完整可读。

| 维度 | 可执行描述 | 避免 |
| --- | --- | --- |
| 光影 | 主光来源、方向、软硬、阴影边界；必要时加反射或轮廓光 | 把侧光等同硬光，把柔光等同无纹理 |
| 构图 | 景别、主体占比、机位、前中后景、留白与视线落点 | 每个物体都同等锐利、同等抢眼 |
| 皮肤 | 固有肤色底调、局部高光、随景别可见的毛孔或唇纹 | 全脸同一毛孔强度、砂纸纹理、无端加龄美白 |
| 发色 | 底色、受光色、阴影色分开；轮廓→发束→少量散发 | 暖轮廓光把黑发变成金发、根根同亮 |
| 服饰 | 轮廓、领襟、叠层、材质、连接点和受力褶皱 | 纱、丝缎、麻布同一种反光；刺绣脱离布面 |
| 背景 | 地点、可辨物、纵深、尺度与主体交互 | 雾遮掉全部结构、装饰无因果 |
| 风格 | 媒介、边缘、形状语言、明暗方式、纹理尺度、色盘 | 同一区域叠加互斥的二维与摄影要求 |
| 瑕疵 | 类别、位置、强度、成因和保护区 | 用错手、糊脸、身份漂移伪造自然 |

## 媒介路径

真人摄影：明确写实照片，描述可捕捉的瞬间。皮肤、头发、织物具有不同反射；近景保留局部纹理，远景依靠轮廓、重量与接触影。商业精修也可真实，不将脏乱或无妆设为前提。

二维国漫：先指定线条、色块、分区阴影或绘画渐变，再写造型。头发以体积、发束和散发分层，皮肤不默认摄影毛孔。水墨纸感与干湿笔边缘须指定落点，脸部与关键道具保持可读。

三维国漫：指定风格化程度、成年比例、发束体积、材质粗糙度、柔和透光与接触影。保留动画造型，不为材质真实而改成真人；避免蜡质皮肤、塑料发条和金属衣料。

仙侠是题材层：选择身份、轮廓、主色、专属器物与场景尺度中的叙事锚点。优先一个主要超自然现象，其余特效降权。定义超自然例外及其光照、遮挡、反射，其余空间统一。发丝、披帛与雾响应同一风向。

## 混合媒介合同

混搭有条件有效，不按“风格越多越好”处理。写清主体层、环境层、特效层、成像层的归属与交界，用户未要求的层不补。混合区域必须有位置、深度／遮挡、光照与边缘规则。

| 用户建议 | 判断 | 可执行修正 |
| --- | --- | --- |
| 3D仙侠主体＋2D水墨施法，飞白、墨焰 | 有用；混合媒介设计 | 角色保持三维体积，墨效只在手边和指定空间展开；前后遮挡明确。飞白留在笔触内部；说明墨焰是否发光，若发光则影响手与袖口 |
| 实拍竹林＋CG人物 | 有用；取决于是否提供素材 | 有背景照片才称使用实拍底图；无素材写“摄影质感竹林”。匹配相机视点、光向、软硬、曝光、色温、景深、地面接触与竹叶遮挡，不只写“完全匹配” |
| 数字赛博＋16mm漏光＋VHS干扰 | 有条件；有意混合成像风格 | 16mm颗粒、漏光与VHS色度拖尾／水平跟踪纹分别定义，不能混称同一种噪声；限定边缘与暗部，保护脸和文字。高光溢出只作用于霓虹局部 |
| 万能模板全部叠加＋8K＋运镜 | 不作为万能模板 | 拆成可选层，按画面选择。删除无控制依据的8K；静态图把运镜改为机位、透视和动作瞬间；长曝光拖影仅意图明确时保留 |

静态画面中“水墨晕开”描述已形成的扩散边缘、浓淡与飞白，不要求图片实际播放动画。“国漫电影级”需展开为造型、光影、构图与材质。

## 受控瑕疵

| 类别 | 可选项 | 约束 |
| --- | --- | --- |
| 身份 | 痣、雀斑分布、眉形不对称 | 仅原创设定或用户授权的外观改动；已有身份不擅加 |
| 生理纹理 | 鼻翼毛孔、唇纹、眼下色差、局部油光 | 服从年龄、景别和光照；不满脸同强度 |
| 动作状态 | 碎发、衣袖压褶、附着雨滴 | 有天气、动作、材质成因 |
| 物件痕迹 | 簪子边缘磨亮、剑鞘擦痕、旧台阶 | 与叙事相符；新品广告默认不用 |
| 成像痕迹 | 指定颗粒、局部色差、运动模糊、漏光或眩光 | 按下表分别选择；不作为通用真实感增强 |
| 手绘痕迹 | 线条轻重、干笔、边缘变化 | 用于二维区域，不转为压缩故障 |

可从零到两类瑕疵开始，这是可调整设计预算。用位置与范围控制，例如“纹理只在鼻翼可辨，面颊保持柔和”，不用伪精确的毛孔百分比。清晰度优先时减少成像噪声，保留材料细节。

成像痕迹仅在用户所选风格需要时启用；“烂镜头”应拆成可见效果，不默认叠加。正常现代镜头的干净清晰也可真实。下表是摄影原理转译的候选写法，未证明对 image_gen 有稳定增益。

| 效果 | 位置与成因 | 范围与保护 |
| --- | --- | --- |
| 胶片颗粒 | 指定胶片外观的细粒纹理，不与数字高 ISO 色噪等同 | 延续指定强度，不为去 AI 感额外加粗；去噪规则见 [图片质量](chatgpt-image-quality.md) |
| 色差／色散 | 如画面外围高反差轮廓的轻微色边；不固定所有镜头都是红蓝两色 | 局部、低强度，不给所有物体描彩边；保护脸部、身份锚点与文字可读性 |
| 运动模糊／拖影 | 对应具体运动对象或相机运动，方向与速度关系可解释 | 仅相关区域受影响；面部是否清楚服从动作与闪光意图，不机械要求全图锐利或全图模糊 |
| 胶片漏光（light leak） | 模拟胶片意外受光的局部光雾，可从边缘侵入 | 不自动由逆光推导；指定色彩、落点和低强度，不遮盖主体或文字 |
| 镜头眩光／鬼影（lens flare） | 强光接近或进入视场时的镜头内散射／反射效果 | 位置与光源、构图相关；可在画内出现，不强制贴边或添加完整光圈；避免淹没主体 |

漏光、眩光、色差和颗粒不可互作同义词。效果若压过主体或破坏清晰度目标，先减弱该层，不靠更重锐化补救。出处与证据边界见 [来源记录](sources.md#2026-09-12去噪真人感与受控成像)。

检查顺序：媒介、身份、结构 → 光色与材质 → 瑕疵与特效。修皮肤不改脸型，修固有发色不改主光；减特效不删主要叙事锚点。


## 视觉重点与媒介边界

风格由媒介、题材、形状与边缘、明暗、色彩、纹理尺度组合，不由标签数量决定。商业精修、平面化、毛孔弱化和高度风格化可以是合格目标，不以摄影真实性统一评分。优先保留身份或产品结构、视觉重点与媒介语言；细节量不是质量分数。构图选择见 composition-and-scene.md。胶片、CCD、DV 默认仅指成像处理，不添加 UI、日期或边框；设备类别不对应唯一固定色偏。
