# 人物外观、造型与表情

当人物外观是画面重点，或任务涉及完整角色设定、参考图复现、系列人物一致性时，完整读取本文件。先检查所有维度，再只输出当前画面可见且有用的细节；不要把清单机械拼接成提示词。

## 1. 规格分层与来源

先把人物信息拆成三层：

- **身份锚点**：脸型、肤色范围与底调、眼睛、基础眉形、基础发色、发长与发质、稳定面容特征。系列图默认固定。
- **造型变量**：具体发型、发饰、妆面、服饰、配饰。可以随场景变化，但同一组图须明确哪些固定、哪些可变。
- **瞬时状态**：视线、眉眼张力、嘴角、下颌、头部角度、肩颈、手势和动作触发的表情。单张图只描述一个时刻。

为每项记录来源：`用户明确`、`参考图可见`、`品牌固定`或`创作默认`。优先级依次为用户明确要求、已排序的参考图、品牌固定项、与场景一致的创作默认。发生冲突时先解决优先级，不要静默融合。

若互斥要求来自同一优先级，且会改变身份锚点、核心造型、唯一视线或表情时刻，把它视为**阻断冲突**。将同类冲突合并为最多 1—3 个短问题，等待用户选择后再生成主提示词；不得默认保留先出现的要求、把两组属性平均，或一边声明冲突一边仍交付“可直接使用”的成稿。只有用户明确授权代为选择时，才采用与用途最一致的一组，并把取舍列为创作默认。

## 2. 十一类人物要素

| 要素 | 可执行描述 | 避免 |
| --- | --- | --- |
| 发型 | 长度、发质、分缝、整体轮廓、束发方式、整洁或松散程度、动作中的发丝状态 | 同时出现互斥长度或造型；只写“高级发型” |
| 发饰 | 类型、材质、颜色、大小、佩戴位置、固定方式，以及与头发、帽子和耳饰的遮挡关系 | 发饰悬空、穿过头发；同一位置堆叠多个主发饰 |
| 发色 | 固有基础色、冷暖底调、挑染或渐变位置、发根连续性；另行说明光线造成的可见色偏 | 把灯光反射误写成永久发色；无过渡地同时要求两种纯色 |
| 脸型 | 外轮廓、额部与颧骨宽度关系、面颊饱满度、下颌线与下巴形态 | 用脸型推断族裔、性格或社会身份；堆叠互斥轮廓 |
| 肤色 | 可见明度范围、冷暖或中性底调、自然局部色差、日晒或雀斑等用户指定特征，以及主光下的呈现 | 用肤色替代族裔标签；既要求强烈彩色光染色又要求完全不受光色影响 |
| 眼睛 | 眼型、相对大小与间距、虹膜颜色、眼睑状态、同一个可见物理落点；近距注视时会聚量与目标距离相称，眼神光必须由主光解释 | 墨镜或闭眼状态下要求虹膜和眼神光完整清晰；双眼看向不同目标；近距注视夸张成斗鸡眼 |
| 眉毛 | 浓淡、宽度、走向、弧度、眉峰、眉尾和整理程度；区分稳定眉形与表情引起的暂时变化 | 刘海完整遮眉却要求眉毛全貌；基础眉形与瞬时皱眉混为一谈 |
| 面容 | 五官比例、颧骨、鼻、唇、面颊、下颌、年龄相符的纹理和少量识别性特征；通常选 2—4 个关键锚点 | 穷举十余个微小特征；“完美五官”“网红脸”等不可执行标签 |
| 服饰 | 品类、轮廓、剪裁、层次、合身程度、面料、颜色／图案、使用状态、与动作产生的褶皱和垂坠 | 互斥材质表现；衣物穿层关系错误；用品牌名代替可见设计 |
| 配饰 | 类别、数量、材质、颜色、尺度、佩戴位置、表面反光及与服装和动作的关系；通常保留 1—3 件主配饰 | 配饰漂浮、穿透皮肤或衣物；数量过多抢走人物和产品重点 |
| 表情 | 一个主情绪、至多一个次级张力，并落实到视线、眼周、眉毛、嘴角、下颌、呼吸和肩颈 | 只写“自然”“高级脸”；同一瞬间直视镜头又望向远方 |

脸型描述外轮廓，面容描述内部五官、组织感和年龄痕迹，两者不得重复堆词。眼睛与眉毛既是身份锚点，也参与表情；先写稳定形态，再写当下变化。

## 3. 景别与细节预算

- **面部特写／头肩**：展开脸型、肤色纹理、眼睛、眉毛、面容、发际与发饰；服饰只保留领口、肩部和可见配饰。
- **半身／三分之二身**：平衡面部锚点、发型、上身服饰、1—2 件配饰、手势和表情，是完整人物造型的默认景别。
- **全身**：优先发型轮廓、服装剪裁与层次、鞋履、配饰位置、身体姿态；眼睛和眉毛只保留能被观看距离识别的概括特征。
- **环境人像**：保留 3—5 个身份锚点、清楚的服装轮廓和可读表情，把其余细节预算留给场景、道具和动作关系。

先判断可见性再描述。背面人物不展开面容；厚重刘海不要求完整眉形；宽檐帽形成眼部阴影时降低虹膜细节要求；远景不写毛孔、虹膜纹理或单根眉毛。

## 4. 合理补全边界

- 用户未指定永久外貌属性且任务只是单张简单人像时，可以省略，不要为了“完整”擅自确定族裔、宗教、健康状况、残障或社会身份。
- 用户明确要求“完整角色设定”时，可以对十一类要素给出相互一致的创作默认，但必须标记为创作选择，且不得从脸型、肤色或服装反推敏感身份。
- 仅在服装、发型或配饰承担场景叙事时补全它们，例如运动场景需要固定头发、厨房场景避免垂落饰品接触食物；说明可见理由。
- 描述肤色时区分固有肤色与光源色偏。系列一致性可固定“明度范围＋底调＋自然变化”，不要用精确色值把真实皮肤压成单一平面颜色。
- 未成年人须使用与年龄和活动相符的发型、服装、配饰、妆面和表情，不成人化、性化或添加不必要的商业成熟造型。
- 真实人物或身份参考图只保留可见特征；不要推断不可见身份信息，也不要承诺仅靠文字即可精确复现身份。
- 奇幻、舞台或强风格任务可以使用非自然发色、肤色或配饰，但要把它们标为有意的造型规则，并保持材质、光线和世界观一致。

## 5. 系列一致性锚点

建立一条简洁的身份锚点，不随镜头重复改写：

```text
<年龄范围与整体气质>；<脸型与 2—4 个面容锚点>；<肤色范围与底调>；<眼型／虹膜色>；<基础眉形>；<基础发色、发长与发质>；<识别性发饰或配饰，如有>。
```

把以下内容默认固定：脸型、肤色底调、眼型与虹膜色、基础眉形、基础发色、发际与发质、稳定面容特征。把具体束发方式、可更换发饰、服装层次、非标志性配饰和表情列为可变项。若剧情需要永久改变，明确记录变化发生在哪一张或哪一幕。

同一变体最多主动改变 1—2 个造型轴。使用参考图时，逐项写明哪张图负责身份、发型、服装、配饰、姿态或光色，不要用“融合全部参考”替代优先级。

## 6. 遮挡、动作与冲突修正

| 冲突 | 修正 |
| --- | --- |
| 齐刘海完整遮住眉毛，同时要求眉毛全貌清晰 | 调整刘海开口，或只描述可见眉尾与眉间变化 |
| 深色墨镜遮眼，同时要求虹膜纹理与眼神光 | 移除墨镜，或把表情重点转到嘴角、下颌和姿态 |
| 紧贴头皮的光洁盘发，同时要求长发披肩飞扬 | 选择盘发，或改成部分束发并保留可动发束 |
| 发色既是均匀纯黑又是整体浅金 | 指定黑色发根向浅金渐变，或只保留一个基础色 |
| 帽子、大发夹和头巾占用同一位置 | 确定一个主头部配件，其余删除或移到不冲突位置 |
| 精致长耳坠被头发完全覆盖却要求成为视觉焦点 | 把头发别到耳后，或更换可见配饰位置 |
| 全身远景要求清晰虹膜纹理、单根眉毛与毛孔 | 保留眼神方向和面部总体状态，把微观细节留给近景 |
| 固定系列人物在相邻图片中眼色、基础发色或脸型漂移 | 恢复身份锚点，只改变事先声明的造型变量 |

若表中冲突来自用户同时给出的明确要求且没有优先级，不直接采用“修正”列替用户选择；先提出合并后的选择问题。

## 7. 提示词编排

按以下顺序把规格改写成自然摄影语言：

```text
<身份范围与年龄相符的整体气质>；
<脸型、肤色与少量面容锚点>；
<当前景别可见的眼睛与基础眉形>；
<基础发色、发质、具体发型与发饰>；
<服饰轮廓、层次、面料与颜色；1—3 件必要配饰>；
<姿态和动作触发；唯一视线；眼周、眉毛、嘴角、下颌与肩颈共同形成的单一表情时刻>。
```

相邻内容可以合并成流畅句子。相同颜色、材质或情绪只写一次；不把“发型：……、发色：……”等字段标签直接塞进最终摄影提示词，除非用户明确要求结构化规格表。


## 多人及改编入口

多人按 multi-subject-and-interaction.md 建立属性归属；角色改编按 character-transcreation.md 分离身份与造型。用户指定制服或相似外貌时保留，不强制差异化。单次变体改变 1—2 个造型轴是控制漂移的启发式，不限制用户明确要求的多个兼容修改。
