# 真实人像场景预设

需要对应摄影方案时选择一项；预设仅补未指定内容，不覆盖身份、年龄、服装、构图或编辑范围。数值预算和景别细节沿用 [真实人像照片感](../references/portrait-photo-realism.md)。以下为设计示例，未证明模型固定增益。

| 类型 | 优先证据 | 可选线索 | 不自动加入 |
| --- | --- | --- | --- |
| 窗光半身 | 侧窗主光、背光侧层次、可辨房间 | 50mm 等效视角 | 满脸毛孔、额外补光、泛光 |
| 商业棚拍 | 面部体积、眼神、修饰程度、背景分离 | 85mm，约 f/4 景深观感 | 污渍、粗颗粒、抓拍动作 |
| 全身穿搭 | 拍摄距离、支撑、鞋底落地、布料重量 | 50mm | 拉长肢体、可数毛孔 |
| 雨夜直闪 | 闪光主导人物曝光，环境光与湿地反射对应 | 35mm；需要拖影时加慢快门语义 | 五官重影、夜如白昼、全脸油膜 |
| 手机生活照 | 手持拍摄关系、环境信息、符合意图的处理风格 | 可省略 | 低画质、轮廓式虚化、故意失焦 |
| 多人合照／COS | 身份归属、共同空间、材质与成像一致 | 按人物深度设计清晰区 | 强制差异化、配饰串位、全员同锐 |
| 儿童证件照 | 原有身份、儿童年龄感、正面姿态、指定背景 | 可省略 | 成人妆容、晒伤、抓拍动作 |

多人按 [多主体与互动](../references/multi-subject-and-interaction.md) 绑定角色；检查各人服装和皮肤共享曝光、光源和深度规则，不能像来自不同照片的贴片。相同制服与相似面孔可以是用户意图。

## 新生成骨架

```text
一张[拍摄类型]，表现[主体]在[地点]的[一个动作瞬间]。[景别与机位]，视线落在[目标]，[入镜的支撑或接触关系]。[主光来源及可见结果]；[景别允许的皮肤或衣物表现]，[清晰区与环境关系]。保留[用户明确项]，避免[当前最高风险的一至两项问题]。
```

省略不适用字段。比如背面全身图无需交代眼睛、鼻翼或唇纹。

## 窗光示例

```text
一张真实生活人像照片。一名25岁的成年女性坐在窗边，听到画外朋友说话后抬眼，手中仍握着陶瓷杯，嘴角浮现笑意。眼平半身构图，50mm等效视角；躯干由椅背支撑，手指环绕杯身，指腹与杯子有接触和遮挡。左侧窗光照亮面部，另一侧保留阴影层次。面颊呈柔和色差，鼻翼和唇部保留当前景别可辨的纹理；棉质上衣在肘部和腰间形成受力褶皱。双眼处于清晰区，杯子与身体的清晰度符合各自深度，背景仍能辨认窗框和书架，不出现轮廓式虚化白边。
```

## 局部修订示例：全脸油亮

```text
只调整面部皮肤的高光面积与纹理表现：缩小覆盖面颊的连片油亮反光，保留与现有主光对应的鼻尖及颧部局部高光，恢复面颊明暗过渡和当前景别可辨的肤质。保持同一人物的脸型、五官、年龄、肤色底调、妆面、表情、发型、服装、机位、构图、光源位置和背景；不新增雀斑、痣、皱纹或痘印。
```
