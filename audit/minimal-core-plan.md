## 第一性原理与最小合同

每阶段只做：必要输入与锁定检查 → 按需自动路由 → 创作/复用原生结果 → 校验、审计与交接。保留Canon、ScriptIR、DirectorIR、ArtIR、StoryboardIR、AVIR等原生表示，不新建平行内容IR或第三套编排内核。

| 阶段/技能 | 保留的核心职责 | 交付 |
|---|---|---|
| 总工作流 | 来源、状态、依赖、范围、异常恢复 | Canon、进度与最终索引 |
| 编剧 | 因果、人物认知、信息顺序、台词 | ScriptIR及必要映射 |
| 导演 | 表演、视听意图、运镜、光色和转焦 | DirectorIR与冻结约束 |
| 美术 | 身份/服装/道具/空间与光源 | ArtIR与按用途的资产需求 |
| 图像 | 输入理解、可复制提示词、真实素材验收 | 图像提示词、真实媒体及审阅 |
| 分镜 | 动作/机位/节拍/起止态和跨镜连续性 | StoryboardIR与实际需要的控制/分镜资产 |
| 视频编译 | 目标隔离、AVIR投影、分段与引用映射 | 编译包、正文、附件与覆盖/阻塞 |

独立使用时在授权范围内补齐最少输入，不伪造上游执行；串联时复用同一原生产物，不重新解读已锁定决定。真实生成、Flow 2K和剪映属于有执行入口时的既有生产链，不能用简化名义跳过媒体或质量门。

## 实施路径

1. 七个SKILL收敛为短入口与最小阶段合同，完整规则转入按需文档；各技能继续独立可安装。名家/场景/技巧注册表与来源不删减。
2. 新lean项目采用冻结的最小上下文策略；现有/audited项目不静默迁移。宿主只接收当前核心任务视图，完整原生任务继续作为审计证据。去重字段与引用不截断硬约束、异常或用户原文；必要深入读取入口保留。
3. 增加轻量结果入口：程序填充真实文件/规则指纹、已执行原生检查和读取回执；宿主仍负责创作、语义判断、采用/不适用、视听验收。相同采用证据允许分组，展开后仍须逐项完整覆盖；不能自动宣称技巧已采用。
4. 同一操作内复用确定性检查，缓存以内容与锁定上下文为依据；跨操作重新核验，篡改/失败/修订不复用旧结论。先剖析热点，不为追求速度放宽校验。
5. 审计保留权威输入、输出、规则采用、校验、异常及哈希；不生成重复的宿主草稿、方法说明副本或整库上下文。问题回到责任阶段；未知外部执行先回收，不重提交。
