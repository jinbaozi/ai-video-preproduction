# Compact workspace：第一性原理、实施与验证

基线 main：`fabd5be3a9f15cf3cff90f314dea51df11c07ece`，包含上次专业方法默认路由。用户提到的本轮运行任务附件未出现在当前对话上传中，因此未对该任务进行删除、迁移或实测；以下验证使用仓库的已编写 cafe 样例。

## 设计先行

工作流要持久保留的是：原始来源、当前内容及锁定、跨角色依赖、实际媒体、接受/拒绝/恢复证据和下一步。重复叙述这些事实，不增加可恢复上下文。文件少与 token 少也不是同一指标：只在生成、读取、回显减少时才可能节省模型上下文。

采用单一权威副本加引用，不另建 context IR。新 lean 项目默认 compact，旧项目、独立审计和显式 audit 保持原协议。将人读导航限制为一个进度页，产物在按序阶段目录，内部证据在 .runtime。删除策略使用不产生重复文件的白名单，而不是对未知项目作递归清扫。

## 实施

- 新 `output_policy=compact-workspace/1.0` 在 project/state 双方冻结；改变或删除单侧配置拒绝继续，不作静默迁移。
- `workspace.py` 集中管理顺序目录、懒创建、进度投影、按指针取上下文与依赖去重。项目本身仍是原状态机和原生 IR 链。
- 交接字段移除值的副本，保留 native_uri、sha256、pointer 和全部硬交接要求。已选 craft 方法嵌入任务且不另存同内容文件，保留原有采用证明与重验。
- 快照复用已冻结且哈希相符的依赖，共享外部文件按字节寻址；同名不同内容不合并，修改过的缓存失败关闭，依赖环拒绝。原件在路径重定位发生时保留一份，用户资料与外部源文件不改动；宿主写在 task.output_file 的本轮未接受原生草稿可在保留原件后重定位，接受过的版本不得覆盖。
- 不写 state 的 manifest 镜像、常量 phase-index、全量 delivery/index.json 和普通历史记录镜像。不删除原生协议依赖的收据、媒体、控制包或恢复证据。
- 标准输入 RoleResult 省去一次性的结果文件；`context --slot --pointer` 直接返回核验后的原生值，不落盘上下文副本。旧命令与完整协议继续可用。
- 事务、模块缓存、生成记录与文件导航使用同一真实路径，隐藏目录不使用软链接伪装。前期交付和真实视频完成状态不互换。

## 验证计划

实际 cafe 原生文字交付对照 compact/audit 的目录、文件数、UTF-8任务/交接字节；每一步重新打开内核验证断点恢复。另测默认入口、旧入口不迁移、失效来源、路径逃逸、循环依赖、缓存篡改、同名异字节、重复/冲突提交、stdin、精确 context、真实链接、局部修订、事务回滚/失败恢复和生产路径。专业方法端到端测试使用真实门禁与原生验证器，创作内容是预编写测试材料，不代表 LLM 创作或实际媒体验收。

## 已完成的同样例对照

机器记录：`audit/compact-workspace-benchmark.json`。复现：`python ai-comic-drama-workflow/scripts/benchmark_compact.py --out /绝对路径/空目录`。固定三镜 cafe 样例，7 个原生任务，每步重新打开内核；两个配置均 DELIVERED 且完整原生验证通过。没有使用用户未提供的任务附件。

| 指标 | 原 lean/audit 布局 | compact | 减少 |
|---|---:|---:|---:|
| 项目内容文件（不含运行模块/锁定归档） | 56 | 40 | 28.57% |
| 项目内容字节 | 924259 | 740072 | 19.93% |
| 任务信封 UTF-8 字节合计 | 110303 | 70102 | 36.45% |
| 交接 UTF-8 字节合计 | 71686 | 28589 | 60.12% |
| 含模块/锁定归档的文件总数（不含 pycache） | 432 | 416 | 3.70% |

模块仍须保持可复现运行，因此全目录文件数的降幅小于创作输出文件降幅；不把隐藏目录说成删除，不把字节降幅说成实际 token 或付费降幅。样例作者文件位于项目外，统计没有把 task.output_file 避免作者副本的潜在收益算进去。

本地已验证七包重复构建逐字节一致、六个内置模块与独立包一致。更多测试的实际日志以提交对应 CI 为准；不把正在运行或跳过的测试计为通过。真实模型创作、生图、生视频、付费提交和成片审片均 NOT_RUN。合成 PNG 只验证实际图片解码、字节登记与批准门禁。
