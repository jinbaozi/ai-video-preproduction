# 长篇改编与剧集

先识别文件章节或分集结构，记录已读范围；摘要帮助定位，不替代需要核对的原文。只读三章只交三章范围的改编，不宣称覆盖全书。来源保留文件哈希、章节/段落、摘录与对应正文块。

改编账本逐项记 preserve、compress、merge、reorder、omit、externalize、invent；说明理由、影响人物、事件和权限。合并角色或重写结局属于结构变更，不在润色中偷偷完成。版权与署名证据独立记录，不把“有来源”当成授权证明。

剧集先建立下一集持续产生事件的机制、季线、本集承诺、主副线与出口状态。每批读取当前场景所需原文、人物状态、未兑现承诺与相关已定事实，不每次加载全书。

续写批次结束更新人物关系、所持物件、目标、知识和开放问题；一集不是模型生成段的集合。项目正文可以按 scene 分集标记，长项目用多个明确范围的主稿，由外部 Canon 统一 ID 和事实，不声称实现跨季自动求解。

时长目标、估计区间与实测分别存储。朗读和动作可并行，不能简单累加字数；真正实测才填 measured_seconds 和测量记录。
