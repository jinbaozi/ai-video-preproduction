# 构图参考图实验：实拍风格可辨，构图仍 FAIL

本轮是与上一轮文字编辑不同的单次方法实验：由冻结摄影机画面目标绘制扁平构图参考图，按固定顺序将其与 A、B 身份母版及咖啡馆材质母版送入内置 image_gen，要求生成一张完整摄影关键帧。调用前冻结 [参考图绘制脚本](draw_guide.py)、[准确提示词](prompt.txt)、四个输入摘要与信封中心每轴 ±0.02 的原验收阈值；没有改变 AVIR 或放宽标准。参考图为相机画面排布，不是俯视轨迹图，也不是模型具备确定性坐标控制的证明。

实际输出为 1672×941 PNG，SHA-256 `f326481d7525679ac872f64df19a0258bec60586bbb5d346c644d62c48d24b03`，保存在本地 `outputs/host-keyframe-guide-r2/actual-keyframe.png`，未上传仓库。手工估计信封中心 (674,657) 像素，归一化 (0.403110,0.698193)，相对冻结目标误差约 (+0.024748,-0.018052)；标记不确定性 ±12 像素与阈值分开记录。信封横向落在阈值外但靠近边界，单项记为 UNDETERMINED，不记 PASS。桌面后沿约 y=810±10 像素，即 0.860786，明显低于目标 0.775；整体构图 FAIL。人物身份、服装和咖啡馆材质可辨，无额外人物或印出的导线；手别未确定。逐项记录见 [observation.json](observation.json)。

相对于前次文字编辑的信封中心 (745,577)，本次估计更接近目标，但两次同时改变了编辑/新生图方式和是否提供构图参考，不能把差值归因于单独一个因素。内置工具未给出可核验供应商模型、执行编号或费用，不写作零费用。此图未通过 `keyframe_host` 的事前 stage/receipt 链，不作为可消费的合格首帧，更没有执行视频平台请求。来源照片与实际输出只留本地；公开目录提供可重画参考图及核验边界。
