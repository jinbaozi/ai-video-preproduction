# Guided photograph edit, attempt r3

This is one preregistered local edit experiment. `frozen-experiment.json` and `prompt.txt` were saved before the built-in image generation call. Input order was the r2 photographic result, the r2 flat camera-space guide, then the two actor identity masters. The earlier empty-room café scene reference was omitted because its tabletop geometry conflicts with the target. The guide is a camera-space composition drawing, not a top-down blocking or trajectory map.

The generated photographic PNG is retained only in ignored local `outputs/host-keyframe-guided-edit-r3/actual-keyframe.png`; its SHA-256 is in `observation.json`. The actual photograph is not in the public repository. Manual measurements from the 1672×941 output place the envelope around `(759,662)`, or `(0.453947,0.703507)`, versus frozen `(0.378362,0.716245)`. The x error is `+0.075585`, larger than the preregistered per-axis `0.02` allowance even with ±12 px marking uncertainty. The tabletop rear and front edges are around y=778 and y=906, giving errors `+0.051780` and `+0.065806` against the frozen 0.775 and 0.897 targets; both exceed 0.02 with the stated marking uncertainty. Overall result: **FAIL**.

The output preserves a recognizable two-person café scene but does not satisfy the geometry. Handedness remains undetermined. The built-in tool provided a file result, but no provider model name, execution ID or price. This experiment did not run the product `keyframe_host` stage/receipt path or a video backend, and it cannot qualify as an accepted first frame. Its local manual visual assessment is not independently checkable from GitHub without the photograph. Further prompt-only edits to the same image are not treated as a verified spatial-control mechanism.
