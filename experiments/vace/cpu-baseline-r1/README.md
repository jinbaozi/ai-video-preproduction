# VACE CPU 单帧基线

本实验延续 [MPS 精度对照](../diagnostics-r1/README.md)，使用相同的原始 checkpoint、文本、种子、512×288 画幅和 20 步 FP32 计算分支，在独立 CPU 服务完成一次真实采样。实际耗时 **98.382 秒**，缓存节点为空；完整回执摘要与字节校验见 [evidence.json](evidence.json)。工作流与提交前冻结文件原样保留。

![实际 CPU 单帧原图](actual-output.png)

实际审图可辨识左侧深蓝服装短发人物、右侧米色服装人物、木桌及左窗。相较先前 MPS 结果中的黑黄粉色块，可辨识程度提高；但输出仍为明显卡通插画，脸和手部简化，蓝纸呈竖直弯曲形状，桌上多出杯子。**质量仍为 FAIL**，没有放宽原来的自然质感要求或负面提示中的 cartoon 约束。

该图没有绑定到具体 AVIR 事件时刻，不用它证明或否定某一时刻的信封姿态。单帧不能验收四秒动作、轨迹、接触顺序或摄影机稳定性；本次也没有 `control_video` 输入，不能证明控制收益。

复跑使用 [独立服务说明](../COMFY-EXPERIMENT.md) 中已核验的源码和三份权重，保留禁用自定义／API 节点及独立数据库的设置，另加 `--cpu --fp32-vae`。须使用新的独立 base/input/output/database 目录，不能与其他服务同时占用端口 8189。将本目录 `workflow-api.json` 提交到独立服务的 `/prompt`，记录实际编号后只查询该编号，不因查询超时重交。

本次同时改变了运行设备和 VAE 精度（之前为 MPS／BF16 VAE，当前为 CPU／FP32 VAE），因此不是单变量根因实验。没有修改用户的 ComfyUI 源码、依赖或模型文件，没有商业 API 费用。不能将可辨识程度提高归因于某一个算子，也不能称为通用 MPS 修复、已接受的关键帧或完成产品集成。

后续在同一 CPU 服务仅改变 shift 的 [单变量对照](../cpu-shift5-r1/README.md) 仍未恢复自然摄影质感，原验收要求和本次证据均保留。
